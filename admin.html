불러오는 중

공고가 잘못 들어왔을 때 고칩니다. 고친 값은 따로 적어두기 때문에 수집이 다시 돌아도 안 지워집니다. 칸을 비우면 원래 값으로 돌아가고, 빗금(-) 하나만 적으면 빈 칸이 됩니다.

채용담당자 계정입니다. 커뮤니티와 급여 통계는 안 보입니다.
업무 이메일 인증을 마쳐야 공고를 올릴 수 있습니다. 도메인 메일이 없는 병원은 여기서 직접 열어주세요.
전화로 재직을 확인하신 뒤 여시고, 메모에 남겨두시면 나중에 찾기 쉽습니다.

앱 화면에 나가는 글을 고칩니다. 페이지별로 묶어뒀습니다.
칸을 비우면 원래 문구로 돌아갑니다. 회색 글씨가 원래 문구입니다.
줄을 바꾸려면 <br>, 굵게 하려면 <b>굵게</b> 로 적으세요.

공고를 얼마나 자주 긁어올지 정합니다. 30분마다 깨어나되, 매번 전부 긁지는 않습니다.
가벼운 것(알리오·중앙 공공기관)은 깨어날 때마다 — API 5번이라 부담이 없습니다.
무거운 것(잡플러스·나라일터)은 정해진 시각에만 — 나라일터가 상세를 열어 API 86번을 씁니다. 지자체 공고는 30분마다 새로 뜨지 않습니다.

짧은 시간에 지나치게 많이 조회한 계정입니다. 분당 20번을 넘으면 기록하고, 40번을 넘으면 잠깐 막습니다. 자동 수집이 의심되는 계정을 여기서 확인하세요.

앱 아래쪽 메뉴에 뜨는 항목입니다. 위아래 화살표로 순서를 바꾸고, 숨김에 체크하면 안 보입니다. 이름과 설명도 여기서 고칠 수 있습니다.

앱 홈과 대시보드에 뜨는 광고 판넬입니다. 여러 개를 넣으면 5초마다 바뀌면서 돌아갑니다.
