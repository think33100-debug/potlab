## 1절 · 지금 상태 (a) — **제가 확인할 수 없는 자리와 확인한 자리**

| 무엇 | 확인 | 어떻게 |
|---|---|---|
| Vercel Preview 배포가 켜져 있나 | **확인 못 했습니다** | Vercel 토큰이 저장소·서버에 없습니다. 세중님 화면에서 봐야 합니다 |
| Preview 환경변수가 운영과 같은 Supabase 를 보나 | **확인 못 했습니다 — 그러나 그럴 가능성이 큽니다** | 우리 설정에 Supabase 프로젝트가 **하나**뿐입니다 (`web/.env.local` 의 `NEXT_PUBLIC_SUPABASE_URL` 한 줄). Vercel 에서 환경변수를 **All Environments** 로 넣었으면 Preview 도 **운영 DB** 를 봅니다 |
| 그러면 무슨 뜻인가 | **지금 미리보기 = 운영 DB** 라는 뜻입니다 | 수지가 Preview 에서 누르는 것이 **운영 자료를 바꿉니다**. 그래서 환경이 서기 전에는 수지에게 Preview 를 주지 않습니다 |

**세중님이 볼 화면 (3분)**

```
① vercel.com → potjob-web → Settings → Environment Variables
   NEXT_PUBLIC_SUPABASE_URL 줄의 **Environments** 칸을 봅니다
     Production·Preview·Development 가 다 켜져 있으면 → **같은 DB** 입니다
② Settings → Git → Ignored Build Step / Deployment Protection
   「Vercel Authentication」이 켜져 있으면 로그인 없이는 Preview 를 못 봅니다
③ Deployments 목록에서 가지(branch) 배포가 생기는지 — 「Preview」 딱지가 붙은 줄이 있나
```

## 3절 · Preview 에만 개발용 주소·열쇠 걸기 (c)

```
① 개발용 프로젝트에서 받는 것 — URL · anon 열쇠 (service_role 은 **Vercel 에 넣지 않습니다**)
② Vercel → Settings → Environment Variables
   NEXT_PUBLIC_SUPABASE_URL      = 개발용 URL      · Environments: **Preview 만**
   NEXT_PUBLIC_SUPABASE_ANON_KEY = 개발용 anon     · Environments: **Preview 만**
   (Production 줄은 **그대로 둡니다** — 건드리면 운영 화면이 멈춥니다)
③ 같은 이름이 Production·Preview 둘 다 있으면 Vercel 은 **그 환경 것**을 씁니다
④ 넣은 뒤 **ui/ 가지를 한 번 밀어** Preview 배포가 개발용 DB 를 보는지 확인합니다
   확인법 — Preview 주소에서 공고 수가 **표본 수(50~100)** 로 보이면 개발용입니다
Deployment Protection
   끄면 주소를 아는 사람은 누구나 봅니다. 「Protection Bypass for Automation」 또는
   공유 링크(Share)를 쓰면 로그인 없이도 **그 링크만** 열립니다 → **세중님 선택 2번**
```


## 5절 · 수지 권한과 준비물 (e)

```

안 적는 것   운영 service_role 열쇠 · 운영 DB 주소(SUPABASE_DB_URL) · 서버 ssh —
            **어느 문서·대화·.env 예시에도 안 적습니다**
수지 윈도우에서
  Node        20 이상 (우리 서버는 24 입니다 · package.json engines 확인)
  명령         cd web && npm install && npm run dev
  .env 예시    web/.env.local.example 을 **이름만** 적어 둡니다 (값 없이) —
               NEXT_PUBLIC_SUPABASE_URL= · NEXT_PUBLIC_SUPABASE_ANON_KEY= ·
               NEXT_PUBLIC_VAPID_PUBLIC=
               ★ 값은 세중님이 **개발용** 것만 따로 전달합니다 (문서에 안 적습니다)
  확인         npx tsc --noEmit · npm run build 가 통과해야 밀 수 있습니다 (지침 11-2)
```
