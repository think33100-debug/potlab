## 「매칭 의심」 — 이름으로 붙은 것만 의심합니다

```
① 한 NAME: 묶음에 공고의 **시도가 둘 이상**     ← 서로 다른 지역 기관을 한 이름으로 묶은 것
② 심평원에 **그 이름을 품은 공식 이름**이 둘 이상  ← 더 긴 공식 이름과 헷갈릴 수 있음
③ 이름키가 **4자 이하**                        ← 「가람」·「성산원」 같은 흔한 이름
```

재는 자는 `tools/매핑점검_1024.mjs` 하나입니다. 의심 건은 —

```
· **회원 화면에 기관 정보를 붙이지 않습니다** (11/1~6 화면 작업 때 그 규칙으로 그립니다)
· 손확인 ① 문서로 올립니다 → 세중님이 「맞음/아님」·「바꿀 번호」를 채우면
  `tools/손확인_매핑_읽기.mjs` 가 읽어 **번호로 확정**합니다 (칸기록 · 되돌림 파일)
· 「맞음」이면 `기관.확인한때` 가 찍혀 **의심에서 빠지고**, 규칙·되메우기가 그 줄을 안 덮습니다
```

## 긁기 출처는 **이름 매칭을 안 거칩니다** (2026-10-24 세중님 C3)

우리가 긁는 곳은 **어느 기관인지 이미 알고** 시작합니다 (설정에 기관을 적어 두니까요).
그래서 긁은 공고는 **기관번호를 직접 적어** 담습니다 — 이름으로 다시 맞히지 않습니다.
그 공고의 연결상태는 「사람」으로 둡니다(규칙이 덮지 않게).
