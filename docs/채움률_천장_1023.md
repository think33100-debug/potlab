# 긁기 출처 채움률의 **천장** — 올릴 수 없는 것이 얼마인가 (2026-10-23 새벽)

맞음률은 100% 인데 채움률이 53~71% 입니다. 그래서 「채움률을 올리자」로 가기 전에
**공고문에 그 값이 적혀 있나**를 건마다 봤습니다. 사이트를 안 두드렸습니다 —
담긴 공고문 글만 봤습니다 (병원자체 회원 공고 17건 · 글 17/17 담김).

```
결론   남은 빈 칸의 **대부분은 공고문에 그 값이 없습니다.**
       채움률 53%·29% 는 읽기 실패가 아니라 **천장에 가까운 수**입니다.
```

## 2. 모집인원 — 채움률 53% · **여덜 중 여섯은 글에 없습니다**

```
글에 「N명」 이 아예 없는 것      6건
글에 있는데 비어 있는 것          2건  ← 아래
```

| 공고 | 글 | 왜 비었나 |
|---|---|---|
| HS1429957266 중앙병원 | 「물리치료사 **및** 작업치료사 모집 - 모집인원 : **0명**」 | **일부러 비웁니다** — 직군이 둘이라 어느 쪽 인원인지 모릅니다 (자기점검 2464줄에 그렇게 적혀 있습니다) |

★ 세중님께 묻습니다 — **일곱 칸 규칙의 「0명 그대로」** 를 이 두 꼴에도 쓸까요?
  둘 다 「0명」이라 어느 쪽이든 **0** 이라 뜻이 갈리지 않습니다. 다만 지금 규칙은
  「직군이 둘이면 비움」이고 **자기점검이 그것을 지키고 있어** 제가 함부로 뒤집지
  않았습니다 (한 줄 바꾸면 되고, 되돌리기도 한 줄입니다).

## 4. 그래서 능력표에 적을 말

```
병원자체 17건의 채움률 — 마감시각 29% · 모집인원 53% · 지원자격 53%
  그 가운데 **공고문에 값이 없는 것** — 마감시각 12/12 · 모집인원 6/8 · 지원자격 4/8
  고칠 수 있는 것 — **지원자격 2건** (표 칸 이름) · 모집인원 2건 (0명 규칙 · 세중님 결정)
```

**채움률을 100% 로 만들 수 없습니다.** 병원이 안 적은 것을 우리가 적으면 그것이
「틀린 값」입니다 — 그래서 빈 칸은 화면에서 **「공고문 확인 + 원문 링크」** 로 둡니다
(오픈 일정 원칙 · CLAUDE.md 15절). 올릴 수 있는 천장은 **지원자격 53% → 65% 쯤**입니다.

★ 이 글의 뜻 — 「채움률이 낮다」를 **고장으로 읽지 마십시오.** 낮은 까닭이
  ① 병원이 안 적음 ② 우리가 못 읽음 둘인데, 지금 병원자체는 **①이 대부분**입니다.
  ②만 고치면 되고, 그 수는 위에 적은 네 건입니다.
