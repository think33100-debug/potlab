# 긁기 출처 채움률의 **천장** — 올릴 수 없는 것이 얼마인가 (2026-10-23 새벽)

맞음률은 100% 인데 채움률이 53~71% 입니다. 그래서 「채움률을 올리자」로 가기 전에
**공고문에 그 값이 적혀 있나**를 건마다 봤습니다. 사이트를 안 두드렸습니다 —
담긴 공고문 글만 봤습니다 (병원자체 회원 공고 17건 · 글 17/17 담김).

```
결론   남은 빈 칸의 **대부분은 공고문에 그 값이 없습니다.**
       채움률 53%·29% 는 읽기 실패가 아니라 **천장에 가까운 수**입니다.
```

```

  않았습니다 (한 줄 바꾸면 되고, 되돌리기도 한 줄입니다).

## 3. 지원자격 — 채움률 53% · **여덜 중 넷은 글에 없고, 둘은 표 안입니다**

```

| HS341922328 용인세브란스 | 「○ 모집인원 및 응시자격 / 응시 부문 · 지망 구분 · 모집인원 · **응시자격** / 물리치료사(…) 재활의학팀 1명 [필수사항] - 대학(」 | **표** — 칸 이름이 「응시자격」 |

★ **이 둘도 지금은 못 고칩니다 — 제가 위에 「고칠 수 있다」고 쓴 것을 바로잡습니다.**

  담긴 글을 열어 보니 `<table>` 이 없고 **표가 한 칸씩 줄로 눕혀져** 있습니다 —

  ```
  ○ 모집부문 및 응시자격
  모집부문              ← 머리 칸 넷이 줄마다
  근무형태
  자격요건 및 우대사항
  모집인원
  작업치료사(보건직)      ← 자료 칸 넷이 또 줄마다
  출산/육아휴직 대체자 (계약직)
  - 학력 : 대학(교) …
  ```

  (HS1093929036 · kind=상세 · `<table>` 없음 · 줄바꿈 133개 · 칸 구분자 `|` 0개)

  그래서 「표 칸 이름을 더하기」가 아니라 **눕혀진 표를 다시 세우기**입니다 —
  머리 칸이 몇이고 자료 칸이 어디서 끊기는지를 **짐작해야** 합니다 (지침 3절 금지).
  두 건을 얻으려고 짐작 규칙을 넣으면, 꼴이 다른 공고에서 **엉뚱한 칸이 자격으로**
  들어옵니다 — 오늘 밤 예상연봉에서 겪은 그 일입니다.

  **제대로 고치는 길** — HS3 의 쪽 본문을 지금처럼 글자로만 담지 말고
  **kordoc 의 표 구조(blocks)로** 담는 것입니다. 그러면 `칸뽑기` 의 표 규칙이
  그대로 먹습니다. 다만 수집기 쪽 일이라 **동결(10/31) 전에는 위험**합니다 —
  오픈 뒤로 미루는 것이 맞다고 봅니다 (docs/동결까지_남은일_1023.md 4절).

## 4. 그래서 능력표에 적을 말

```
병원자체 17건의 채움률 — 마감시각 29% · 모집인원 53% · 지원자격 53%
  공고문에 값이 **없는** 것        마감시각 12/12 · 모집인원 6/8 · 지원자격 4/8
  값은 있는데 **구조가 없는** 것    지원자격 2/8 (눕혀진 표)
  규칙을 뒤집어야 하는 것          모집인원 2/8 (「0명 그대로」 · 세중님 결정)
  **지금 코드로 더 채울 수 있는 것 — 0건**
```

**채움률을 100% 로 만들 수 없습니다.** 병원이 안 적은 것을 우리가 적으면 그것이
「틀린 값」입니다 — 빈 칸은 화면에서 **「공고문 확인 + 원문 링크」** 로 둡니다
(오픈 일정 원칙 · CLAUDE.md 15절).

★ 이 글의 뜻 — 「채움률이 낮다」를 **고장으로 읽지 마십시오.** 낮은 까닭이
  ① 병원이 안 적음 ② 글에 구조가 없음 ③ 우리가 못 읽음 셋인데, 병원자체는
  **①이 대부분이고 ③은 0건**입니다. 동결 전에 제가 코드로 올릴 수 있는 채움률은
  **없습니다** — 올리려면 ②(담는 꼴)를 바꿔야 하고 그것은 동결 뒤 일입니다.

## 5. 그 빈 칸들이 **회원 화면에 어떻게 보이나** — 확인했습니다 (2026-10-23)

화면 코드(`web/app/jobs/[id]/page.tsx`)를 읽고 칸마다 확인했습니다.

| 칸 | 비었을 때 | 원문 링크 | 확인 |
|---|---|---|---|
| 모집 인원 | **「공고문 확인」** | 걸립니다 (`url={모집인원 ? null : j.url}`) | ○ |
| 지원 자격 | **「공고문 확인 ↗」** | 걸립니다 (`<a href={j.url}>`) | ○ |
| 접수 마감 | **「마감일 공고문 확인」** | 마감표시() 가 정한 말 | ○ |
| 마감 시각 | 칸이 따로 없습니다 — 접수 마감에 **붙여** 그립니다 (「… 오전 9시 마감」) | — | ○ 비면 날짜만 |
| 예상 연봉 | **「내규에 따름」** (회원에게는 언제나 그립니다) | — | △ 아래 |
| **근무지** | **칸이 아예 사라졌습니다** | — | **✗ → 고쳤습니다** |

```
원문 링크   회원 화면 284건 **전부** url 이 있습니다 (링크 없는 것 0건) —
            그래서 「공고문 확인」이 늘 링크로 걸립니다
```

### 근무지 — 고쳤습니다 (2026-10-23)

```
전   {(j.지역보임 || j.work_place) && ( <Core label="근무지" … /> )}
     → 둘 다 비면 **칸이 사라집니다**
후   <Core label="근무지" v={… || '공고문 확인'} url={있으면 null : j.url} />
     → 옆 칸(모집 인원)과 글자까지 같은 꼴
영향 회원 화면 **6건** (국립재활원 둘 · 수원병원 · 대구보건대 · 원광대 · 경남광역치매센터)
     여섯 다 원문 링크가 있어 바로 링크로 걸립니다
```

세중님 2026-10-22 4번 지시(「비어도 칸을 그립니다」)가 모집 인원·지원 자격에는
걸려 있었는데 근무지에는 안 걸려 있었습니다. 그 지시의 까닭이 **「회원이 「우리가
못 읽은 것」인지 「공고에 없는 것」인지 알 수 없다」** 였으니, 근무지도 같아야 합니다.

### 예상 연봉 — 「내규에 따름」이 맞나 (△)

회원에게는 **언제나** 그리고, 비면 **「내규에 따름」**이 됩니다
(2026-10-14 세중님 결정 · 화면 주석 340줄 「공고에 금액이 안 적힌 것이 흔하고
1층 39건 중 31건」).

```
걸리는 것   공고문에 **급여 이야기가 아예 없는** 공고도 「내규에 따름」으로 보입니다.
            그것은 「확인했더니 내규에 따른다」가 아니라 **우리가 모른다**는 뜻입니다
다른 칸은    모르면 「공고문 확인」입니다 — 칸마다 말이 다릅니다
```

★ **고치지 않았습니다.** 2026-10-14 에 세중님이 그 말로 정하신 자리이고,
  바꾸면 1층 31건의 화면 글자가 바뀝니다. 아침에 한 줄 여쭙니다 —
  「급여 이야기가 **아예 없는** 공고도 「내규에 따름」으로 둘까요, 아니면
  그때만 「공고문 확인」으로 둘까요」. (`승인대기_1023` F 로 적어 두겠습니다)
