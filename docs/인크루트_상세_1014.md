# 인크루트 채용관의 공고 본문은 `/jobcont/` 에 있습니다 (2026-10-14 · 읽기만)

세중님 지시 — 「인크루트 상세(recruit.incruit.com/…/job/…)가 JS 로 그려지는
것이면, 상세를 불러오는 뒤쪽 주소를 playwright-cli 로 찾아 fetch 로 받을 수
있는지 먼저. **주소를 짐작하지 말 것.**」

## ① 상세 페이지는 정말 비어 있습니다

```
node tools/hosp/긁을수있나.mjs https://recruit.incruit.com/khnmc/job/2610120006
  HTTP 200 · 8,095자
  태그 걷은 글 244자  ★ 자바스크립트로 그리는 쪽일 수 있습니다
  → 제목·접수기간·전형안내뿐. 모집부문·자격조건·급여가 없습니다
```

## ② 뒤쪽 주소를 **네트워크 기록에서** 찾았습니다 (짐작 아님)

```
playwright-cli -s=pot goto https://recruit.incruit.com/khnmc/job/2610120006
playwright-cli -s=pot --raw requests --static
  1.  [GET] https://recruit.incruit.com/khnmc/job/2610120006      => 200
  29. [GET] https://recruit.incruit.com/khnmc/jobcont/2610120006  => 200   ← 이것
  30. [GET] https://recruit.incruit.com/khnmc/api/?…&svc=siteinfo => 200
  31. [POST] https://recruit.incruit.com/api/bd/api_menu.asp      => 200
```

본문은 **JSON 이 아니라 iframe 으로 끼우는 HTML** 입니다.
주소는 상세 주소의 `/job/` 을 **`/jobcont/`** 로 바꾼 것입니다.

## 얻을 수 있는 칸

```
지원자격   「물리치료사 면허 소지자 …」      지금 빈칸
예상연봉   「연 4,110만원 ~ 4,210만원」       지금 빈칸 → 금액이 있습니다
모집인원   「O명」(강동경희대는 안 밝힘)·「1명」 꼴
접수마감   목록 쪽에서 이미 받고 있습니다 (시각 23:59 까지 글에 있습니다)
```
