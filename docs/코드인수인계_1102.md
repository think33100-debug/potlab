## 5. 꼭 기억할 함정 (올해 밟은 것들 중 오늘 또 만난 것)

```
· 보고 숫자는 **도구 출력에서 복사**합니다. 오늘 `git branch -v | head -10` 으로 보고
  가지를 「여덜」이라 적었는데 실제로는 더 있었습니다 (지침 10-6)
· 권한 코드·버킷 이름은 **짐작하지 않습니다.** 오늘 `권한있나('신고')`(실제 '신고처리')와
  버킷 `chat`(실제 `chat-images`)을 둘 다 틀렸습니다 — 찍어 보고 고쳤습니다 (지침 3·5절)
· 약관 본문은 **마크다운이 아닙니다**(whitespace-pre-wrap). `**…**` 를 넣으면
  회원 화면에 별표가 그대로 보입니다 — 오늘 셋을 넣었다가 뺐습니다
· React 컴포넌트 이름에 **한글을 쓰면** rules-of-hooks 가 전부 걸립니다
  (「컴포넌트가 아니다」로 봅니다). 안쪽 조각은 영어 이름으로 (지침 6-2b 와 같은 결)
· psql 의 NOTICE 는 **stderr** 로 나옵니다 — 러너가 stdout 만 찍으면 시험 결과가 안 보입니다
· 정적 쪽(●)에서 「시각이 지나면 바뀌는 것」은 **빌드 때 굳습니다** — revalidate 를 함께 걸어야
  합니다 (오늘 「초안입니다」 띠)
· 관리자 화면을 더하면 **메뉴 줄도** 더합니다 — 커밋 훅이 화면 수와 메뉴 수를 셉니다
```
