## 넣은 규칙

`tools/hosp/hs_files.js` 의 **`JS주소꼴` 한 자리**입니다. `<a>` 를 통째로 보고
`href` 든 `onclick` 이든 그 안에서 함수 호출을 찾습니다. 돌려주는 줄에
**`받는법`** 이 붙습니다 —

```
보훈   { 꼴: 'GET',  쿠키: '상세' }
성주   { 꼴: 'POST', 폼: { filenm, uuid, saveGbn }, 쿠키: '상세' }
```

자기점검 **8가지**를 더했습니다 (주소 꼴 · 받는법 · 폼 셋 · 점수).

### 실제 다섯 곳 전후

```
전   첨부 3개
후   첨부 **10개**
       중앙보훈   0 → 3   (공고문 pdf · 안내 pdf · 지원서 hwp)
       성주군     0 → 1   (javascript: 였던 것)
       청주의료원  0 → 3   (그누보드 꼴 · 앞서 고친 것)
       청주성모   0 → 1
       강남구치매  2 → 2
```

  <tr><td>기간제 간호직</td><td>간호사</td><td>2</td>…
  <tr><td>기간제 보건직</td><td>물리치료사</td><td>1</td><td>재활의학과</td>
      <td>‘26.11.01. ~ ’27.10.31.</td><td>계약직</td></tr>
  <tr><td>기간제 기능직</td><td>시설(기계)</td><td>1</td>…

세중님이 2026-10-02 에 원문으로 확인해 주신 **「물리치료사 1명」** 그대로입니다
(지침 10-2).

지원자격도 제대로 나왔습니다 —

```
(필수) 공고마감일 기준 물리치료사 면허증 소지자
(우대) 중추신경계발달치료(NDT) 등 요양급여(사-122, MM105) 청구가 가능한 자
```

### ★ 그런데 모집인원은 비었습니다 — 까닭이 또렷합니다

```
뽑힌 칸 — 모집인원 {} · 접수마감 null
```

표의 인원 칸이 **「1」** 입니다. `명뽑기` 는 `([0-9]{1,3})\s*명` 이라
**「명」이 붙어야** 집습니다. 중앙보훈 표에는 「명」이 없습니다.

**이것은 3번(칸 뽑기)에서 고칠 자리**입니다 — 표에서 우리 직군 줄을 찾았을
때는 **인원 칸의 숫자만으로도** 집어야 합니다. 「지어내지 말 것」과 어긋나지
않습니다 — 그 칸이 인원 칸이라는 근거가 표 머리(「채용예정 인원」)에 있습니다.
