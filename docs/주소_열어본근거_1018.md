# 병원 주소(hira_org.hosp_url) — **실제로 열어 본** 근거 (2026-10-18)

세중님 9번 — 「스킴 빠진 2곳·낡은 8곳 — 고친 주소는 **근거(실제 열어 본 것)와
함께, 짐작 금지**」

**이 컴퓨터(Windows·Node 24)에서** 받아 봤습니다. 서버가 아닙니다 — 「서버에서만
안 열리는 것인가」를 가리는 것이 목적이었기 때문입니다. 받은 것을 그대로 적습니다.

## 먼저 바로잡을 것 — 「스킴 빠진 2곳」 은 **822줄**입니다

```
hira_org 에 주소가 있는 줄            8,824
그중 http:// · https:// 가 없는 줄      822   ← 9.3%
```

전에 「2곳」 이라고 보고한 것은 **1층 사각지대 안에서 센 것**이었습니다
(`docs/사각지대_꼴묶음_1018.md` 2절). 전체로는 822줄입니다. **표를 822번
고치는 길로 가지 않는 것이 맞습니다** — 읽는 자리에서 붙입니다(아래 4절).

제목이 그 병원 이름인 것까지 확인했습니다 — 「열렸다」가 아니라 **그 병원이
맞다**는 근거입니다.

### 울산대학교병원 — **서버 탓이 아니었습니다**

세중님이 「서버에서만 안 열리는 까닭(https·인증서·IP) 먼저 — 고신대 꼴이면
같은 해법」 이라고 하셨습니다. 열어 보니 **고신대 꼴이 아닙니다.**

```
http://www.uuh.ulsan.kr/main/main.asp    ✗ 소켓이 끊깁니다 (UND_ERR_SOCKET)
https://www.uuh.ulsan.kr/main/main.asp   ✓ HTTP 200 · 1,687바이트
```

**hira_org 값이 `http://` 인데 사이트는 https 만 받습니다.** 이 컴퓨터에서도
http 로는 안 열립니다. 서버 IP·인증서 문제가 아니고 **스킴 하나**입니다.

제목이 비고 1,687바이트뿐인 것은 **JS 껍데기**라는 뜻입니다 — 게시판을 찾으려면
5번(브라우저 네트워크 기록)으로 가야 합니다. 그건 별개입니다.

### 세종여주병원 — 한글 도메인은 **퓨니코드로 잘 바뀝니다**

문서에 「`fetch` 가 퓨니코드로 바꿔 주는지 확인해야 합니다」 라고 적어 두었던
자리입니다. **바꿔 줍니다** — https 쪽이 `CERT_HAS_EXPIRED` 까지 갔다는 것이
곧 DNS·연결이 됐다는 뜻입니다. 인증서가 만료됐을 뿐이고 http 로는 200 입니다.

## 2. 못 열었습니다 — 두 번 실패해서 멈췄습니다 (세중님 규칙)

| 기관 | 받은 것 | 읽은 뜻 |
|---|---|---|
| 서광병원 | `http`·`https` 둘 다 **ENOTFOUND** (느슨하게도 같음) | **도메인이 사라졌습니다.** 주소를 지어내지 않습니다 |
| 정읍한국병원 | `http` → 302 → https · `https` → **ERR_SSL_DH_KEY_TOO_SMALL** | 사이트의 TLS 가 낡아 Node 가 거부합니다. 브라우저는 열 수 있습니다 |

둘은 **「손으로 확인할 곳」** 으로 보냅니다 (8번과 같은 자리 · `hand_check`).
CLAUDE.md — 「안 되는 곳은 「손으로 확인할 곳」 목록에 넣고 마지막 확인일을
남긴다. **빠지지 않는 것이 자동화보다 중요하다**」

정읍한국병원은 **TLS 를 느슨하게 하면** 받을 수 있지만, 그건 긁는 길이 아니라
까닭을 적기 위한 확인이었습니다. 긁을 때 인증서를 무시하지 않습니다.

## 4. 고치는 자리 — **표가 아니라 읽는 쪽**

822줄을 고치는 대신, 주소를 여는 자리에서 가립니다.

```
스킴이 없으면        https:// → 안 되면 http://
http 로 안 되면      https 로 한 번 더   ← 울산대가 이 경우입니다
https 로 안 되면     http 로 한 번 더    ← 세종여주·화성유일이 이 경우입니다
두 번 실패하면       멈추고 「손으로 확인할 곳」 으로
```

`tools/hosp/주소열기.mjs` 한 자리입니다 (지침 6절 — 기준은 한 자리).
`hira_org` 는 **안 고칩니다** — 심평원에서 받은 원본이고, 다음 동기화가
우리 수정을 덮습니다.

가 아니라 우리 표(`org_targets` 쪽)에 칸을 하나 두는 것이 맞습니다. 지금은
읽는 자리에서 가리기만 해 두었습니다.
