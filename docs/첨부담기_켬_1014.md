## 켜기 전 확인한 것

**① 바깥 주소만 담습니다.** `tools/첨부담기.mjs` 에 저장소 올리기가
없습니다 — 쓰는 파일은 마른 실행 미리보기 JSON 하나뿐입니다. 표 칸도
`job_id · kind · name · url · 수집묶음` 으로 **주소**입니다.

**② 파일 치우개가 못 닿습니다.** `tools/clean_orphan_files.js` 는
**Storage 버킷**(`avatars` · `post-images`)만 걸으며, 허용 목록
(`지워도되는꼴`)의 경로 꼴에 **안 맞으면 아예 안 건드립니다.**
`job_attachments` 는 Storage 가 아니라 표의 바깥 주소라 그 길에 없습니다.

## kordoc 으로 읽은 칸은 어느 길로 담기나

**`collect_put`** 입니다. 수집기가 `job_posts` 줄에 `뽑은값`(jsonb)·`뽑은법`
(`'kordoc'`)을 실어 보내고 창구가 `job_posts.뽑은값` 에 **합쳐** 담습니다
(`collect-cleaneye.mjs:469` · `collect-nara.mjs:589` · `collect-nid.mjs:383`).
`collect_attach` 는 **첨부 주소만** 받습니다 — `뽑은값` 칸이 없습니다.
