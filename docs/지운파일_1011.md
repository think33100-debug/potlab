## 1. 지운 것이 **회원 자료일 수 있었나** — 아닙니다

### notices (공고·교육 첨부) 13개

`notices` 통에 파일을 넣을 수 있는 사람은 **승인된 담당자**뿐입니다
(storage 규칙 `첨부올릴수있나`). 그런데 —

| 근거 | 값 |
|---|---|
| 담당자가 올린 공고(`source='BIZ'`) | **아홉 건, 전부 `시험자료 = true`** |
| 그중 2026-10-11 것 | `BIZ000010` ~ `BIZ000015` **여섯 건** — 오늘 제가 한 바퀴 돌며 만든 것 |
| 그 여섯 건의 `공고첨부` 줄 | **0줄** ← 지워진 파일들이 이것입니다 |
| 살아남은 `notices` 6개 | 전부 `BIZ000005`(2026-10-09 예시 자료)의 것 · `공고첨부` 6줄이 가리킴 |
| 수집기 첨부(`job_attachments`) | **0줄** (지금은 바깥 주소만 씁니다 — 우리 통에 파일이 없습니다) |

**즉 `notices` 통에 들어온 파일은 예시 자료와 오늘 제 시험뿐입니다.**
실제 회원·실제 기관이 올린 파일은 **한 번도 없었습니다** — 담당자 승인이
오늘 처음 났기 때문입니다.

지워진 13개 중 **이름을 댈 수 있는 10개** (화면 기록에 남은 것):

```
BIZ000010/1791714399525-notice.pdf   BIZ000010/1791714399787-notice.png
BIZ000011/1791714434500-notice.pdf   BIZ000011/1791714434629-notice.png
BIZ000012/1791714467834-notice.pdf   BIZ000012/1791714467943-notice.png
BIZ000013/1791714505597-notice.pdf   BIZ000013/1791714505718-notice.png
BIZ000014/1791714522072-notice.pdf   BIZ000014/1791714522193-notice.png
```

**못 댄 3개**는 같은 꼴(`BIZ000014`·`BIZ000015` 와 교육 첨부 `edu10/…`)로
보이지만 **이름을 적어 두지 않았으므로 「그랬을 것」이라고만 적습니다.**
내용은 전부 제가 그 자리에서 만든 가짜입니다 —
`%PDF-1.4 … %%EOF` 한 줄짜리 PDF 와 1×1 픽셀 PNG.
