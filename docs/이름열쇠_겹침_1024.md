# 이름열쇠 겹침 — **같은 이름, 다른 병원** 전수 셈 (2026-10-24 세중님 1번)

`hira_name_key()` 는 법인·괄호 말을 떼어 이름을 열쇠로 만듭니다. 그래서 **서로 다른
병원이 같은 열쇠**가 되는 자리가 있습니다. 한일병원을 가르면서 **같은 꼴을 전부** 셌습니다.

```

우리 기관 표        그런 열쇠를 쓰는 줄 **33줄** (1,219줄 가운데)

사이트표(hosp_sites) 그런 줄 **17줄** · 한 열쇠에 **줄이 둘인 곳 5곳**
```

★ **남은 위험 — 기관 표를 이름키로 잇는 자리** (고치지 않았습니다 · 승인 자리 ㉪)
서울 한전 한일병원은 **기관 표에 줄이 없습니다**. 그래서 `left join 기관 o on o.이름키 =
hira_name_key(g."기관")` 로 이으면 **진주 줄(경남 주소)이 붙습니다**. 1층 대상인데 주소가
딴 병원 것입니다. 기관 표를 **번호(ykiho)로** 잇게 바꾸는 것이 길이고, 그건 여러 도구와
`일층병원_구멍()` 을 함께 고치는 일이라 세중님 자리입니다.
