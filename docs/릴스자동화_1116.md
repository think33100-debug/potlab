# 릴스 자동화 — 1층 새 공고를 인스타 릴스로 (2026-11-16)

> 이 문서가 한 자리입니다. 코드는 `tools/reels/`.

## 무엇을 하나

1층(대학병원 · 종합병원 · 공공기관) 공고가 **회원 화면에 올라오면** 15초짜리 세로 릴스를
만들어 RAPO 인스타 계정에 올립니다.

```
0~3.2초    걸기       분류 칩 · 기관 이름 · 「작업치료사 채용」
3.2~7.6초  기관 소개  종별 · 설립 · 지역 · 허가 병상 · 개설 연도 · 근무 중인 물리/작업치료사 수
7.6~11.8초 공고 내용  직군 · 고용형태 · 모집인원 · 접수마감
11.8~15초  마무리     D-n · 마감 일시 · 「프로필 링크 → RAPO」
```

디자인은 RAPO OG 그림 틀(`web/lib/og-card.tsx`)을 세로로 옮긴 것입니다 — 남색 바탕 · 흰 판 ·
빨간 열린 테두리 · 안쪽 화살표 · Pretendard. 인스타 화면이 덮는 자리(위 ~220 · 아래 ~380 ·
오른쪽 ~140)에는 글을 두지 않습니다.

### 음악 — 가요 · 반자동 (2026-11-16 세중님 「가 ㄱㄱ · 가요로」)

API 로 올리는 릴스는 인스타 음악 보관함의 노래를 못 붙이고, 가요를 파일에 넣으면 저작권 검사에 걸립니다.
그래서 **소리 없는 릴스를 메일로 보내고, 휴대폰 인스타 앱에서 올리며 그때 인기 가요를 고릅니다.**

```
node tools/reels/run.mjs --메일 [--최대 2]
  → 1층 새 공고마다 소리 없는 15초 릴스(mp4) + 표지(jpg) + 캡션을 NOTIFY_EMAIL 로 (Resend)
  → 휴대폰: 영상 저장 → 인스타 새 릴스 → 음악에서 인기 가요 → 캡션 붙여 넣기 → 공유
  → 보낸 공고는 log/릴스_올림.json 에 「메일보낸때」 — 다시 안 보냅니다
```
★ Resend 첨부(`attachments` · base64) 는 이 세션에서 명세 원문을 못 열었습니다. 응답 원문 600자를 찍게 해 두었고
  **서버 첫 발송에서 메일이 첨부와 함께 오는지** 확인합니다. 영상 한 편은 약 3MB 입니다.
