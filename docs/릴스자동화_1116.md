# 릴스 자동화 — 1층 새 공고를 인스타 릴스로 (2026-11-16)

> 이 문서가 한 자리입니다. 코드는 `tools/reels/`.

## 무엇을 하나

1층(대학병원 · 종합병원 · 공공기관) 공고가 **회원 화면에 올라오면** 15초짜리 세로 릴스를
만들어 RAPO 인스타 계정에 올립니다.

```
0~3.2초    걸기       분류 칩 · 기관 이름 · 「작업치료사 채용」
3.2~7.6초  기관 소개  종별 · 설립 · 지역 · 허가 병상 · 개설 연도 · 근무 중인 물리/작업치료사 수
7.6~11.8초 공고 내용  직군 · 고용형태 · 모집인원 · 접수마감
11.8~15초  마무리     D-n · 마감 일시 · 「프로필 링크 → RAPO」
```

디자인은 RAPO OG 그림 틀(`web/lib/og-card.tsx`)을 세로로 옮긴 것입니다 — 남색 바탕 · 흰 판 ·
빨간 열린 테두리 · 안쪽 화살표 · Pretendard. 인스타 화면이 덮는 자리(위 ~220 · 아래 ~380 ·
오른쪽 ~140)에는 글을 두지 않습니다.

### 첫 장면 걸기 (2026-11-16 2차)

0초 첫 프레임에 글이 다 보입니다. 문장은 공식 값에서만 고릅니다(`걸기글()`) — 「꿀직장」 같은 지어낸 말은 안 씁니다.

```
갈래(조교·연구·행정)  국립중앙의료원 / 「작업치료사 지원 가능한 행정 자리」
마감 3일 안           마감까지 2일 / 「원광대학교병원 작업치료사 채용」
500병상 이상          1,044병상 상급종합병원 / 「전남대학교병원 작업치료사 채용」
그밖                  새 공고 / 「○○ 물리치료사 채용」
```
직군 글자 뒤로 형광펜이 지나가고, D-day 딱지가 튀어나옵니다.

### 사진 — 허락받은 기관만

드라이브 `병원이미지_수집`(전경 사진 · 로고)을 쓸 수 있게 해 두었지만, **관리표의 사용 조건이 전부
「사용 허가 미확인」**(449곳) 또는 「공식 페이지 게시 원본 · 재사용 허가 별도 미확인」(51곳)입니다.
11/13 로고를 내린 것과 같은 까닭으로 **기본은 끕니다.**

```
tools/reels/photos.json   { "기관 이름": { "파일": "photos/…jpg", "출처": "…", "허락": "누가·언제·어떤 조건" } }
                          「허락」 칸이 비면 안 씁니다. 지금은 {} 입니다
--시안사진 <파일>          허락 전 사진으로 내부 시안만. 화면에 「내부 시안 · 게시 금지」 도장
```
사진이 있으면 첫 장면 위쪽이 전경 사진(천천히 확대)이 되고 소개 장면까지 흐린 사진이 바탕에 남습니다.
드라이브 사진은 700px 안팎이라 세로 1080 화면에서는 조금 무릅니다 — 허락받을 때 원본 해상도도 함께 받으면 좋습니다.

### 점검 (2026-11-16 · 회원 화면 1층 20줄 전수)

```
node tools/reels/check.mjs <공고들.json> 2026-11-16
1층 20줄 → 묶은 뒤 19편 · 만듦 18 · 건너뜀 1 · 걸림 0
```
건너뜀 1 = 세브란스 PT+OT (마감 11-16 = 오늘). 렌더해서 눈으로 본 것 — 전남대(소개 있음) ·
홍성군 보건소(소개 없음 → 12초) · 국립중앙의료원(행정 갈래) · 삼성서울병원(칩).

## 돌리는 법

```
node tools/reels/run.mjs                 마른 실행 — 고르고 mp4·캡션만 만듦 (log/reels/<날짜>/)
node tools/reels/run.mjs --올리기        IG_USER_ID · IG_ACCESS_TOKEN 이 있을 때만 올림
node tools/reels/run.mjs --id 306936     한 건만
node tools/reels/render.mjs --자료 x.json --나감 x.mp4 [--음악 곡.mp3] [--표지 x.jpg]
```
한 편 렌더에 약 20초 (Playwright 로 프레임 450장 → ffmpeg H.264/AAC 48kHz · 30fps).
