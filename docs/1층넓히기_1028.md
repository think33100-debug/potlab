### ★ 그런데 21곳 가운데 **일곱은 게시판 주소가 아닙니다**

주소를 눈으로 보니 「채용 게시판 목록」이 아닌 것이 섞여 있습니다 —

```
한 글만 보이는 쪽 (게시판 목록이 아님)
  고양정신병원      …/sub04_01.php?boardid=notice&mode=view&idx=62   ← **글 하나**(view)
첫 화면 (게시판이 아님)
  광주보훈요양병원   https://www.bohun.or.kr/gwangjucare/main.do
  부산요양병원      https://www.bohun.or.kr/busancare/main.do
  서울요양병원      https://www.bohun.or.kr/seoulcare/main.do
  근로복지공단 부산의원  https://www.comwel.or.kr/busanclinic/index.jsp
  근로복지공단 서울의원  https://www.comwel.or.kr/seoulclinic/index.jsp
같은 주소를 두 기관이 씀
  인천광역시의료원 ↔ 인천광역시의료원백령병원  (백령병원은 분원입니다 · http/https 만 다름)
```

**까닭** — `채용게시판찾기` 의 울타리가 「링크를 열어 **목록 줄이 하나라도** 나오면
채용 게시판」입니다. 첫 화면에도 공지 목록이 있어서 **통과했습니다.**
`mode=view` 처럼 **글 하나**인 쪽도 줄이 하나 나옵니다.

```
고칠 자리 (울타리를 좁힙니다 · 수집기라 10/30 동결 앞이면 승인 자리)
  ㉠ 주소에 mode=view · idx= · ?no= 처럼 **글 하나**를 가리키는 꼴이면 버립니다
  ㉡ 목록 줄이 **둘 이상**이고, 줄마다 **글 번호가 다른** 링크여야 합니다
  ㉢ 첫 화면(`main.do`·`index.jsp`·`/`)은 **게시판으로 안 봅니다**
  ㉣ 같은 주소가 **다른 기관 둘**에 담기면 둘 다 의심으로 두고 손확인
```

★ **지금 회원 화면에 해가 가지는 않습니다** — 이 21곳은 사각지대(공고가 안 들어오는
곳)라 ① 18건에 섞여 있지 않습니다. 다만 **HS4 를 이대로 보내면 7곳은 헛돕니다.**
