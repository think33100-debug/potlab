# 사이트 왼쪽 메뉴 글자가 직군이 됐습니다 (2026-10-14)

세중님 결정 — 강진의료원 「필기시험 장소 (변경) 공고」 2건을 보류함으로 내리고,
같은 꼴을 전수 조사하고, 왜 기존 걸러내기가 놓쳤는지 찾을 것.

찾다 보니 **그 2건은 한 뿌리에서 나온 8건 중 2건**이었습니다.

## 1. 전수 — 제목에 시험·결과 말이 든 것

회원 화면 365건의 **기관 원문 제목**을 다 봤습니다.

```sql
select id, org_name, title from job_posts_pub
 where "원문제목" ~ '시험장소|시험 장소|필기시험|면접|합격자|서류전형 결과|장소 변경|일정 안내|결과 공고'
```

**2건입니다.** 둘 다 강진의료원, 둘 다 세중님이 짚으신 것입니다.

```
HS37047046    [전라남도 공고 제2026-581호] … 통합채용 필기시험 장소 공…
HS1611728177  [전라남도 공고 제2026-603호] … 통합채용 필기시험 장소 변…
```

표 전체(살아 있는 것·보류함·숨긴 것 다 합쳐)로는 6건이고, 그중 **제목에 우리
직군이 적힌 것은 0건**입니다. 그래서 낱말을 보태도 멀쩡한 공고를 안 건드립니다.

## 2. 왜 놓쳤나 — 걸러내기가 **두 군데서** 새고 있었습니다

### ㉮ 걸러낼 낱말에 「시험 장소」가 없습니다

```
gjmed.json 의 skip   합격자|발표|결과|서식|양식|임용후보        ← 사이트마다 따로
HS_SKIP_RE           … 시험\s*안내|시험\s*일정 …                ← 「시험 장소」가 없음
```

낱말이 **사이트마다 한 벌씩**(cfgs 86곳) 있고, 공통 한 벌인 `HS_SKIP_RE` 에는
「시험 장소」가 빠져 있습니다. `HS_SKIP_RE` 는 `gas/wage.js` 에서 떼어 오는데
그 파일은 **옛 앱(심사 중)이라 건드리지 않습니다.**

→ `tools/sort-rule.mjs` 에 `더보탠끝난말` 을 **한 자리**에 보탰습니다.
  `tools/check-sort.mjs` 에 「일부러 갈라놓음」 한 벌을 두어, 두 벌 대조가
  이 2건을 빨간 줄로 안 띄우고 **까닭과 함께 ※ 로** 찍습니다.
  (안 적으면 날마다 빨간 줄이 떠서 아무도 안 믿게 됩니다 · 지침 15절)

### ㉯ **이게 진짜 뿌리입니다** — 본문 승격이 제목을 다시 안 봤습니다

`tools/collect-hosp.mjs` 에 이 다섯 줄이 있었습니다.

```js
const j = matchJob(글);                  // 글 = 상세 페이지 전체
if (j) {
  x.직군 = j;
  x.갈래 = { 갈래: '회원목록', … };      // ← sortJob 을 안 지납니다
}
```

둘이 같이 틀렸습니다.

**① `matchJob` 은 맨 「물리치료」로도 걸립니다.** 그런데 `글` 은 상세 페이지
**전체**라서 **왼쪽 메뉴가 통째로 들어 있습니다.**

```
강진의료원 job_body (HS1611728177 · 1,626자 — 전부 메뉴입니다)
  「… 첨단장비소개 진료전문센터 종합검진센터 물리치료센터 진료안내 …」
                                       ↑ 여기 걸렸습니다

한국병원 (HS1340954199 · 기관 원문 제목이 「[모집]심뇌혈관센터 방사선사」)
  「… 직업환경의학센터 진료지원 물리치료실 임상병리실 …」
                                 ↑ 여기 걸렸습니다
```

**② 갈래를 손으로 '회원목록' 이라고 못 박아서**, 제목의 마감·결과·시험장소
걸러내기(`sortJob` 의 ⓪-0)가 **다시 안 걸렸습니다.** 첨부로 직군을 찾는 자리는
이미 `sortJob` 을 지나는데 본문 자리만 빠져 있었습니다 (지침 6절 — 두 자리).

→ `tools/공고문읽기.mjs` 에 `본문직군()` 을 두고 거기서 **「치료사」를 요구**합니다.
  기준은 이미 그 파일에 있던 `우리직군` 한 벌입니다 —
  `/물리\s*치료사(?![가-힣])/`. 2026-10-11 에 `물리\s*치료사?` 의 `?` 때문에
  「물리치료학과」가 걸린 것을 고친 그 규칙인데, **그때 본문 승격 자리를
  안 고쳤습니다.** 같은 뿌리를 두 번 밟았습니다.
  자기점검 7개를 더했습니다(강진 본문을 그대로 떼어 넣었습니다). 42개 전부 통과.
  `collect-hosp.mjs` 는 이제 `sortJob` 을 지나고, 제목이 거른 건수를 찍습니다.

## 3. 제목 정리 규칙 — 「채용공고」와 「물리치료사」는 어디서 왔나

`제목만들기행()` (DB 함수)이 조각을 **붙여 만듭니다**.

```
기관 + [부서] + [분야] + 직군 + [고용] + [대체사유] + '채용공고'
                          ↑ job_group          ↑ 늘 붙입니다
```

| | |
|---|---|
| 기관 원문 | `[전라남도 공고 제2026-603호] 2026년 상반기 … 통합채용 필기시험 장소 변경 공고` |
| 우리 제목 | `강진의료원 전라남도 공고 제2026-603호 물리치료사 채용공고` |

- **「물리치료사」** — `job_group` 에서 왔고, 그 `job_group` 이 **메뉴 글자**에서
  왔습니다. 2절 ㉯ 로 막았습니다. **이것이 막아야 할 것이었습니다.**
- **「채용공고」** — `제목만들기행` 이 **늘** 붙입니다. 363건 중 **362건**이
  이 말로 끝나고, 그중 **175건**은 기관 원문에 「채용·모집·초빙·공채」가
  한 번도 안 나옵니다. 그런데 열어 보니 거의 다 워크넷입니다 —

  ```
  원문  서울 성동구 굿모닝요양병원에서 물리치료사 구인합니…      (WN2 147건)
  우리  굿모닝요양병원 물리치료사 계약직 채용공고
  원문  노인주야간보호센터에서 간호조무사 혹은 작업치료사 모십니다.  (WN 23건)
  우리  정관로얄주간보호센터 작업치료사 정규직 채용공고
  ```

  「구인합니다」·「모십니다」를 「채용공고」로 적은 것입니다 — **뜻은 같고 말이
  다릅니다.** 「원문에 있는 말로만」을 글자대로 적용하면 이 170건의 제목이
  같이 깨집니다. 그래서 **손대지 않았습니다.** 세중님 결정으로 남깁니다.

## 5. 고치기 전에 잰 것 — 같은 뿌리 7건

  from job_posts p join job_posts_pub v on v.id = p.id join job_body b on b.job_id = p.id
