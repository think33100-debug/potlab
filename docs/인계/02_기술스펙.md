## 권한과 RLS

### 원칙

- **표를 직접 안 읽습니다.** 창구(`security definer` 함수)로만 드나듭니다
- 화면의 `isAdmin` 은 **단추를 보일지 말지**에만 씁니다. 막는 자리는 DB 입니다
- 숨긴 화면도 같습니다 — 화면에서 `isAdmin` 을 지워도 창구가 거절합니다

### 세 가지 함정 (실제로 밟았습니다)

**① `revoke … from anon` 만으로는 아무것도 안 닫힙니다.**
`anon` 은 `PUBLIC` 에 딸려 있습니다.

```sql
revoke execute on function f() from anon;           -- 안 닫힙니다
revoke execute on function f() from public, anon;   -- 닫힙니다
grant  execute on function f() to authenticated;
```

**② 함수 인수를 바꾸면 그것은 새 함수입니다.** PostgreSQL 이 새 함수를
**PUBLIC 에게 EXECUTE** 로 엽니다. 2026-09-25 에 `org_public_host_branch` 가
인수를 하나 더하면서 **기관 58,610곳이 보름 동안 비로그인에게 열려** 있었습니다.

**③ 기본 권한을 닫아 두는 것은 여기서 안 됩니다.**
`alter default privileges … revoke execute on functions from public` 을 걸고
시험해 봤더니 **그대로 PUBLIC 이 붙었습니다.** 마이그레이션마다 손으로 겁니다.

그래서 **새 함수를 만들 때는 같은 SQL 끝에 `revoke … from public, anon` 을
함께 넣습니다 — 트리거 함수도 예외가 아닙니다.**

## 개발자와 코드의 일 나누기

이 프로젝트는 **전부 자동일 필요가 없습니다.** 안 되는 곳은
「손으로 확인할 곳」 목록에 넣고 마지막 확인일을 남깁니다.
**빠지지 않는 것이 자동화보다 중요합니다.**

| 코드가 하는 일 | 사람이 하는 일 |
|---|---|
| API 10곳에서 공고 긁기 | 못 가린 공고를 **보류함**에서 확인 후 올리기 |
| 제목·상세·첨부에서 직군 찾기 | `.hwp` 중 못 읽은 것 |
| 마감일 읽기 | 비면 「마감일 공고문 확인」으로 두고 눈으로 |
| 상세 일곱 칸 채우기 | 끝내 못 찾은 칸을 **「빈칸 공고」**(`/admin/blanks`)에서 |
| 사업자번호 진위확인 (국세청 API) | 열쇠가 없으면 「수동 확인」 |
| 기관 성격 심평원 값 채우기 | 공식 값이 비면 **미정으로 두고 관리자 확인** |

**짐작해서 채우지 않습니다.** 비면 비어 있는 대로 두고 화면은 안전한 쪽으로 적습니다.

### 고친 뒤 할 것

```
1. npx tsc --noEmit                 (web/ 에서)
2. npm run lint                     새로 고친 파일에 지적이 없는지
3. node tools/check.js              API 표 ↔ METHODS · 중복 이름 · 색 · 조회 한도
                                    · 관리자 화면 수 ↔ 메뉴 줄 수

```

`npm run build` 는 **마지막에 한 번** 돌립니다 — `.next` 의 옛 타입 파일 때문에
`tsc` 가 헛 오류를 내는 일이 있습니다 (폴더 이름을 바꾼 직후).
