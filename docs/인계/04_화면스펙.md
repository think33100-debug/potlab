# 04. 화면 스펙

화면마다 — **목적 · 누가 · 구성 요소 · 상태별 모습 · 캡처 · 숨김 · 알려진 문제**.
캡처 파일은 `docs/screens/<이름>__pc.png` 와 `__phone.png` 두 벌입니다.

---

## 1. 홈 `/`

| | |
|---|---|
| **목적** | 공고로 가는 가장 짧은 길. 비회원에게는 「여기 오면 다 있다」를 보이는 자리 |
| **누가** | 누구나 |
| **구성** | 오픈 화면(스플래시) → 로고 → 맛보기 공고 → 계산기 넷 → 기관 → 교육 → 봉사 → 청년 → 초임·스펙 |
| **상태** | 비회원(맛보기 + 가입 권유) · 가입중(흐림) · 회원(전체) · **모름(아무것도 안 그림)** |
| **캡처** | `비로그인_홈` · `학생_홈` · `가입중_홈` · `비회원보기_홈` |
| **문제** | **홈 CTA 깜빡임** — 비회원→회원 판정이 늦어 「가입하고 전부 보기」가 잠깐 떴다 사라집니다 |

**오픈 화면 광고(`SplashAd`)** — `광고배너` 자리 둘이 **모두 꺼져 있고 그림이
비어** 있어 배너 겹이 아예 안 그려집니다. 지금 모습이 「광고 없음」 모습입니다.

## 2. 공고 목록 `/jobs`

| | |
|---|---|
| **목적** | 탭·직군·지역·검색으로 공고를 좁혀 보기 |
| **누가** | 회원. 비회원은 **맛보기 10건** (`site_settings.비로그인_공고수`) |
| **구성** | 탭 넷 → 직군·지역 고르개 → 검색 → 목록 20건 → 쪽 넘기기 |
| **탭 넷** | 공공기관·대학·종합 / 재활·요양병원·의원 / 아동·정신센터 / 요양원·노인센터 |
| **상태** | 비회원 맛보기 · 회원 목록 · 결과 없음 · 마감 포함 보기 |
| **캡처** | `비로그인_공고목록` · `학생_공고목록` · `작업치료사_공고목록` · `가입중_공고목록` |

**카드가 읽는 값은 DB 가 정합니다** — `지역보임`(순천병원이 「전남광주」로
나오던 자리) · `마감표시`(「수시채용」을 화면이 정하지 않습니다).
**화면에서 `work_place`·`apply_to` 로 직접 판단하지 마십시오.**

## 3. 공고 상세 `/jobs/[id]`

| | |
|---|---|
| **목적** | 지원할지 정하는 데 필요한 것만. 그 밖은 원문으로 |
| **누가** | 누구나 열립니다 (공유 링크가 살아야 해서). **본문은 회원만** |
| **구성** | 제목·꼬리표 → **일곱 칸** → 지원 자격 → 첨부 → 경쟁률 → 비슷한 공고 → 아래 고정 띠 |
| **일곱 칸** | 모집인원 · 접수마감 · 근무지 · 지원자격 · 예상 연봉 · 얼마나 바쁜 곳 · 병원 뜯어보기 |
| **상태** | 비회원(가입 권유 + 「로그인하고 지원하러 가기」) · 가입중(흐림) · 회원 · **마감(회색 · 아래 띠 없음)** |
| **캡처** | `비로그인_공고상세_로그인안내` · `학생_공고상세` · `작업치료사_공고상세` · `비회원보기_공고상세` |
| **숨김** | 아님 |

**비회원에게는 원문 주소를 창구가 아예 안 줍니다** (`job_one` 이 `url` 을 null 로).
화면에서 단추만 가리면 HTML·JSON 에 값이 그대로 남습니다.

**안 그리는 칸** — 전형방법·우대사항·결격사유·문의처·제출서류·**학력**.

**못 찾은 칸은 안 그립니다.** 「공고에 없음」을 쓰지 않습니다.

| 알려진 문제 | |
|---|---|
| 아래 띠 | 2026-10-09 에 **안전 영역**을 더했습니다 (아이폰 홈 막대에서 마지막 줄이 가렸습니다) |
| 마감 공고 미리보기 | 카톡 썸네일이 온통 빨강입니다 — 직군 공통색 `#FF3B30` 을 쓰고 있어서입니다 |
| 빈 칸 | 보이는 공고 377건 중 **374건**에 빈 칸이 있습니다 (지원자격 365·모집인원 363) |

## 4. 경쟁률 `/compete`

| | |
|---|---|
| **목적** | 「○○병원 작업치료사 경쟁률」로 찾아오는 사람을 받는 자리 |
| **누가** | **회원만** (2026-10-09 부터 목록도) |
| **구성** | 직군·지역·기관 고르개 → 묶음 목록 222개 → 한 묶음 펼치면 숫자 |
| **상태** | **비회원(로그인 안내)** · 회원(목록) · 회원(숫자까지) · 결과 없음 |
| **캡처** | `비로그인_경쟁률_로그인안내` · `학생_경쟁률` |

**앞 결정과 다릅니다** — 2026-10-05 에는 「목록은 누구나, 숫자는 회원만」이었고
2026-10-09 에 「목록도 회원만」으로 바뀌었습니다. 코드 주석에 둘 다 적혀 있습니다.

**숫자는 화면에서 가리지 않습니다** — 목록 창구가 평균·최고·최저를 **아예 안
내보냅니다.** 화면에서 가리면 개발자 도구에 값이 그대로 보입니다.

## 5. 커뮤니티 `/community` · `/community/[ch]` · `/post/[id]`

| | |
|---|---|
| **목적** | 역할이 같은 사람끼리 이야기하는 자리 |
| **누가** | 방마다 다릅니다. **학생 방에 치료사는 못 들어갑니다. 학생은 치료사 방을 봅니다** |
| **구성** | 방 고르기 → 글 목록 → 글 + 댓글 → 글쓰기(사진) |
| **상태** | 비회원(맛보기) · 역할별 방 · 중고거래 · 운영진 글 표시 |
| **캡처** | `비로그인_커뮤니티` · `학생_커뮤니티` · `작업치료사_커뮤니티` · `담당자_커뮤니티` |

**담당자는 읽기만 합니다** (치료사·학생 역할을 겸할 때만 씁니다).
**글쓴이 회원번호가 화면에 안 나갑니다** — `공개글` 보기가 닉네임만 담아 줍니다.
사진도 `/api/post-image/...` 로 중계합니다 (저장소 경로에 회원번호가 들어 있습니다).

| 알려진 문제 | |
|---|---|
| 사진 올리기 | 실제로 눌러 보지 못했습니다 |
| 신고 처리 | 글·댓글·대화·리뷰 **넷 다 처리 화면이 없습니다** |

## 6. 교육·학술 `/edu` · `/edu/session/[id]` · `/edu/org`

| | |
|---|---|
| **목적** | 학회·학원 교육을 한자리에. 결제는 받지 않고 **계좌 안내만** 전합니다 |
| **누가** | 누구나. 계좌는 **신청한 사람**과 담당자에게만 |
| **구성** | 과정 목록 → 회차 → 정원·접수·수강료 → 입금 안내 → 환불 규정 → 첨부 → 후기 |
| **상태** | 모집중 · 마감(정원 참) · 끝남 · 내 신청(신청함·입금대기·참여확정·미선정) · 후기 쓸 수 있음 · **첫날 08시 전** |
| **캡처** | `교육_모집중` · `교육_입금대기` · `교육_미선정` · `교육_후기쓰기` · `교육_후기아직` |

**후기를 지금 쓸 수 있나는 DB 가 정합니다** (`교육회차보기` 의 `리뷰가능`).
화면이 날짜를 만들면 그릴 때마다 값이 달라지고 규칙이 두 벌이 됩니다.

**주소에 한글을 쓰지 마십시오** — `/edu/회차/[id]` 가 로컬에서는 되는데
배포에서 404 였습니다 (2026-10-09 · `/edu/session/[id]` 로 바꿨습니다).

## 7. 채용 관리 `/biz` ★숨김

| | |
|---|---|
| **목적** | 병원 담당자가 **자기 공고를 직접** 올리고 고치는 자리 |
| **누가** | 승인된 **채용담당자**. 교육담당자 페르소나로는 안 열립니다 |
| **구성** | 병원 고르기 → 「공고 쓰기」 → **일곱 칸** → 첨부 → 내 공고 목록 |
| **단추** | 고치기 · 지금 마감 · 내리기 · (모아 온 공고에는) 공식 확인 도장 |
| **상태** | 승인 전(준비 중) · 병원 없음 · 공고 없음 · 시험병원(회원에게 안 보임 안내) |

**모아 온 공고는 담당자가 못 고칩니다.** 창구가 `source <> 'BIZ'` 를 거절합니다 —
긁어 온 값과 담당자가 고친 값이 어긋났을 때 어느 쪽이 맞는지 정하는 규칙을
먼저 만들어야 하기 때문입니다.
