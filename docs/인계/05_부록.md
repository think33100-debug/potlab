**「코드에 있다」는 ○ 가 아닙니다.** 메뉴에서 닿고, 열리고, 끝까지 되어야 ○ 입니다.

| | 수 |
|---|---|
| **전체** | 화면 **62** + 아직 없는 기능 14 = **76줄** |
| ○ 끝까지 됨 | 47 |
| △ 열리지만 덜 됨 | 10 |
| ✗ 아직 없음 | 14 |
| 개발자 몫 | 12 |
| 세중님 결정 | 5 |

화면이 61 → **62** 가 된 것은 `/admin/blanks`(빈칸 공고)를 더했기 때문입니다.
`/edu/회차/[id]` 는 `/edu/session/[id]` 로 **이름만** 바뀌었습니다 (수는 그대로).

자세한 표는 **`docs/화면전수점검_1009.md`** 에 있습니다. 여기에는 **바뀐 줄만** 적습니다.

## 2. 숨긴 기능과 여는 법

| 주소 | 무엇 | 지금 누구에게 |
|---|---|---|
| `/biz` | 채용 관리 | 승인된 채용담당자 · 마스터(채용 페르소나) |
| `/edu/manage` | 교육 관리 | 승인된 교육담당자 · 마스터(교육 페르소나) |
| `/partner` | 담당자 신청 | 운영진 |
| `/verify` | 재직 인증 | 운영진 |
| `/talk` · `/talk/[room]` | 1:1 대화 | 관리자 · 마스터 |
| `/alarm` · 탑바 종 | 알림함 | 관리자 |
| `/master` | 마스터 | 마스터 |
| `/admin/*` 23곳 | 관리자 | 권한별 |

### 여는 법 — **하나씩**

한꺼번에 열면 어디가 터졌는지 모릅니다. 화면마다 **한 줄**입니다.

| 어디 | 무엇을 |
|---|---|
| 그 화면 맨 위 `if (!isAdmin && !마스터)` 갈래 | 지웁니다 |
| `components/alarm-bell.tsx` 의 `!isAdmin` | 지웁니다 |
| `components/tab-bar.tsx` 의 `관리길()` | **그대로 둡니다** — 승인된 담당자에게만 뜨는 것이 맞습니다 |

**`/biz`·`/edu/manage` 는 열고 말고가 아닙니다** — **담당자를 승인하면**
그분에게 보입니다. 지금 안 보이는 것은 승인된 담당자가 없어서입니다.

**막는 자리는 화면이 아니라 DB 입니다.** 화면에서 `isAdmin` 을 지워도
`교육담당자인가()`·`담당자공고쓰기()` 같은 창구가 그대로 거절합니다.
그래서 화면만 열어 보는 것은 안전합니다.

## 5. 미뤄 둔 UX 문제

고치지 **않기로 한 것이 아니라, 아직 안 한 것**입니다.

| 무엇 | 지금 모습 | 왜 미뤘나 |
|---|---|---|
| **`loading.tsx` 가 없습니다** | 화면을 옮길 때 잠깐 빈 칸. 각 화면이 「잠시만요…」를 따로 그립니다 | 라우트마다 넣어야 해서 한 번에 할 일입니다 |
| **화면 제목이 14곳에만** | `<title>` 이 레이아웃 하나뿐이라 탭 이름이 전부 「POTJOB · 채용공고」. 계산기 넷 중 실업급여만 제목이 있습니다 | 제목 문구를 세중님이 정하셔야 합니다 |
| **홈 CTA 깜빡임** | 비회원→회원 판정이 늦어 「가입하고 전부 보기」가 잠깐 떴다 사라집니다 | 세 값으로 고쳤는데 홈만 남았습니다 |
| **카드가 두 모양** | 공고 카드와 기관 카드의 테두리·여백이 다릅니다 | 디자인을 한 벌로 정해야 합니다 |
| **마감 공고 카톡 썸네일이 온통 빨강** | 직군 공통색 `#FF3B30` 을 그대로 씁니다 | 마감색을 따로 정해야 합니다 |
| **화면에 직접 박은 색 338곳 / 41파일** | `tools/check.js` 가 셉니다 (늘어나면 보입니다) | 토큰으로 옮기는 일이 큽니다 |
| **스크롤 등장 효과(`Rise`)** | 화면에 들어오기 전까지 `opacity: 0` 입니다. 캡처가 스크롤을 안 하면 아래쪽이 **통째로 빈칸**으로 찍힙니다 | 캡처 쪽에서 훑고 찍도록 고쳤습니다. 화면 자체는 그대로입니다 |

**2026-10-09 에 고친 것** — 휴대폰 공고 상세의 아래 띠. 재 보니 띠 75px +
탭바 62px = 137px 인데 여백이 152px 이라 평평한 화면은 괜찮지만, 탭바가
`env(safe-area-inset-bottom)` 을 더 먹어 아이폰에서 171px 이 됐습니다.
(캡처에서 본 「본문 잘림」은 `fullPage` 가 고정 띠를 한 번만 그리는 **촬영 자국**
이었습니다 — 고치기 전에 원인을 확인했습니다.)

## 6. 세중님이 정하실 다섯 — **추천안과 까닭**

### ① 경쟁률 예시 자료 — `/compete` 가 시험 기관에서는 빈 화면입니다

> **추천 — 그대로 둡니다.** 경쟁률은 알리오가 공개한 **진짜 자료**라 지어낼 수
> 없습니다. 시험병원에 가짜 경쟁률을 넣으면 「우리가 만든 숫자」가 생깁니다.
> 대신 캡처는 **진짜 기관**(알리오 공공기관 19곳 중 하나)으로 찍습니다.

### ② 오픈 화면 광고 — 배너 둘 다 꺼져 있어 모양을 못 봅니다

> **추천 — 시험용 배너를 `시험자료`로 하나 켭니다.** `광고배너` 표에
> `시험자료` 칸을 더하고 관리자·마스터에게만 보이게 하면, 모양을 보면서도
> 회원에게는 안 나갑니다. 지금 구조(`광고배너`)로 바로 됩니다.

### ③ 알림 푸시 — 서버 크론이라 화면에서 확인이 안 됩니다

> **추천 — 관리자 화면에 「마지막으로 보낸 알림」 한 줄을 붙입니다.**
> `보낼알림()` 이 이미 건수를 돌려줍니다. `/admin/beat`(수집기 상태)에
> 같은 모양으로 한 줄이면 됩니다. 푸시를 실제로 받아 보는 것은 그다음입니다.

### ④ 중고거래 — 값·거래 상태 칸이 없습니다

> **추천 — 값과 상태(판매중·예약중·거래완료) 두 칸만 먼저 넣습니다.**
> 지금은 글 본문에 「가격 0원」처럼 적고 있어서 찾기도 거르기도 안 됩니다.
> 결제는 **안 붙입니다** — POTJOB 은 결제를 받지 않는다는 원칙과 같습니다.

### ⑤ 국세청 `NTS_BIZ_KEY` — 사업자 진위확인이 「수동 확인」입니다

> **추천 — 열쇠를 서버 `.env` 에 넣습니다.** 2026-10-09 에 활용신청 승인을
> 받으셨습니다. 넣으면 `tools/사업자진위확인.mjs` 가 저절로 돕니다.
> **다만 명세를 아직 원문으로 확인하지 않았습니다** — 열쇠가 생기면 먼저
> 한 건을 쏘아 응답 원문과 항목 이름을 찍고, 그걸 보고 읽는 코드를 맞춥니다
> (지침 3절·4절).
