### 여는 법 — **하나씩**

한꺼번에 열면 어디가 터졌는지 모릅니다. 화면마다 **한 줄**입니다.

| 어디 | 무엇을 |
|---|---|
| 그 화면 맨 위 `if (!isAdmin && !마스터)` 갈래 | 지웁니다 |
| `components/alarm-bell.tsx` 의 `!isAdmin` | 지웁니다 |
| `components/tab-bar.tsx` 의 `관리길()` | **그대로 둡니다** — 승인된 담당자에게만 뜨는 것이 맞습니다 |

**`/biz`·`/edu/manage` 는 열고 말고가 아닙니다** — **담당자를 승인하면**
그분에게 보입니다. 지금 안 보이는 것은 승인된 담당자가 없어서입니다.

**막는 자리는 화면이 아니라 DB 입니다.** 화면에서 `isAdmin` 을 지워도
`교육담당자인가()`·`담당자공고쓰기()` 같은 창구가 그대로 거절합니다.
그래서 화면만 열어 보는 것은 안전합니다.

## 6. 세중님 결정 대기 — 다섯 · **추천안과 까닭**

**개발자가 알아야 할 것** — 아래 다섯은 **아직 정해지지 않았습니다.** 그래서
그 자리의 화면이 비어 있거나 「수동 확인」입니다. 고장이 아닙니다.

**`/compete` 를 「회원만」으로 바꾼 것은 확정입니다** (2026-10-09 세중님 지시).
2026-10-05 의 「목록은 누구나」 결정을 뒤집은 자리라 적어 둡니다 — 비회원은
목록도 못 봅니다. 「경쟁률 보러 가기」가 로그인 안내로 바뀝니다.

### ① 경쟁률 예시 자료 — `/compete` 가 시험 기관에서는 빈 화면입니다

> **추천 — 그대로 둡니다.** 경쟁률은 알리오가 공개한 **진짜 자료**라 지어낼 수
> 없습니다. 시험병원에 가짜 경쟁률을 넣으면 「우리가 만든 숫자」가 생깁니다.
> 대신 캡처는 **진짜 기관**(알리오 공공기관 19곳 중 하나)으로 찍습니다.

### ② 오픈 화면 광고 — 배너 둘 다 꺼져 있어 모양을 못 봅니다

> **추천 — 시험용 배너를 `시험자료`로 하나 켭니다.** `광고배너` 표에
> `시험자료` 칸을 더하고 관리자·마스터에게만 보이게 하면, 모양을 보면서도
> 회원에게는 안 나갑니다. 지금 구조(`광고배너`)로 바로 됩니다.

### ③ 알림 푸시 — 서버 크론이라 화면에서 확인이 안 됩니다

> **추천 — 관리자 화면에 「마지막으로 보낸 알림」 한 줄을 붙입니다.**
> `보낼알림()` 이 이미 건수를 돌려줍니다. `/admin/beat`(수집기 상태)에
> 같은 모양으로 한 줄이면 됩니다. 푸시를 실제로 받아 보는 것은 그다음입니다.

### ④ 중고거래 — 값·거래 상태 칸이 없습니다

> **추천 — 값과 상태(판매중·예약중·거래완료) 두 칸만 먼저 넣습니다.**
> 지금은 글 본문에 「가격 0원」처럼 적고 있어서 찾기도 거르기도 안 됩니다.
> 결제는 **안 붙입니다** — POTJOB 은 결제를 받지 않는다는 원칙과 같습니다.

### ⑤ 국세청 `NTS_BIZ_KEY` — 사업자 진위확인이 「수동 확인」입니다

> **추천 — 열쇠를 서버 `.env` 에 넣습니다.** 2026-10-09 에 활용신청 승인을
> 받으셨습니다. 넣으면 `tools/사업자진위확인.mjs` 가 저절로 돕니다.
> **다만 명세를 아직 원문으로 확인하지 않았습니다** — 열쇠가 생기면 먼저
> 한 건을 쏘아 응답 원문과 항목 이름을 찍고, 그걸 보고 읽는 코드를 맞춥니다
> (지침 3절·4절).

```
job_attachments  0줄        (공고 377건 중 첨부가 담긴 것 0건)
```

공고 상세 일곱 칸은 **제목 → 상세 API → 첨부 공고문** 순으로 채웁니다.
셋째 단계의 재료가 지금 **없습니다.** 그래서 —

- 상세 API 에 없는 칸은 **그려지지 않습니다** (「공고에 없음」이라고 안 적습니다)
- 보이는 공고 **377건 중 374건**에 빈 칸이 있습니다 (`/admin/blanks` 에서 봅니다)
- `tools/공고칸채우기.mjs`(되메우기)는 **지금 돌려도 얻을 것이 적습니다** —
  첨부를 담는 일이 먼저입니다 (승인대기 ⑨ 가 ⑧ 뒤인 까닭)

**이 일은 인계 뒤로 미뤘습니다** (2026-10-10 세중님 지시 — 인계가 1순위).

**어디를 고쳐야 하나** — 저장소를 뒤져 확인했습니다. 담을 자리도, 창구도,
주소를 받아 오는 코드도 **이미 있습니다.** `insert` 한 줄만 없습니다.

```
표      job_attachments (job_id · kind · name · url · parsed_at)
        지금 0줄. 쓰는 코드는 tools/공고칸채우기.mjs 하나뿐이고 **읽기만** 합니다
        (`grep -rn job_attachments` → 코드 2곳 · 문서 8곳. 넣는 곳 0)

주소를 이미 받는 곳
  tools/collect-nara.mjs:320   첨부받기(idx) → { pdf, hwp }
                               부르는 곳 395 · 405 줄
  tools/collect-alio.mjs:199   첨부 공고문(atchFileType = 'A')을 골라 글자로
  tools/collect-cleaneye.mjs   cleaneye-file.mjs 의 첨부받기(URL)
```

세 수집기 다 **공고문을 열어 글자를 읽습니다** — 직군을 가리는 데 쓰려고요.
읽고 나서 **주소를 버립니다.** 그 자리에서 `job_attachments` 에 한 줄 넣으면
일곱 칸의 셋째 재료가 생깁니다.

**주의 둘.**
1. 나라일터 주소는 `&amp;` 를 안 풀면 **HTML 오류 화면**이 옵니다. 이미
   `온전히()` 가 풀어 두었으니 그 값을 넣으십시오 (작업지침 5절).
2. 넣은 뒤에 `tools/공고칸채우기.mjs` 를 돌립니다 (승인대기 ⑨). 되메우기는
   **`updated_at` 을 바꾸지 않습니다** — 그걸 보고 도는 것이 있습니다
   (작업지침 9절).

### 8-2. 일곱 칸 — 두 공고를 뜯어 본 결과

자세한 진단은 **`docs/공고상세_일곱칸_진단_1009.md`** 에 있습니다. 요약 —

| 칸 | 강릉의료원 작업치료사 | 삼성서울병원 물리치료사 |
|---|---|---|
| 모집인원 | ○ 상세 API | ✗ **안 그려짐** |
| 접수마감 | ○ 상세 API | ○ 제목에서 뽑음 |
| 근무지 | ○ 기관표 | ○ 기관표 |
| 지원자격 | ○ 상세 API | ✗ **안 그려짐** |
| 예상 연봉 | ✗ **안 그려짐** | ✗ **안 그려짐** |
| 얼마나 바쁜 곳 | ○ 심평원 치료사 수 | ○ 심평원 치료사 수 |
| 병원 뜯어보기 | ○ 기관표 | ○ 기관표 |

**강릉의료원은 출처가 셋**입니다(클린아이·워크넷·홈페이지 긁기). `detail` 항목
수가 각각 8 · 2 · 1 로 달라서, 어느 줄을 보느냐에 따라 칸이 찼다 비었다 합니다.

**출처가 칸을 잘못 채운 자리도 있습니다** — 클린아이 줄의 `결격사유` 에
「방문,우편(등기)」가 들어 있습니다. 그건 **제출 방법**입니다. 그래서 일곱 칸에서
`결격사유` 를 뺀 것이 결과적으로 맞았습니다.

**빈 칸은 그리지 않고 `/admin/blanks` 에 모읍니다.** 관리자가 채운 칸은
`edited_fields` 에 잠겨 수집기가 덮지 않습니다.

### 8-3. 화면 주소에 한글을 쓰면 **배포에서만** 404

```
/edu/회차/[id]    로컬 npm run build 는 통과 · tsc 통과 · 배포에서 404
                  퍼센트 인코딩으로 쳐도 404
→ /edu/session/[id] 로 바꿨습니다 (폴더 1 · 화면 1 · 문서 15 · DB 함수 4)
```

**고약한 까닭** — 로컬 빌드 목록에 `ƒ /edu/회차/[id]` 로 멀쩡히 찍힙니다.
**올려서 열어 봐야만** 드러납니다. 캡처 다섯 장이 전부 「이 자리에 아무것도
없어요」로 찍혀서 알았습니다.

### 8-4. **저장소 경로**에 한글을 쓰면 파일이 아예 안 올라갑니다

8-3 과 같은 뿌리입니다. Supabase Storage 가 열쇠(경로)에 한글이 있으면
`InvalidKey` 로 거절합니다. 2026-10-10 에 **셋**을 찾아 고쳤습니다.

| 어디 | 무엇이 한글이었나 | 증거 |
|---|---|---|
| `notices` (공고·교육 첨부) | **파일 이름** — 공고문 이름은 거의 다 한글 | 올리자마자 400 |
| `proofs` (재직 증빙) | 경로 앞머리 `재직-` | 버킷에 **견본 6장뿐** |
| `ad-images` (광고 배너) | 자리 이름 `앱` · `커뮤니티` | 버킷 **0장** |

경로는 ASCII(uuid + 확장자)만 쓰고 **보여줄 이름은 표에** 둡니다
(`공고첨부.이름`). 고친 뒤 `tools/첨부시험.mjs` 가 22가지 전부 ○ 입니다.

**광고 배너가 「꺼져 있어 모양을 못 본다」(6절 ②)의 까닭 절반이 이것입니다** —
켜고 안 켜고가 아니라 그림이 올라갈 수 없었습니다.

**같은 꼴을 또 만들지 않으려면** — 밖에서 이름으로 가리키는 자리(화면 주소 ·
저장소 경로 · 훅 주소 · 쿠키 이름 · HTTP 헤더 값 · 셸 변수)는 **영문**으로.
안에서 부르는 변수·함수는 한글이 낫습니다 (작업지침 6-2b).

### 8-5. 휴대폰 아래 띠가 본문을 가림 — **고쳤습니다**

```
재 보니   띠 75px + 탭바 62px = 137px  < 여백 152px   → 평평한 화면은 괜찮음
아이폰    탭바가 env(safe-area-inset-bottom) 을 더 먹어 171px > 152px  ← 진짜 문제
```

여백과 띠 위치를 둘 다 `env(safe-area-inset-bottom)` 을 더하도록 고쳤습니다
(`pb-[calc(152px+env(safe-area-inset-bottom))]` ·
`bottom-[calc(62px+env(safe-area-inset-bottom))] md:bottom-0`).

**처음에 캡처를 보고 「본문이 잘린다」고 보고했는데 그건 틀렸습니다** —
`fullPage` 가 고정 띠를 한 번만 그리는 **촬영 자국**이었습니다. 원인을 재 보고
나서야 진짜 문제(안전 영역)를 찾았습니다.

### 8-6. 미뤄 둔 UX 넷

5절의 표에 자세히 있습니다. 한 줄씩 —

| 무엇 | 왜 미뤘나 |
|---|---|
