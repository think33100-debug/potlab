## 낱말 풀이 — 먼저 읽으십시오

문서 곳곳에 설명 없이 나오는 말들입니다. **이 표만 알면 나머지는 읽힙니다.**

| 낱말 | 뜻 |
|---|---|
| **창구** | DB 함수(`security definer` RPC). **화면은 표를 직접 안 읽습니다** — 늘 창구를 거칩니다. 권한 규칙이 창구 한 곳에만 있어서, 주소를 손으로 쳐도 막힙니다 |
| **페르소나** | 마스터 계정이 **진짜 그 역할로** 바꿔서 보는 것. 화면만 흉내 내는 게 아니라 DB 의 `profiles.role` 까지 바뀝니다 → 「마스터 계정으로 직접 보는 법」 절 |
| **A 규칙** | 2026-10-09 에 정한 **담당자 역할 나누기**. 채용담당자는 「채용 관리」만, 교육담당자는 「교육 관리」만, 둘 다 승인되면 둘 다, 그 밖(회원·학생·관리자 페르소나)은 **둘 다 없음** |
| **보류함** | 수집기가 **우리 직군인지 못 가린 공고**를 모아 두는 곳. 버리지 않고 관리자가 확인한 뒤 올립니다. 화면은 `/admin/jobs` 안의 거르개입니다 (따로 된 주소가 없습니다) |
| **쓰레기통** | 우리 직군이 **아니라고 판정한** 공고. 「왜 버렸나」를 나중에 대보려고 남깁니다 (`/admin/trash`) |
| **다리** | 옛 앱(Apps Script)이 모은 공고를 Supabase 로 옮기는 것 (`tools/sync_jobs.js`). 한 방향입니다 |
| **시험자료** | `시험자료 = true` 가 붙은 줄. **회원에게 안 보입니다.** 시험병원·시험 교육기관에만 붙어 있고, 실제 회원 계정에는 한 줄도 없습니다 |
| **일곱 칸** | 공고 상세에 그리는 칸 일곱 — 모집인원 · 접수마감 · 근무지 · 지원자격 · 예상 연봉 · 얼마나 바쁜 곳 · 병원 뜯어보기. **못 찾은 칸은 안 그립니다** (「공고에 없음」이라고 안 적습니다) |
| **빈칸 공고** | 일곱 칸 중 빈 것이 있는 공고를 모은 관리자 화면 (`/admin/blanks`) |
| **진단띠** | 주소 끝에 `?진단=1` 을 붙이면 화면 맨 아래에 뜨는 상자. 「이 화면을 누구로 보고 있나」를 **값 없이 세기만** 해서 보여줍니다 (쿠키 수·배포 해시 등) |
| **묶음** | 쓰는 자리마다 뜻이 다릅니다 — 캡처에서는 **페르소나 한 벌**, 경쟁률에서는 **채용 공고 한 건**, 관리자 메뉴에서는 **메뉴 묶음** |
| **마스터** | 앱스토어 심사·화면 확인용 계정 하나. `/master` 로만 들어옵니다 (길이 없습니다) |
| **비회원 보기** | 로그아웃이 **아닙니다.** 로그인을 유지한 채 쿠키 하나로 브라우저·서버가 둘 다 JWT 를 안 보냅니다 → 자료까지 비회원이 됩니다 |

## 마스터 계정으로 직접 보는 법

화면 아홉 역할을 **진짜 그 역할로** 봅니다. 시험 계정을 아홉 개 만들 필요가
없습니다.

```
1. https://potjob-web.vercel.app/master 로 들어갑니다
   (메일·비번은 세중님이 따로 전달합니다. 이 문서에 없습니다)
2. 들어가면 화면 아래에 **빨간 띠**가 생깁니다
3. 띠에서 역할을 누릅니다 —
   관리자 · 학생 · 작업치료사 · 물리치료사 ·
   채용담당자 · 교육담당자 · 채용+교육담당자 · 가입중 · 비회원
4. 보고 나면 **「관리자」로 되돌려 두십시오**
```

알아 둘 것 둘.

- **「비회원」은 로그아웃이 아닙니다.** 로그인은 그대로 둔 채 쿠키 하나로
  브라우저와 서버가 둘 다 JWT 를 안 보냅니다. 띠는 남아 있지만 **자료까지**
  비회원이 보는 것과 같습니다 (캡처로 다섯 화면이 글자까지 같은 것을 확인).
- **시험 자료는 `시험자료 = true` 로 표시돼 있고 회원에게 안 보입니다.**
  시험 병원·시험 교육기관에만 붙어 있습니다. 실제 회원 계정에는 한 줄도
  넣지 않았습니다 (작업지침 8-9).

주소로 직접 쳐서 들어가도 **창구(DB 함수)가 거절합니다** — 화면만 막은 것이
아닙니다. 그래서 눌러 보는 것은 안전합니다.

## 캡처 스크립트 쓰는 법 — `tools/캡처.mjs`

**코드가 직접 찍습니다.** 사람이 비번을 치지 않습니다.

```
npm install -D playwright          (저장소 맨 위에서 · 한 번만)
npx playwright install chromium

node tools/캡처.mjs --목록          무엇을 찍는지만 봅니다
node tools/캡처.mjs --손님만        로그인이 필요 없는 것만
node tools/캡처.mjs                 묶음 아홉 전부 (PC 1280 · 휴대폰 390)
node tools/캡처.mjs --묶음 관리자
node tools/캡처.mjs --주소 http://localhost:3000
```

비번을 저장소에 두지 않고 돌리는 법 (서버 `.env` 에서 **프로세스 안으로만**) —

```powershell
$env:MASTER_EMAIL = (ssh potjob "sed -n 's/^MASTER_EMAIL=//p' ~/potlab/.env").Trim()
$env:MASTER_PW    = (ssh potjob "sed -n 's/^MASTER_PW=//p'    ~/potlab/.env").Trim()
node tools/캡처.mjs
Remove-Item Env:MASTER_EMAIL, Env:MASTER_PW
```

| 어떻게 | 왜 |
|---|---|
| 로그인 칸은 **안 찍습니다** | 찍으면 메일 주소가 그림에 남습니다 |
| 틀리면 한 번만 시도하고 멈춥니다 | `/master` 가 다섯 번에 15분 잠급니다 |
| 페르소나는 **띠의 단추를 눌러** 바꿉니다 | 창구를 몰래 부르면 띠가 안 지나갑니다 |
| 끝나면 `finally` 에서 「관리자」로 되돌립니다 | 안 되돌리면 다음에 학생으로 들어가 있습니다 |
| 「비회원 보기」는 로그아웃 창과 **글자를 맞춥니다** | 그림을 맞추면 빨간 띠 때문에 늘 다릅니다 |

**배포 주소는 `potjob-web.vercel.app`** 입니다. `potjob.co.kr` 은 아직
**옛 앱(GitHub Pages)** 이라 거기로 찍으면 404 만 나옵니다.

**저장소 맨 위의 `package.json` 은 git 에 없습니다** — 서버에서 `git pull` 뒤
`npm install` 이 돌면 크로미움(수백 MB)까지 받으려 하기 때문입니다.
