- **서버 ssh** — 수집기를 고칠 차례가 오면 그때
- **마스터 비번** — 세중님 것입니다. 캡처는 아래처럼 **값을 보지 않고** 돌립니다

열쇠 값은 화면·로그·커밋 어디에도 안 남깁니다. `git commit` 훅이 열쇠 모양을
찾아 막습니다 (커밋할 때 「○ 열쇠가 섞인 곳 없습니다」가 뜹니다).

## 캡처 스크립트 쓰는 법 — `tools/캡처.mjs`

**코드가 직접 찍습니다.** 사람이 비번을 치지 않습니다.

```
npm install -D playwright          (저장소 맨 위에서 · 한 번만)
npx playwright install chromium

node tools/캡처.mjs --목록          무엇을 찍는지만 봅니다
node tools/캡처.mjs --손님만        로그인이 필요 없는 것만
node tools/캡처.mjs                 묶음 아홉 전부 (PC 1280 · 휴대폰 390)
node tools/캡처.mjs --묶음 관리자
node tools/캡처.mjs --주소 http://localhost:3000
```

비번을 저장소에 두지 않고 돌리는 법 (서버 `.env` 에서 **프로세스 안으로만**) —

```powershell
$env:MASTER_EMAIL = (ssh potjob "sed -n 's/^MASTER_EMAIL=//p' ~/potlab/.env").Trim()
$env:MASTER_PW    = (ssh potjob "sed -n 's/^MASTER_PW=//p'    ~/potlab/.env").Trim()
node tools/캡처.mjs
Remove-Item Env:MASTER_EMAIL, Env:MASTER_PW
```

| 어떻게 | 왜 |
|---|---|
| 로그인 칸은 **안 찍습니다** | 찍으면 메일 주소가 그림에 남습니다 |
| 틀리면 한 번만 시도하고 멈춥니다 | `/master` 가 다섯 번에 15분 잠급니다 |
| 페르소나는 **띠의 단추를 눌러** 바꿉니다 | 창구를 몰래 부르면 띠가 안 지나갑니다 |
| 끝나면 `finally` 에서 「관리자」로 되돌립니다 | 안 되돌리면 다음에 학생으로 들어가 있습니다 |
| 「비회원 보기」는 로그아웃 창과 **글자를 맞춥니다** | 그림을 맞추면 빨간 띠 때문에 늘 다릅니다 |

**배포 주소는 `potjob-web.vercel.app`** 입니다. `potjob.co.kr` 은 아직
**옛 앱(GitHub Pages)** 이라 거기로 찍으면 404 만 나옵니다.

**저장소 맨 위의 `package.json` 은 git 에 없습니다** — 서버에서 `git pull` 뒤
`npm install` 이 돌면 크로미움(수백 MB)까지 받으려 하기 때문입니다.
