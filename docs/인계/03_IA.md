\* 관리자 **페르소나**에서는 담당자 화면이 안 보입니다. 담당자 자격이 있어야
보입니다 (A 규칙 — 「그 밖은 둘 다 없음」). 마스터는 페르소나를 바꿔서 봅니다.

**담당자는 치료사가 아닙니다.** 채용·교육 담당자 페르소나는 `role` 이 비어
있어서 커뮤니티 치료사 방에 **글을 못 씁니다.** 치료사가 담당자를 겸하면
치료사 역할 + 담당자 자격 둘 다를 갖습니다.

## 들어가는 길

| 어디서 | 무엇이 걸려 있나 |
|---|---|
| **로고** | `/` |
| **탑바 (PC)** | 공고 · 커뮤니티 (+ 담당자면 채용 관리 · 교육 관리) · 알림 종(관리자) · 내 정보 |
| **아래 탭바 (휴대폰)** | 홈 · 공고 · 커뮤니티 (+ 담당자 길) · 내 정보 |
| **홈** | 공고 · 기관 · 교육 · 계산기 · 봉사 · 청년 · 초임 · 스펙 |
| **`/me`** | 찜 · 알림 · 담당자 화면 · 탈퇴 |
| **꼬리말** | 약관 3종 · 문의하기 · 신고번호 |
| **`/admin` 왼쪽 메뉴** | 관리자 23곳 (**메뉴가 유일한 길**입니다) |
| **페르소나 띠** | 마스터에게만. 역할 아홉 |

### 길이 **없는** 곳 (일부러)

| 주소 | 왜 |
|---|---|
| `/auth/callback` | OAuth 가 부르는 자리 |
| `/master` | 운영 전용. 주소를 아는 사람만 |
| `/soon` | 자리만 둔 화면 |

2026-10-09 에 **길이 없던 `/partner`·`/verify` 두 곳**을 찾아 `/me` 에 붙였습니다.
저장소 전체(파일 174개)에서 `href=`·`href:`·`push(`·`replace(` 를 세어 찾았습니다.
**길이 없으면 없는 기능입니다.**

## 공고 상세 — 일곱 칸 (2026-10-09 확정)

```
① 모집 인원        우리 직군 인원만. 통합 공고의 전체 인원 금지
② 접수 마감        날짜 + 시각. 없으면 「마감일 공고문 확인」
③ 근무지          공고문 우선, 없으면 기관표 주소
④ 지원 자격        공고 말 그대로
⑤ 예상 연봉        「내규에 따름」·「협의」도 그대로. 숫자를 만들지 않음
⑥ 얼마나 바쁜 곳    심평원 자료 (회원만)
⑦ 병원 뜯어보기     심평원 자료 (회원만)
```

**안 그립니다** — 전형방법 · 우대사항 · 결격사유 · 문의처 · 제출서류 · **학력**.
그 내용은 **첨부 공고문**과 **「원문 보기」**(회원만)로 갑니다.

**못 찾은 칸은 안 그립니다.** 「공고에 없음」이라고 적으면 회원이 공고문을
안 찾아봅니다. 빈 칸은 `/admin/blanks` 「빈칸 공고」로 모읍니다.

## 자료가 흐르는 길

```
수집기(서버 크론) ─→ collect_put ─→ job_posts ─→ job_posts_pub ─→ 회원 화면
                                       ↑                ↑
옛 앱 ─ 다리(30분) ────────────────────┘        가리는 규칙이 여기 한 곳
                                                 (감춤 · 보류 · 시험자료)
담당자(/biz) ─→ 담당자공고쓰기 ─→ job_posts (source='BIZ')
```

**저절로 도는 규칙에서 BIZ 는 뺍니다** — 수집기가 확인해 주지 않는 공고라
「아무 신호가 없다」가 당연하기 때문입니다 (`hide_stale_posts` ② ·
`hold_rehab_only` · `fill_deadline_from_title`).
마감일이 지나서 내리는 규칙은 BIZ 에도 그대로 적용됩니다.
