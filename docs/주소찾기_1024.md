## ★ 먼저 — 어제 제가 틀리게 보고했습니다

```
어제 적은 것   「사각지대 456곳은 기관 표·심평원 hosp_url·병원사이트표를 다 대 봤고
              주소가 있는 곳이 **0곳**」
왜 틀렸나      심평원 주소를 **기관 표를 거쳐** 봤습니다 —
                 일층병원_구멍() → left join 기관 (이름키) → left join hira_org (ykiho)
              그런데 **사각지대 기관은 기관 표에 줄이 없습니다**(그래서 사각지대입니다).
              가운데 고리가 끊겨 심평원 주소에 **닿지도 못했습니다**
바른 숫자      이름열쇠로 **바로** 이으면 — 456곳 가운데
                 ⓐ 심평원 hospUrl 이 있는 곳        **292곳**
                 ⓒ 공공표 homepage 로 더 얻는 곳     **86곳**  (심평원에 주소가 없을 때만)
                 둘 다 없는 곳                      **78곳**  ← 세중님 손이 꼭 필요한 곳
```

## ⓑ 알리오 기관정보(INST) — **명세를 못 봤습니다** (세중님 캡처가 필요합니다)

우리가 가진 알리오 열쇠는 **채용정보 둘**뿐입니다.

```
ALIO_LIST_KEY     opendata.alio.go.kr/new/v1/recruit/list.do        (채용 목록)
ALIO_DETAIL_KEY   apis.data.go.kr/1051000/recruitment/list · detail (채용 상세 · steps)
```

**기관정보 서비스는 신청한 적이 없고 응답을 본 적도 없습니다.** 주소를 지어내
두드리지 않습니다 (지침 3절). 그래서 **신청 화면의 「상세기능」 표 캡처 한 장**이
필요합니다 — 그러면 그날 두드려 항목 이름을 원문으로 찍습니다 (지침 4절).

★ 참고 — 공고가 들어오는 기관은 이미 홈페이지가 옵니다. 워크넷 상세의 `homePg` 를
`detail.기관홈페이지` 로 담고 있고 **64건**입니다. 다만 **사각지대는 공고가 없는 곳**이라
이 길로는 한 곳도 못 얻습니다.

## 담는 울타리 — **열어서 확인한 것만** (`tools/사각지대_주소채우기.mjs`)

```
① 이름열쇠가 심평원에 여러 줄이면 **건너뜁니다** (어느 병원 주소인지 모릅니다)
② 주소를 **엽니다** — 심평원 주소가 옛 길이면 ㉠ https 로 바꿔 ㉡ **같은 집의 뿌리**까지
   한 번 더 두드립니다 (경주시·익산시가 그 꼴입니다). **봇 검사는 우회하지 않습니다** —
   우리 이름(User-Agent) 그대로이고 403·404 면 손확인 길로 보냅니다
③ **그 기관이 맞는지** 봅니다 — ㉠ 쪽 전화 = 심평원 전화 ㉡ 또는 이름 글자.
   ★ 「노인전문병원」 같은 **흔한 종별 말만** 맞은 것은 **안 받습니다**
     (그런 쪽이 수십 곳이라 엉뚱한 병원을 담습니다 — 2026-10-24 밤에 자를 좁혔고
      느슨한 자로 담긴 2곳(상주시립요양병원·천안시립노인전문병원)은 비웠습니다)
④ 못 맞추면 **안 담습니다** — 「자바스크립트로 그리는 쪽」은 갈라 적습니다
   (강북삼성병원 www.kbsmc.co.kr 은 본문 글자가 **1자**입니다)
⑤ 담을 때 근거 — 불변근거.홈페이지 = '<심평원 hosp_url|공공표 homepage> · 열어서 확인 <날짜> (<무엇으로>)'
```
