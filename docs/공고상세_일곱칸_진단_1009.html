5. 채우는 규칙 (세중님 확정)


순서     ① 제목  ② 상세 API 가 준 detail  ③ 첨부 공고문
         ③ 은 PDF·HWP 는 kordoc, **그림은 Haiku**

· 「공고에 없음」을 쓰지 않습니다. 못 찾으면 **칸을 안 그립니다**
· 모집인원은 **우리 직군 인원만**. 통합 공고의 전체 인원 금지
· 「내규에 따름」·「협의」는 공고 말 그대로. 숫자를 만들지 않습니다
· 근무지는 공고문 우선, 없으면 기관표 주소
· 끝내 못 찾은 칸 → /admin/blanks 「빈칸 공고」. 채우면 edited_fields 로 잠김
· 뽑은 값은 job_posts.뽑은값 에 따로 담고 원문 detail 은 그대로 둡니다
· admin_locked · edited_fields 는 안 건드리고 updated_at 도 안 바꿉니다
