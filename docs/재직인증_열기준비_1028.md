## 2. 동의 체크 + **기록 자리** — ★ 표를 고쳐야 합니다 (승인대기 ㉨)

```
지금    web/app/verify/page.tsx 는 **누르면 바로 올라갑니다.**
       :79-82 에 파기·민감정보 안내는 **있지만** 「동의 체크」가 없고,
       동의한 기록이 **아무 데도 안 남습니다** (`약관동의` 같은 표가 **없습니다**)
필요    ㉠ 화면 — 올리기 단추 위에 체크 한 칸
            「위 **수집 항목·목적·보관 기간·파기**에 동의합니다 (필수)」 + 처리방침 링크
       ㉡ 기록 — **누가·언제·무슨 문구에** 동의했는지
```

**제 제안 (승인대기 ㉨)** — 새 표를 만들지 않고 **`재직인증` 에 칸 둘**을 더합니다.

```sql
alter table "재직인증"
  add column if not exists "동의한때" timestamptz,
  add column if not exists "동의문구" text;   -- 그때 보여 준 문구의 판(예: 'verify-2026-11')
```

```
왜 표가 아니라 칸인가   동의는 **그 신청 한 건에 딸린 것**입니다. 신청 줄이 지워지면
                     동의 기록도 같이 지워지는 것이 맞습니다 (보관 기간이 같습니다)
왜 승인 자리인가       DB 구조 변경입니다 (0-0 · 지휘 절 ⓑ)
빈 값                그 칸이 null 인 **옛 네 줄은 시험자료**라 손댈 것이 없습니다
화면 쪽               체크를 안 하면 단추가 안 눌리게 (web/ 만 · ui/ 가지)
```
