# A — 사각지대 셈에서 「API 꼴」을 빼기 (2026-10-23 08:50 올림)

## ★ 먼저 — 제가 드린 숫자(459 → 442)가 **틀렸습니다**

올려서 재 보니 이렇습니다.

```
            전        후      움직임
사각지대    459  →   457      -2
공고만들어옴  34  →    19     -15
사이트있음   284  →   301     +17
──
대상 합     777      777      그대로
```

**17곳이 「사이트있음」으로 옮겨간 것은 맞습니다.** 그런데 그 가운데 **15곳은
이미 「공고만들어옴」**이었습니다 — 공고가 들어오고 있으니 사각지대로 세지
않고 있었던 것입니다. 사각지대에 있던 것은 **둘뿐**이었습니다.

```
사각지대에서 빠진 둘
  대학병원  빛고을전남대학교병원   전남 광주남구   (180일 공고 0건)
  상급종합  전북대학교병원        전북 전주덕진구  (180일 공고 0건)
```

이 둘이 바로 **2026-10-19 에 제가 「주소가 없으니 못 긁는 곳」으로 고쳤던
그 둘**입니다. 그때 고친 것이 과했고, 이번에 되돌린 것입니다.

**제가 「459 → 442」라고 적은 까닭** — 주소 빈 줄 17개를 세고 「17곳이 사각지대에서
빠진다」로 적었습니다. **그 17곳이 지금 어느 칸에 있는지 세지 않았습니다.**
지침 10-5 그대로입니다 — 숫자를 보고하기 전에 분모를 봐야 합니다.

★ **그래도 고침 자체는 맞습니다.** 셈이 틀린 자리는 하나가 아니었습니다 —
「공고만들어옴」 34곳 가운데 15곳은 **우리가 긁고 있는 곳**인데 「긁지는 않는데
공고가 어디선가 들어온 곳」으로 세고 있었습니다. 그쪽이 바로잡혔습니다.

## 올린 전문·전후 ACL

```
파일   supabase/migrations/2026_10_23_구멍_API꼴.sql (145줄 · md5 3c06fdba538a)
고친 곳  `긁는곳` CTE 의 where 한 줄 —
         where (nullif(s.url,'') is not null
                or s.kind in ('appsite','schmc','listjson','cmc','greeting'))
           and not coalesce(s."끔", false)
ACL 전  {postgres=X/postgres,service_role=X/postgres}  secdef=true
ACL 후  {postgres=X/postgres,service_role=X/postgres}  secdef=true   ← 글자까지 같습니다
```

인수가 같아 `create or replace` 가 ACL 을 그대로 둡니다 (지침 6-2). 그래도 끝에
`revoke … from public, anon, authenticated` + `grant … to service_role` 을 다시
걸어 뒀습니다.

**되돌리는 법** — `supabase/migrations/2026_10_23_구멍_API꼴_되돌림.sql` 을 올리면
`긁는곳` 의 where 가 `nullif(s.url,'') is not null` 만 보는 전 규칙으로 갑니다.
