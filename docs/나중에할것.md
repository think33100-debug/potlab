# 나중에 할 것

급하지 않은데 잊으면 안 되는 것을 한 줄로 적습니다 (2026-10-09 부터).
급한 것(자료가 깨지거나 · 수집이 멈추거나 · 보안 구멍)은 여기 안 적고 바로 고칩니다.

- `page_hits`·`job_events` 에 비로그인이 바로 씁니다 → RPC 를 거치게 하고, 같은 방문자·같은 공고·같은 날 한 번만 세기 (가짜 조회수 막기)
- 수집기 창구 20여 개가 anon 열쇠 + `p_secret` 에 기댑니다 → 서버 전용 열쇠(service_role)로 옮기기
- `기본권한시험()` 함수가 남아 있습니다 (아무도 못 부름) → 다음 `delete` 묶음 때 치우기
- `push_devices` 가 죽은 표입니다 (0줄 · 코드 없음) → 치우기
- `collect_secret_all` 의 꺼진 줄 여섯 → 24시간 멀쩡하면 지우는 SQL (승인 창)
- `열쇠 마지막 쓴 때` → `collector_beat` 의 출처별 마지막 박동으로 갈음 (표·함수 안 늘림)
- IA 문서 5절의 UX 문제 18가지 → 화면 제목 14개 · 로딩 화면 · 홈 CTA 깜빡임 순서로
