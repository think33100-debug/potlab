**우리가 만드는 우리의 공간 — 정보를 투명하게 공유한다.**
채용공고만이 아니라 **경쟁률 · 연봉**까지. 지금은 물리 · 작업치료사, 나중엔 **의료기사 전체**.

## 1. 이름 칸 (검색에 걸리는 자리)

```
RAPO 라포 | 치료사가 만든 채용사이트      ← 2차 추천 (브랜드)
RAPO 라포 | 치료사 채용·경쟁률·연봉        ← 1차 (검색어 위주)
```
인스타 검색은 **사용자 이름과 이름 칸**만 봅니다. 「치료사 채용」으로 찾는 사람에게 걸리게 넣었습니다.
의료기사 전체로 넓힐 때 「치료사」 → 「의료기사」로 바꿉니다.
