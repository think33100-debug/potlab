# 24시간 컴퓨터로 옮기기 — **준비 목록** (2026-10-27 세중님 5번 · 실행은 **10/30 뒤**)

지금은 **목록만**입니다. 동결(10/30) 앞에 옮기면 「어느 컴퓨터에서 돈 코드인지」가
섞입니다 — 그래서 **태그를 붙인 뒤에** 옮깁니다.

```
옮기는 것      Claude Code 를 돌리는 **제 자리**(작업 컴퓨터)뿐입니다
안 옮기는 것    수집기·크론·DB — 그대로 **서버(potjob)** 에서 돕니다. 서버는 안 건드립니다
그래서         24시간 컴퓨터가 꺼져도 **공고 수집은 멈추지 않습니다.** 멈추는 것은 제 쪽 일뿐입니다
```

## 1. 깔 것

| 무엇 | 왜 | 확인하는 법 |
|---|---|---|
| **Node 24.x** (서버와 같은 쪽) | 도구가 전부 `.mjs` 입니다 | `node -v` → `v24.` |
| **git** | 저장소를 받고 올립니다 | `git --version` |
| **Claude Code** | 제가 도는 자리 | 로그인 한 번 |
| **ssh 클라이언트** (윈도우 기본 것) | 서버에 **읽기·git pull** 만 걸러 | `ssh -V` |
| ~~psql~~ | **안 깝니다** — DB 는 서버에서만 두드립니다 | — |

★ **`psql`·DB 주소를 그 컴퓨터에 두지 않습니다.** DB 를 보는 일은 서버에서 돌립니다
(`ssh potjob 'bash -s' < 할일.sh`). 그래야 열쇠가 한 자리에만 있습니다.

## 2. 저장소

```
git clone https://github.com/think33100-debug/potlab
cd potlab && node tools/check.js         ← 통과하면 준비된 것입니다
```

`gas/` 는 **받지 않습니다** (지침 0절 — 손대지 않는 것). 지금도 저장소에서 빠져 있습니다.

## 3. `.env.local` — **이름만** 적습니다 (값은 세중님이 그 컴퓨터에서 직접)

```
SUPABASE_URL=
SUPABASE_SERVICE_KEY=
APPS_SCRIPT_URL=
EXPORT_KEY=
```

```
★ 값을 여기 적지 않습니다. 채팅·문서·커밋에도 적지 않습니다 (지침 8-11)
★ .env 는 셸로 source 하지 않습니다 — node 가 읽습니다 (지침 8-12)
★ 서버의 .env 와 ~/수집크론.sh 는 **저장소 바깥**입니다. 옮길 것이 없습니다
```

## 4. 서버 접속 — **열쇠 없이 git pull 구조를 지킵니다**

```
그 컴퓨터가 서버에 하는 일    ① git pull 을 시키는 것 ② 로그·숫자를 읽는 것
                            둘 다 `ssh potjob '…'` 한 줄입니다
서버에 파일을 넣지 않습니다    scp · ssh cat 쓰기 금지 (지침 8-10 — 세 번 밟았습니다)
ssh 는 한 걸음에 한 번        UFW 가 22번을 30초에 6연결로 묶습니다 (지침 8-18)
```

**열쇠(ssh 비밀키)를 그 컴퓨터에 새로 만들지, 지금 것을 옮길지는 세중님 자리입니다.**
제 쪽 제안 — **그 컴퓨터에서 새 열쇠를 만들어 공개키만 서버에 붙이는 것**입니다
(지금 열쇠를 복사하면 열쇠가 두 자리에 생깁니다). 붙이는 일은 서버 설정이라
**승인 자리**이고, 세중님이 직접 하시는 것이 맞습니다 —

```
그 컴퓨터에서   ssh-keygen -t ed25519 -C "24시간컴퓨터"
서버에서        ~/.ssh/authorized_keys 에 그 **공개키**(.pub) 한 줄 붙이기
~/.ssh/config   Host potjob / HostName … / User … / IdentityFile …
                ★ 주소는 config 한 곳에만 둡니다 (지침 8-5)
```

