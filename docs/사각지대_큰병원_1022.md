# 1층 사각지대 — 상급종합·대학병원 (2026-10-22 밤 · 세중님 3번)

세중님 지시 — 「1층 사각지대 중 **상급종합·대학병원만** cfg 붙이기. 먼저 대상 목록.
짐작으로 cfg 만들지 않기(지침 3절)」.

**목록을 만들다가 숫자가 틀린 것을 찾았습니다.** 먼저 그것을 적습니다.

---

## ★ 1. 「안 긁는 1층 기관 459곳」이 **우리가 긁는 곳을 세고 있습니다**

`일층병원_구멍()` 은 **주소(`hosp_sites.url`)가 비면 「못 긁는 줄」로 봅니다.**
2026-10-19 에 그렇게 고쳤고, 함수 주석에 까닭이 적혀 있습니다 —

> 주소가 없으면 수집기가 열 데가 없고, 끈 줄은 일부러 안 긁는 것입니다.
> 그런 줄을 「사이트있음」으로 세면 ① 에서 조용히 빠집니다 —
> **빛고을전남대·전북대가 그렇게 빠져 있었습니다 (공고 0건).**

그런데 주소가 빈 줄은 **17곳이고 전부 `appsite·schmc·listjson` 꼴**입니다 —
그 꼴은 **주소가 필요 없습니다.** 호스트와 번호로 API 를 부릅니다.
그리고 그 17곳은 **잘 긁히고 있습니다.**

| 기관 | 꼴 | 우리 DB 공고 |
|---|---|---|
| 부산대학교병원 | listjson | **23** |
| 분당서울대학교병원 | appsite | **19** |
| 의료법인 인당의료재단 부민병원 | appsite | 9 |
| 연세대학교 의과대학 용인세브란스병원 | appsite | 8 |
| 아주대학교병원 · 의료법인 길의료재단 길병원 | appsite | 7 · 7 |
| 전남대학교병원 | appsite | 5 |
| 순천향 서울·부천 | schmc | 3 · 3 |
| 충북대학교병원 | appsite | 3 |
| 삼육서울병원 · 서울특별시 동부병원 · 순천향 천안 · 화순전남대 | appsite·schmc | 2 씩 |
| 순천향 구미 | schmc | 1 |
| **빛고을전남대학교병원 · 전북대학교병원** | appsite | **0** |

즉 **0건인 곳은 둘뿐**이고, 그 둘조차 **설정이 이미 있습니다.**
나머지 열다섯은 공고가 들어오는데도 「사이트있음」에서 빠져 있습니다
(`들어온곳` 이 받아 주지만, **공고가 없는 달에는 다시 사각지대로 셉니다**).

★ **고칠 것 — `일층병원_구멍()` 의 「사이트있음」 판정에 `appsite·schmc·listjson`
  꼴을 넣어야 합니다.** DB 함수라 **승인 자리**입니다. 아침 ① 숫자가 그만큼 줄어듭니다
  (적어도 열일곱, 다른 꼴까지 보면 더). 전문은 세중님 말씀하시면 바로 올립니다.

## 2. 그래서 **cfg 를 붙일 큰 병원이 남아 있지 않습니다**

상급종합·대학 사각지대에서 **우리 DB 공고가 0건**인 곳을 추리니 열 곳이었고,
하나씩 보니 이렇습니다.

| 기관 | 종별 | 왜 0건인가 | 해야 할 일 |
|---|---|---|---|
| 전북대학교병원 | 상급종합 | **긁고 있습니다** (appsite · 아래 3절) | 없음 |
| 빛고을전남대학교병원 | 병원 | 전남대 공용 appsite — 공고가 본원 이름으로 옵니다 (cnubh.json 메모) | 없음 |
| 강북삼성병원 | 상급종합 | 채용관이 **봇 막이** | 손확인 |
| 학교법인 울산공업학원 울산대학교병원 | 상급종합 | **Vaadin** 채용시스템 | 손확인 |
| 강남을지대학교병원 | 병원 | 쪽에 채용 링크 없음 (그룹 쪽일 수 있음) | 손확인 |
| 양산부산대학교병원 | 상급종합 | **cfg 가 이미 있습니다** (오늘 수집기가 더한 21곳에 있음) · 오늘 두드리니 못 받음 | 지켜보기 |
| 조선대학교병원 | 상급종합 | **cfg 가 이미 있습니다** · 홈페이지에 한글 채용 링크 0개(JS) | 지켜보기 |
| 연세대학교 원주세브란스기독병원 | 상급종합 | 주소 있음(`/web/www/employment_notice`) · 오늘 쪽에 채용 링크 없음 | 지켜보기 |
| 학교법인 을지학원 대전을지대학교병원 | 종합병원 | 주소 있음 · 모바일 쪽으로 옮겨 가고 채용 링크 0개 | 지켜보기 |
| 동국대학교의과대학경주병원 | 종합병원 | `hosp_sites` 에 **줄이 없습니다** · 오늘 두드리니 **못 받음** | 주소를 사람이 확인 |

**새로 붙일 cfg — 0곳.** 「지켜보기」 넷은 설정·주소가 있는데 쪽이 JS·모바일로
바뀐 것이라, 짐작으로 고치면 안 됩니다 (지침 3절). 동국대경주 하나만 **주소를
사람이 확인**해 주시면 붙일 수 있습니다.

## 4. 오늘 두드린 자취 (robots·게시판 꼴)

`tools/채용판_들어가보기.mjs` — robots 를 먼저 보고 링크를 따라가 **공고 목록인지**
셋으로 가립니다(줄 3개 이상 · 날짜 2개 이상 · 글번호 링크 여럿). 자기점검 26가지 통과.

```
http://www.pnuyh.co.kr/content/   양산부산대      못 받음 — fetch failed
https://www.ywmc.or.kr/           원주세브란스    쪽에 채용 링크 없음
http://www.cuh.co.kr/             전북대          채용 링크는 있지만 공고 목록이 아님 → 3절
http://hosp.chosun.ac.kr          조선대          쪽에 채용 링크 없음 (한글 링크 글 0가지)
http://www.dumc.or.kr/index01.jsp 동국대경주      못 받음 — fetch failed
http://www.emc.ac.kr/default.asp  대전을지        모바일로 옮겨 가고 채용 링크 0개
```

**robots 전면 금지로 막힌 곳은 하나도 없었습니다** — 전부 「링크를 못 찾음·못 받음」입니다.
robots 금지는 손확인 목록(8곳)에 따로 있습니다 (`docs/손확인_한바퀴.md` 1절).
