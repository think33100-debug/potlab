# 나라일터 — 안 쓰던 기능 셋과 보건소 244곳 (2026-10-18)

세중님 지시 **D**(「큰 숙제는 ① 안 긁는 1층 기관 476곳 · 보건소 244 를 먼저」)를
시작하면서, 지침 4절대로 **「내가 이 API 의 기능을 전부 쓰고 있나」**를 먼저 물었습니다.

**결론부터** — 보건소 244곳에 수집기를 새로 만드는 일이 **아닙니다.**
보건소 공고는 **이미 들어오고 있습니다.** 476 중 보건소 244 는 **셈 방식 문제**입니다.

## 1. 지침 4절을 또 밟고 있었습니다

`tools/collect-nara.mjs` 는 나라일터 **6개 기능 중 셋만** 씁니다 —
`getList` · `getItem` · `getItemFile` (파일 14~16줄 머리말에 그렇게 적혀 있습니다).

CLAUDE.md 4절에 **2026-09월에 이미 적어 둔 그대로**입니다 —

> 「나라일터 — 그러고 나서 또 같은 상태였습니다. 신청한 6개 중 3개만 쓰고 있었습니다.
> 쓰던 것 getList · getItem · getItemFile / 안 쓰던 것 getItemPosition ·
> getClsfList · getInsttList」

**한 달 넘게 그대로였습니다.** 이번에 두드려 봤고 **셋 다 됩니다.**

```
BASE  https://apis.data.go.kr/1760000/PblJobService      (XML)

getInsttList     insttcode · insttname                   totalCount 453,642
getClsfList      code · codefullname · codename          totalCount 662
getItemPosition  cnt · code · idx · name · parentidx      공고별 직급과 **인원**
```

★ 제가 처음에 **BASE 를 틀리게** 두드려(`1051000/recruitment`) 「없거나 폐기된
서비스」를 받고 **없는 기능이라고 섣불리 판단했습니다.** 되는 호출 꼴
(`collect-nara.mjs:228`)을 베껴 다시 하니 전부 200 이었습니다.
**되는 호출을 베끼는 것이 먼저입니다** (지침 5절).

## 2. `getItemPosition` — 공고별 직급과 **인원**

알리오의 `steps` 와 같은 것입니다. 견본 **15건 전부**(100%) 왔습니다.

```
한국수산자원공단   → 일반직(정규직) 10명 · 실무직(무기계약직) 9명 ·
                    조사직(무기계약직) 16명 · 기간제 근로자 19명 ·
                    체험형 청년인턴 25명
한국여성인권진흥원 → 공무직 5명 · 기간제(장애인제한포함) 3명
국립호남권생물자원관 → 기간제근로자(영양사) 1명 · 기간제근로자(조리사) 1명
세종특별자치시      → 지방과학기술서기관 또는 지방일반임기제(개방형 4호) 1명
```

**지금 상태** — `GJ2` 공고 **334건 전부 `headcount` 가 빕니다.**
그런데 공고 주소(`gojobs.go.kr/apmView.do?empmnsn=NNNNNN`)에서 **334건 다**
번호가 집힙니다. 즉 **지금 당장 받을 수 있는데 안 받고 있습니다.**

### 그래도 **그대로 쓰면 안 됩니다**

직급 이름이 「일반직 · 공무직 · 기간제 · 실무직」 처럼 **고용형태**인 경우가
많고, **직군이 아닙니다.** CLAUDE.md 15절 —
「여러 직군 통합 공고는 인원이 우리 직군 인원이 아님」.

```
쓸 수 있는 자리   직급 줄이 **하나뿐**이고 그 줄이 우리 직군일 때 → 모집인원 확정
쓸 수 없는 자리   줄이 여럿일 때 → 어느 줄이 우리 직군인지 **이름으로 못 가립니다**
                 (예 「세종특별자치시 개방형직위(보건소장) 1명」 — 우리 직군 아님)
```

→ **통합공고에서 우리 직군 줄을 가리는 재료**로 쓰는 것이 맞습니다.
제목·본문·첨부에서 직군을 가린 뒤, 그 직군 이름이 직급 줄에 있으면 그 줄의 `cnt`.

## 3. `getClsfList` — 직군 거르기에는 **못 씁니다**

662개를 전부 받아 봤습니다. 「치료·재활·보건·간호·의료기사」가 든 것 **60개** —
전부 **공무원 직급 체계**입니다.

```

간호사무관 · 간호주사 · 간호조무주사 · 보건연구관 · 보건연구사
```

**「물리치료」·「작업치료」는 하나도 없습니다.** 의료기사 직군은 이 체계에 없습니다.

## 5. 그러면 ① 476 의 보건소 244 는 무엇인가

`일층병원_구멍()` 이 보건소 244곳을 **전부 「사각지대 · 사이트있음 0 · 공고만들어옴 0」**
으로 셉니다. 그런데 공고는 **중앙 창구(나라일터·워크넷)로 들어옵니다.**

**CLAUDE.md 15절의 치매안심센터와 같은 꼴입니다** —

> 「치매안심센터 공고는 `nid.or.kr` 중앙 게시판에 모입니다. 개별 센터 256곳
> 수집기는 만들지 않습니다. 그래서 커버리지를 「256곳 중 몇 곳」으로 세지
> 않습니다 — `org_targets.커버리지분모 = false` 이고 … 중앙 게시판으로 모이는
> 갈래를 기관 수로 세면 0/256 경보가 날마다 떠서 **아무도 경보를 안 믿게 됩니다.**」

**보건소도 같은 자리입니다.** 244/244 사각지대가 날마다 찍히는데, 메울 길은
기관별 긁기가 아닙니다.

### 세중님이 정해 주셔야 하는 것

```
㉮ 치매센터처럼 뺀다          커버리지분모 = false. ①476 → 232 로 줄어듭니다.
                            「셈에서 뺐다」를 아침 메일에 한 줄로 밝힙니다
㉯ 「중앙 창구로 들어옴」 상태를 따로 둔다
                            사각지대와 구분해 셉니다. 분모는 그대로 793
㉰ 그대로 둔다                244/244 가 계속 찍힙니다
```

**제 의견은 ㉯** 입니다 — ㉮는 「보건소를 안 본다」로 읽히고, ㉰는 15절이 경고한
「아무도 안 믿는 경보」가 됩니다. ㉯는 분모를 지키면서 **메울 숙제와 이미 덮인
것을 가릅니다.**

다만 ㉯를 하려면 **「그 보건소 공고가 들어온 적 있나」를 기관별로 이어야** 합니다.
지금 나라일터 기관 이름(「서울특별시 강북구 보건소」)과 `일층병원_구멍()` 의
이름(「강남구보건소」)이 **꼴이 달라** 안 이어집니다. 묶기 기준 정리가 먼저입니다
(강진의료원 `www` 중복과 같은 뿌리 — 수집기 순서 5).

## 6. 안 한 것 · 다음

- `getItemPosition` 을 수집기에 **아직 안 붙였습니다.** 붙이면 통합공고의 직군별
  인원을 받을 수 있지만, **직군 가리기와 함께** 해야 합니다 (위 2절). 승인 필요.
- `getInsttList` 453,642줄은 **아직 안 훑었습니다.** 기관 트리(대통령·국무총리·
  입법부·사법부·시도…)로 보입니다. 보건소를 이름으로 찾으면 「나라일터가 어느
  보건소를 담고 있나」를 짐작 없이 셀 수 있습니다 — ㉯를 할 때 쓸 재료입니다.
- 상급종합 2 · 대학 19 · 종합 56 은 **아직 손대지 않았습니다.** 이쪽은 보건소와
  달리 **기관 홈페이지 긁기가 맞는 자리**입니다 (중앙 창구가 없습니다).
