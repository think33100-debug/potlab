# 관리자 2단계 인증 켜는 법 (2026-11-18 초안)

멘토-추가-보안5 ④ · 멘토-2차-05-1 · 멘토-4-03

**결론: 휴대폰에 먼저 등록하고, 시험해 보고, 그다음에 SQL 을 올립니다. 순서를 지키면 잠기지 않습니다.**

- 이 가지를 합쳐도 **아무도 안 막힙니다.** 등록 안 한 관리자는 「2단계 인증을 켜 주세요」 띠만 봅니다.
- SQL 을 올리기 전에는 코드 칸이 **화면에만** 있습니다. 진짜 벽은 SQL 입니다.
- SQL 은 **등록한 사람에게만** 코드를 요구합니다. 등록 전에 올려도 바뀌는 것이 없습니다.
- 복구 담당은 **대표 본인**입니다 (Q15 확정).

---

## 0. 미리 볼 것 (한 번)

Supabase 대시보드 → Authentication → **Multi-Factor** 에서 **TOTP(인증 앱)** 가 켜져 있는지 봅니다.
꺼져 있으면 등록 화면에서 「등록을 시작하지 못했어요」가 뜹니다. 켜는 것은 대표 손입니다.

휴대폰에 인증 앱을 하나 깝니다. Google Authenticator 나 Microsoft Authenticator 면 됩니다.

## 1. 휴대폰에 등록

1. 관리자 계정으로 로그인합니다.
2. `/mfa` 를 엽니다 (관리자 화면 맨 위 노란 띠의 「2단계 인증 켜기」).
3. 「등록 시작」 → 화면의 QR 그림을 인증 앱으로 찍습니다.
4. 앱에 뜬 6자리를 넣고 「등록 마치기」.
5. **다른 기기에도 하나 더** 등록해 둡니다 (태블릿·예비 휴대폰). 화면의 「다른 기기에 하나 더 등록」.
   휴대폰을 잃어버려도 그 기기로 들어갈 수 있습니다.

알아 둘 것
- 등록을 마치는 순간 **다른 기기의 로그인은 풀립니다** (Supabase 동작).
- QR 그림·글자·코드는 **누구에게도 보내지 않습니다.** Slack·메모·금고에도 적지 않습니다.
- 마스터 계정(`/master`)도 쓰신다면, 그 계정으로 로그인해서 같은 방법으로 따로 등록합니다.

## 2. 시험

1. 로그아웃 → 다시 로그인 → `/admin` 을 엽니다.
2. **6자리 코드 칸**이 떠야 합니다. 코드를 넣으면 관리자 화면이 열려야 합니다.
3. 틀린 코드를 한 번 넣어 「코드가 맞지 않아요」가 뜨는지 봅니다.
4. `/master` 를 쓰면, 비밀번호 뒤에 코드 칸이 뜨는지 봅니다.
5. 두 번째 기기의 코드로도 들어가지는지 봅니다.

여기까지 되면 SQL 을 올려도 됩니다. **하나라도 안 되면 SQL 을 올리지 않습니다.**

## 3. SQL 올리기 (대표 손)

파일: `sql/초안_1118/관리자_2단계.sql` (되돌리기: `관리자_2단계_되돌리기.sql`)

1. 파일 머리의 「올리기 전에 찍어 둘 것」 쿼리를 돌려 결과를 대화에 붙입니다 (권한 그대로인지 견줄 값).
2. 파일 전체를 SQL 편집기에 붙여 **한 번에** 돌립니다.
   - 운영 함수 본문이 초안과 다르거나, 권한이 바뀌거나, 비회원 판정이 오류를 내면 **스스로 멈추고 아무것도 안 바뀝니다.**
3. 파일 끝 ⑦ 「흉내 시험」을 돌립니다. 등록한 계정은 `aal1_판정 = false`, `aal2_판정 = true` 여야 합니다.
4. 관리자 화면에서 코드를 넣고 공고 숨기기 같은 일을 하나 해 봅니다.

무엇이 바뀌나
- 관리자 판정 셋(`is_admin()` · `대표인가()` · `권한있나()`)이 「등록한 사람은 코드까지 넣은 로그인이어야」를 봅니다.
- `is_admin()` 을 쓰는 관리 함수 약 69개 · RLS 규칙 약 45개 · 뷰 4개가 **함께** 따라옵니다.
- 코드 없이(aal1) 관리 함수를 직접 불러도 「관리자만」으로 거절됩니다. 관리자용 뷰는 빈 표가 나옵니다.

## 4. 휴대폰을 잃어버렸을 때

**우회 비밀번호는 없습니다.** 복구는 대표 본인만 합니다.

1. 두 번째 기기가 있으면 그것으로 들어갑니다. 들어간 뒤 `/mfa` 에서 새 휴대폰을 등록합니다.
   잃어버린 휴대폰의 등록은 대시보드에서 지웁니다 (아래 2번의 방법).
2. 두 번째 기기도 없으면 — Supabase 대시보드(대표 계정)에서:
   Authentication → Users → 본인 계정 → **MFA factors 에서 잃어버린 수단 삭제**.
   지우면 「등록 없음」이 되어 코드 없이 들어갑니다. 다시 1번(등록)부터 합니다.
3. 대시보드에서 지우기 어려우면 `sql/초안_1118/관리자_2단계_되돌리기.sql` 을 돌립니다.
   관리자 판정이 SQL 전으로 돌아갑니다 (등록은 남습니다 — 화면은 계속 코드를 묻습니다. 화면까지 풀려면 2번).
4. 다른 사람이 쓴 흔적이 있는지 `/admin/access` 기록을 봅니다.

**대시보드 로그인은 이것과 다른 문입니다.** 대시보드 계정의 2단계 인증은 Supabase 쪽 설정이고,
그 예비 수단(복구 코드)은 대표가 따로 보관합니다. 이 앱의 등록이 그 문을 대신하지 않습니다.
