# 손확인 29곳 — 한 바퀴 체크리스트 (세중님이 채우십니다)

**왜 이것을 먼저 하나** — 지금 `hand_check` 29곳 가운데 **사람이 본 곳이 0곳**입니다.
그래서 「손 등록 길을 만들까(ⓐ) · 담당자 자리를 쓸까(ⓒ)」를 고를 **근거가 없습니다.**
공고가 한두 건이면 손으로 올리는 것이 싸고, 여러 곳에 꾸준히 있으면 길을 만드는 값이 있습니다.

```
채우는 칸   ⓐ 지금 우리 직군 공고 수   ⓑ 최근 3개월 공고 수   ⓒ 확인일
적는 법     없으면 0 · 못 열면 「못 엶」 · 채용 쪽이 없으면 「없음」
빠른 길     /admin/hand 에서 「사람이 봤다」를 눌러 두시면 마지막확인이 함께 적힙니다
            (창구 admin_hand_check_seen · 메모 칸에 ⓐ/ⓑ 를 적으시면 됩니다)
```
