## 복주회복병원 — 날짜를 왜 못 집었나 (`줄안의날` 은 **고치지 않았습니다**)


원문 창 (⏎ 는 줄바꿈) —

```html

  <li class="no">NO</li> <li class="title">제목</li> <li class="name">작성자</li>

    <li class="name">복주회복병원</li>
    <li class="date">2026-10-23</li>                         ← 날짜는 +231
    <li class="count">65</li>
  </a>

```

날짜 글자 자리 —

```
2026-10-23 — 자리 42308 (제목에서 **+231자**) · 앞 60자 「… <li class="name">복주회복병원</li> <li class="date">」
2022-08-12 — 자리 42631 (+554자)        2022-07-15 — 자리 42965 (+888자)
2026-10-23 — 자리 43305 (+1228자)       2026-09-22 — 자리 43612 (+1535자)
줄안의날 이 낸 값 — (없음)
```

**까닭이 숫자로 드러났습니다.** `줄안의날` 의 창은
`t.slice(앞, 자리 + 뒤끝)` 이고, 여기서 `뒤끝` 은 **자리 뒤 첫 `</tr>`·`</li>` 까지**
입니다. 이 쪽은 `<a>` 가 `<li>` 칸들을 **품고** 있어서, 자리 뒤 첫 `</li>` 가
**+92자**(「공지」 칸의 끝)입니다. 날짜는 **+231자**에 있으니 **창이 날짜 앞에서
끊깁니다.** 그래서 18줄 전부 날짜가 비었습니다 (목록 제목에는 날짜 글자가 보이는데
못 집는 것이 이것 때문입니다).
