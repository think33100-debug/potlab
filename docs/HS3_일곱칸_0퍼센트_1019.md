칠곡경북대·상주적십자·포항세명기독·인천적십자·한일·백제·고신대복음·분당제생·

API 출처(워크넷·알리오·나라일터·클린아이)가 올린 것이고, **병원 홈페이지
긁기는 한 칸도 안 올립니다.** 1층 지원자격이 44.8% 에 머무는 까닭이 이것입니다.

## 까닭 — 칸을 뽑는 코드가 **연결돼 있지 않습니다**

```
collect-hosp.mjs 가 상세를 엽니다            ○ 엽니다 (하루 사이트당 50건까지)
그 본문으로 무엇을 하나                      `본문직군(글)` 으로 **직군만** 가립니다
본문을 저장하나                              **안 합니다**
칸을 뽑나                                    **안 뽑습니다**
```

DB 로도 확인했습니다 — HS·HS3 우리 직군 공고 100건의 `detail` 에 든 열쇠는
**`기관홈` 하나뿐**입니다. `뽑은값` 도 `원문` 도 없습니다.

그런데 **칸을 뽑는 함수는 이미 있습니다** — `tools/공고문읽기.mjs` 의
`칸뽑기(md, 합친글)`. 첨부(hwp·pdf)에는 쓰고 있고 **상세 본문에는 안 씁니다.**
`collect-hosp.mjs` 는 그 파일에서 `본문직군` 만 가져다 씁니다(44행).

지침 6절의 그 자리입니다 — 「코드가 저장소에 있어도 아무도 `import` 하지
않으면 없는 기능입니다」.

## 그래도 **그대로 연결하면 안 됩니다**

위 표의 굵은 글씨를 보십시오 — **지원자격 값이 다음 꼭지까지 넘어갔습니다.**

```
광주씨티    「- 해당 면허증 소지자 / 3. 전형 절차 / 1) 접수: 방문접수 또는」
대구보건대  「: 작업치료사 면허증 소지자 / 3. 우대사항 / 가. 보수교육 이수」
```

`칸뽑기` 는 **첨부(마크다운·표)용**으로 만든 것입니다. HTML 을 태그만 걷어
넘기면 꼭지 경계(`3.`·`가.`)를 못 끊습니다. 이대로 채우면 회원 상세 화면의
「지원자격」 칸에 전형 절차가 섞여 보입니다.

**세중님 원칙 — 「틀린 값 0 이 채움률보다 먼저」.** 그래서 연결 전에 다듬기가
필요합니다.
