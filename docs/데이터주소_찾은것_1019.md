# JS 껍데기 사이트 — 뒤에서 부르는 데이터 주소 (2026-10-19)

세중님 지시 — 「조사할 때만 이 컴퓨터 브라우저로 네트워크 기록 → ajax/JSON
주소를 찾아 수집기는 그 주소를 fetch. 두 번 실패하면 멈춤.」

## 먼저 — **브라우저 길이 막혔습니다**

이 컴퓨터 Chrome 이 **http 사이트를 열지 않습니다.** 조사 대상 세 곳을 열어
보니 전부 「Frame is showing error page」였고, https 인 울산대만 열렸습니다.

```
http://dbjeil.co.kr/bbs/board.php?bo_table=5_5       ✗ 에러 페이지
http://www.dbjeil.co.kr/bbs/board.php?bo_table=5_5   ✗ 에러 페이지
http://hjhospital.co.kr/bbs/notice.php               ✗ 에러 페이지
https://www.uuh.ulsan.kr/main/main.asp               ○ 열림 (내용은 아래)
```

그래서 **다른 길로 갔습니다 — HTML 과 그 안의 script 를 받아 주소가 적힌
자리를 읽었습니다.** 짐작이 아니라 **코드에 적힌 글자**입니다. 네트워크
기록과 같은 것을 얻었고, 오히려 호출부의 파라미터까지 원문으로 봤습니다.

## 1. 울산대학교병원 — **주소가 낡았고, 채용은 딴 호스트입니다**

### ㉠ `hira_org.hosp_url` 의 경로가 죽었습니다

```
hira_org 값   http://www.uuh.ulsan.kr/main/main.asp
브라우저로 열어 보니  「에러 페이지 오류 / ※ 접속오류의 원인은 다음과 같습니다.
                       1. 접속하는 페이지가 없는 경우 …」
루트로 가면   https://www.uuh.ulsan.kr/ → https://www.uuh.ulsan.kr/intro/
              HTTP 200 · 16,118바이트 · 제목 「울산대학교병원」
```

어제 「http 는 소켓이 끊기고 https 는 200·1,687바이트·제목 없음」이라고
적었는데, **그 1,687바이트가 이 에러 페이지였습니다.** 「JS 껍데기」가 아니라
**없는 경로**였습니다. 바로잡습니다.

### ㉡ 채용은 **포트 8443 의 딴 사이트**입니다

본 도메인 대문에서 찾았습니다 — 「채용사이트」 링크.

```
https://www.uuh.ulsan.kr:8443/uuhrecruit/      제목 「울산대학교병원 채용」 · 17,500바이트
  그 안의 「채용공고/입사지원」 →
https://recruit.uuh.ulsan.kr:8443/uuhrecruit/  제목 「UUH 채용시스템」 · 2,542바이트
```

### ㉢ 그런데 **긁을 수 없습니다 — Vaadin 입니다**

```
본문 전체   「UUH 채용시스템 … You have to enable javascript in your browser
            to use an application built with Vaadin.」
script      ./VAADIN/vaadinBootstrap.js
```

Vaadin 은 **서버가 화면을 들고 있는** 틀입니다. 목록을 받으려면 세션과 동기화
토큰을 주고받는 UIDL 통신을 흉내내야 합니다 — **주소 하나를 fetch 하는 것으로는
안 됩니다.** 「ajax 주소를 찾아 그 주소를 fetch」가 통하지 않는 갈래입니다.

→ **「손으로 확인할 곳」** 으로 보냅니다. 1층 **상급종합**이라 빠뜨리면 안 되는
곳입니다 (사각지대 상급종합 2곳 중 하나).

## 2. 화성중앙종합병원 — **주소와 꼴을 찾았습니다. 다만 지금 글이 0건입니다**

HTML 안에 ajax 호출부가 그대로 있었습니다.

```js
$(function(){ get_List(); });
function get_List(){
  $.ajax({
    type : "post",
    url : "/_Proc/notice_list_proc.php",
    dataType : 'json',
    data: $('#frm').serialize(),
    success : function(data) {
      if (data.success) { if (data.json.TotalCount != 0) {
        var totalcount = data.json.TotalCount;
        $.each(data.json.list, function(i, item) { … item.RNUM … item.valid … })
```

`#frm` 의 입력값도 원문으로 봤습니다.

```html
<form id="frm" name="frm" method="post" onsubmit="search(); return false;">
  <input type="hidden" name="pageNo"   value="1"/>
  <input type="hidden" name="pagesize" value="10"/>
  <input type="hidden" name="seq"      value=""/>
  <input type="hidden" name="rnum"     value=""/>
  <input type="text"   name="search_key" …>
```

**실제로 두드려 봤습니다** (POST · `Content-Type: application/x-www-form-urlencoded`).

```
pageNo=1&pagesize=10&seq=&rnum=&search_key=    → HTTP 200 · 68바이트
pageNo=1&pagesize=100&seq=&rnum=&search_key=   → HTTP 200 · 68바이트
받은 것  {"json":{"list":[],"pagination":"","TotalCount":"0"},"success":true}
```

**주소는 맞습니다** — JSON 을 제대로 돌려줍니다. `TotalCount` 가 `"0"` 이니
**그 게시판에 글이 0건**입니다. 긁을 수 없는 것이 아니라 **지금 올라온 것이
없습니다.**

★ 설정을 넣을 값은 있습니다 — 새 공고가 올라오면 잡힙니다. 다만 **응답이
HTML 이 아니라 JSON** 이라 지금 `cfgs/*.json` 의 `type: "html"` 꼴로는 안
됩니다. `type` 을 하나 더 만들 일이라 **세중님 승인을 받고 하겠습니다.**

덤으로 알게 된 것 — 이 사이트는 외부 솔루션을 씁니다
(`form action: http://ursmart43.hmandoo.co.kr/home_comm/board_all_list.htm`).
같은 솔루션을 쓰는 병원이 더 있으면 설정 하나로 여러 곳을 덮을 수 있습니다.

## 3. 동부제일병원 — **채용 게시판이 없습니다**

```
대문의 채용 링크   「채용서류 반환에 대한 고지」 → /bbs/board.php?bo_table=5_5
그 쪽의 <title>    「채용서류 반환에 대한 고지 | 동부제일병원 | 종합병원」
wr_id              **0개**  ← 그누보드인데 글 번호가 하나도 없습니다
ajax·fetch 자리    **0개**  (js/common.js 20,616바이트 · js/wrest.js 11,096바이트 전부 봄)
```

목록이 JS 로 오는 것이 **아닙니다.** 대문의 「채용정보」가 곧 그 고지 글
하나를 가리키고, 그 글이 게시판 전부입니다. **줄 꼴을 정할 근거가 없습니다** —
글이 없는 목록으로 `row`·`title`·`link` 규칙을 쓰면 짐작이 됩니다 (지침 3절).

→ **「손으로 확인할 곳」** 으로 보냅니다.
