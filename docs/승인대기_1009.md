## ⑧ `notices` 저장소 규칙 셋 — **첨부가 이것 없이는 안 됩니다**

**무엇** — 공고 첨부를 담을 버킷 `notices` 는 2026-10-09 밤에 만들었는데,
**규칙(RLS)이 하나도 없어서 지금은 아무도 못 씁니다.** 화면은 다 올라갔고
파일을 고르면 「못 올렸어요」가 뜹니다. 아래 셋을 올리면 바로 됩니다.

**왜 미뤘나** — RLS 정책은 권한 변경이라 21시 이후에 올리지 않았습니다.

```sql
/* 올리기 — 담당자만. 자기 공고·자기 회차 폴더에만 */
create policy "공고 첨부는 담당자가 올립니다" on storage.objects for insert
to authenticated with check (
  bucket_id = 'notices'
  and (
    /* 채용 — 폴더 이름이 공고 번호입니다 */
    exists (select 1 from public.job_posts j
             where j.id = (storage.foldername(name))[1]
               and j.source = 'BIZ'
               and public."채용담당자인가"(j."기관번호"))
    or
    /* 교육 — 폴더 이름이 '교육<회차번호>' 입니다 */
    exists (select 1 from public."교육회차" s
             where '교육' || s."회차id" = (storage.foldername(name))[1]
               and public."교육담당자인가"(s."과정id"))
  ));

/* 보기 — **로그인한 사람만.** 비회원은 경로도 못 받고(첨부하나) 파일도 못 엽니다 */
create policy "공고 첨부는 회원이 봅니다" on storage.objects for select
to authenticated using (bucket_id = 'notices');

/* 바꾸기 — 올리기와 같은 기준 (같은 이름으로 다시 올릴 때) */
create policy "공고 첨부는 담당자가 바꿉니다" on storage.objects for update
to authenticated using (
  bucket_id = 'notices'
  and (
    exists (select 1 from public.job_posts j
             where j.id = (storage.foldername(name))[1]
               and j.source = 'BIZ'
               and public."채용담당자인가"(j."기관번호"))
    or exists (select 1 from public."교육회차" s
             where '교육' || s."회차id" = (storage.foldername(name))[1]
               and public."교육담당자인가"(s."과정id"))
  ));
```

**되돌리기** — 규칙 셋을 다시 떼면 버킷이 잠깁니다 (지금 상태로 돌아옵니다).
**시험** — 마스터를 「채용담당자」 페르소나로 두고 `/biz` 에서 PDF 한 장.
그다음 「비회원」 페르소나로 바꿔 같은 공고를 열어 **첨부 칸이 아예 안 보이는지**.

**지우기 규칙은 일부러 안 만듭니다** — 첨부 치우기는 줄에 `지운때`만 찍고
파일은 남깁니다. 파일을 실제로 지우는 것은 밤정리 몫이고, 그건 ② 와 함께 정합니다.
