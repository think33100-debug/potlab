## ⑧ `notices` 저장소 규칙 셋 — ✅ **2026-10-10 에 올렸습니다**

**승인받아 올렸습니다** (세중님 승인 · 마이그레이션 `2026_10_09_8_notices_저장소규칙`

올린 뒤 **두 가지를 고쳐야 돌았습니다.** 적어 둡니다.

1. **정책 본문은 부르는 사람 권한으로 돕니다.** `authenticated` 는

   가리켰습니다 (떼고 다시 만들지 않았습니다 — 그래야 승인 창이 안 뜹니다).

   한글이라 **한 장도 안 올라갔을** 자리입니다. 같은 뿌리로 `proofs`(재직 증빙)와
   `ad-images`(광고 배너)도 막혀 있었습니다. 셋 다 고쳤습니다 (커밋 `500d24c`).

**확인** — `node tools/첨부시험.mjs` 가 22가지 전부 ○. 보내는 쪽과 **같은 길**
(anon 열쇠 + 회원 토큰 → `/storage/v1`·`/rest/v1/rpc`)로 확인합니다. SQL 로
`storage.objects` 에 넣어 보는 것은 버킷의 형식·크기 제한을 건너뜁니다 (지침 12).

**남은 것** — 캡처용으로 첨부 **둘**(id 7·8)을 `BIZ000005` 에 남겨 뒀습니다.

## ㉑-옛 수집기 창구 권한 걷기

**코드는 이미 올렸습니다** (2026-10-11 · 커밋 `9106739`). 수집기 열넷이
`service_role` 로 창구를 부릅니다. **아직 떨어뜨리지 않는 꼴**이라
(service 가 없으면 anon 으로) 지금은 둘 다 됩니다.

서버 크론 쪽은 **확인했습니다** — 워크넷을 service 열쇠로 돌려 241건을
담았습니다. **GitHub Actions 쪽(AL2·CE2·JF)이 한 바퀴 도는 것을 본 뒤**
아래를 돌립니다.

```sql
revoke execute on function public.collect_put(text, text, jsonb)
  from public, anon, authenticated;
revoke execute on function public.collect_beat(text, text, jsonb)
  from public, anon, authenticated;
revoke execute on function public."판정남기기"(text, text, jsonb)
  from public, anon;
grant execute on function public.collect_put(text, text, jsonb)  to service_role;
grant execute on function public.collect_beat(text, text, jsonb) to service_role;
grant execute on function public."판정남기기"(text, text, jsonb)   to service_role;
```

**인수 꼴을 돌리기 전에 확인하십시오** (`pg_get_function_identity_arguments`).

**왜** — `anon` 은 브라우저에 내려가는 공개 값입니다. 창구가 anon 에게
열려 있으면 `p_secret` 하나만 새도 아무나 공고를 넣을 수 있습니다.

**되돌리기** — `grant execute … to anon;` 한 줄씩. 코드가 아직 anon 으로
떨어질 수 있어서 **바로 되돌아옵니다.**

**빠진 것 하나** — `제목부서(text)` 와 `제목직군(text)` 에 **PUBLIC 이
붙어 있습니다**(`=X/postgres`). 순수 계산 함수라 새는 것은 없지만,
지침 6-3 대로라면 걷는 것이 맞습니다. 같이 보실 때 함께.
