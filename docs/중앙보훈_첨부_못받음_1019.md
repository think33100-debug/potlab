# 중앙보훈병원 첨부 — 맨손 `fetch` 로는 못 받습니다 (2026-10-19)

세중님 5번 「중앙보훈 fileKey — 어디서 채워지나 근거와 함께. 두 번 실패하면 멈춤」.

## 결론 (아침에 쓴 것 — 아래 덧붙임을 함께 보십시오)

**수집기(맨손 `fetch`)로는 못 받습니다.** 세 길을 두드렸고 셋 다 실패했습니다.
**손으로 확인할 곳** 목록으로 넘기는 것이 맞습니다 (CLAUDE.md — 「전부 자동일
필요는 없다. 빠지지 않는 것이 자동화보다 중요하다」).

## 먼저 — 「fileKey 가 어디서 채워지나」

채워지는 자리는 **이미 코드에 있습니다.** 다만 **아무도 안 씁니다.**

```
tools/hosp/hs_files.js:67-72   fn_fileDownload('<해시32>','<계열>') 을 읽어
                               /common/nttFileDownload.do?fileKey=…&bbsSysId=…
                               을 만들고 `받는법: { 꼴:'GET', 쿠키:'상세' }` 를 답니다
tools/hosp/hs_files.js:148·164 그 `받는법` 을 첨부 줄에 실어 돌려줍니다

tools/collect-hosp.mjs:568     첨부모음.더하기({ job_id, kind, name, url })
                               ← ★ **`받는법` 을 안 넘깁니다. 여기서 사라집니다**
tools/첨부담기.mjs:129         더하기({ job_id, kind, name, url }) — 받을 자리가 없습니다
```

`grep -rn 받는법` 으로 찾은 곳이 **네 군데**이고, 그중 쓰는 곳은 **0군데**입니다
(hs_files 의 자기점검만 봅니다). CLAUDE.md 6절 그대로입니다 —
「코드가 저장소에 있어도 아무도 `import` 하지 않으면 **없는 기능**입니다」.

**그런데 `받는법` 을 이어 붙여도 안 됩니다** — 아래가 그 까닭입니다.

## 두드려 본 세 길 (전부 응답 원문을 적습니다)

목록 → 상세를 같은 쿠키(`JSESSIONID`)로 열고, 상세에서 집은 그 공고의
`fileKey` 로 받았습니다. 공고 — `nttSn=187161` ·
`fn_fileDownload('983668d1a3e281da9945ceeb14c26a0b', 'seoul')`

| 길 | 요청 | 응답 |
|---|---|---|
| ① | `GET /common/nttFileDownload.do?fileKey=…&bbsSysId=seoul` **쿠키 있음** | HTTP 200 · **0바이트** · `application/octet-stream` |
| ② | 같은 주소 **쿠키 없음** | HTTP 200 · **0바이트** |
| ③ | `GET /common/nttFileDownloadForSynap.do?synap=Y&fileKey=…` | HTTP 200 · **177자 HTML** — 「**유효하지 않은 요청입니다.**」 |

③ 은 짐작이 아닙니다. 상세 쪽의 `fileView()` 를 읽어 찾았습니다 —

```js
function fileView(dwldUrl, bbsSysId) {
  var fileKey = dwldUrl;
  $.ajax({ type: "POST", url: "/common/nttFileCheckForSynap.do",
           data: { fileKey: fileKey, bbsSysId: bbsSysId },
    success: function(data) { var jsonData = JSON.parse(data);
      if (jsonData.resultAt == 'Y') {
        var dwUrl = jsonData.urlPath + '/common/nttFileDownloadForSynap.do?synap=Y&fileKey=' + fileKey;
        … $('#synap').attr('target',"_blank").submit(); } … } });
};
```

그 앞 ajax 는 **됩니다** —

```
POST /common/nttFileCheckForSynap.do   (fileKey=… & bbsSysId=seoul)
  200 · {"msg":"","resultAt":"Y","urlPath":"https://www.bohun.or.kr"}
```

「`resultAt: Y`(그 파일 있습니다)」까지는 서버가 답해 줍니다. **받는 단계에서만
막습니다.**

## 2026-10-14 에는 658,469바이트가 왔는데요

**쿠키만으로는 안 됩니다** — 2026-10-19 에 쿠키를 들고 다시 재서 확인했습니다.
브라우저 안에만 있는 무엇(폼 토큰·referer 검사·세션 상태 중 하나)이 더 있습니다.
