## ㉦ [승인대기] 제목에 **남의 진료과**가 붙는 것 — `제목부서()` 좁히기 (2026-10-28 세중님 4번ⓐ)

위험  낮음 — 바뀌는 회원 화면 공고 **2건** · 사람이 넣은 부서는 **0건** 안 건드립니다

```
증상    「경기도의료원 수원병원 **마취통증의학과** 작업치료사 계약직」 (HS102260084)
까닭    우리가 부서를 지어 붙인 것이 **아닙니다.** `제목만들기행()` 이
        `제목부서(j.title, j.detail->>'부서')` 로 **원문 제목에서** 뽑습니다.
        그 함수 낱말 목록에 **「의학과」가 통째로** 들어 있습니다 —
          치료실|치료팀|치료센터|재활팀|재활실|**의학과**|의학팀|파트|지원팀
        통합공고(한 공고에 여러 직군)는 원문 제목이 **맨 앞 자리**부터 적으므로,
        마취통증의학과·직업환경의학과처럼 **우리 직군과 무관한 진료과**가 올라옵니다
```

### 전문 (올릴 SQL)

```sql
create or replace function public."제목부서"(p_title text)
returns text language sql immutable as $$
  select nullif(btrim((
    select m[1] from regexp_matches(coalesce(p_title,''),
      '([가-힣A-Za-z0-9]*(?:치료실|치료팀|치료센터|재활팀|재활실|재활의학과|의학팀|파트|지원팀))') m
     limit 1)), '')
$$;
-- ★ 바뀐 것은 「의학과」 → 「재활의학과」 한 낱말입니다 (재활의학과는 우리 자리입니다)
-- ACL — 전 ACL 을 찍어 글자까지 같게 되돌립니다 (지침 6-2a). 인수가 그대로라
--       create or replace 이고 권한은 유지됩니다
```

**마른 실행** — `node tools/제목부서_마른_1028.mjs` (2026-10-28)

```
회원 화면 286건 · 부서가 붙는 것 25건 · **바뀌는 것 2건** · 그중 사람이 넣은 것 0건
  HS102260084         작업치료사  마취통증의학과       → (없음)
  WNK130042610270042  물리치료사  용호베스트마취통증의학과 → (없음)  ← 기관 이름과 겹쳤던 것
```
