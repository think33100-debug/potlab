## A. 기관 이름 = **근무처 이름** (법인 이름 아님)

### A-1 워크넷 상세에 근무처·사업장명 칸이 **없습니다**

`detail` 에 담긴 **열쇠 열여덜 개를 전부** 세어 봤습니다 (워크넷 출처 공고) —

```
연봉 799 · 경력 482 · 근거 482 · 급여 482 · 기관종별근거 482 · 모바일 482 ·
사업자번호 482 · 시설구분 482 · 업종 482 · 직종이름 482 · 직종코드 482 ·
출처 482 · 휴일 482 · 접수방법 461 · 지원자격 451 · 기관홈 336 ·
마감메모 251 · 기관홈페이지 68
```

「근무·사업장·사업체·지점·점·기관·회사·업체·부서·장소」로 훑으면 걸리는 것은
**`기관종별근거`·`기관홈`·`기관홈페이지`** 셋뿐이고, **근무처 이름 칸은 없습니다.**
(우리가 상세에서 담는 칸이 이것들입니다. 워크넷 상세 응답 자체의 59개 항목 가운데
사업장 이름은 `company`·`busino` 꼴로 오지만 **지금 담고 있지 않습니다** — 담는 쪽을
고치는 것은 **수집기**라 동결 자리입니다.)

→ **A-2 길로 갑니다** — 원문 제목에서 근무처 이름을 꺼내고, 법인명과 **다를 때만** 씁니다.

### A-2 원문 제목 앞머리에 근무처 이름이 들어 있습니다

제목 앞머리 `[…]` 가 있는 회원 화면 공고가 **25건**이고, 그 안이 다섯 갈래입니다.

| 갈래 | 보기 | 어떻게 쓸까 |
|---|---|---|
| **근무처 이름** | `[행복한요양원 분당점]`(기관 「주식회사 분당시니어」) · `[우림요양원]`(기관 「주식회사 우림홀딩스」) · `[차오름요양원]` · `[계양효요양원]` · `[연세재활요양원]` · `[경희재활요양원]` · `[예덕주간보호센터]` · `[본점3관]`(기관 「주식회사 삼성케어」) | **기관 이름 자리로** (A) |
| **지역** | `[구포]` · `[부산]` · `[오산]` · `[인천 청학동]` · `[구미 옥계]` · `[연산역]` · `[동래역부근]` · `[ 온라인 ]` | **제목에서 뺍니다** (D) |
| **부서** | `[통합재활팀]` · `[건진팀]` · `[일반-신촌]` | 지금처럼 부서 자리 |
| **법인** | `[안동의료재단]` · `[경진의료재단]` · `[대전보훈병원]` | **뺍니다** (기관 이름에 이미 있거나 법인명입니다) |
| **그 밖** | `[주4.5일]` · `[물리치료사]` · `[작업치료사]` | **뺍니다** (조건·직군입니다) |

★ 지금은 이 다섯이 **전부 「산하 기관」으로 제목에 붙습니다**. 그래서
「연세대학교의과대학세브란스병원 **일반-신촌** 물리치료사 계약직」 ·
「바른아동발달연구소 **작업치료사** 작업치료사 정규직」 같은 제목이 나옵니다.

## B. 인턴 ≠ 정규직

```
지금 회원 화면 고용형태 — 정규직 184 · 계약직 98 · (빈칸) 7
원문에 인턴이 있는데 고용형태가 인턴이 아닌 줄 — **1건**
  306248 [AL2] 고용형태 (빈칸)
    원문   [대전보훈병원] 정규직(약무직(약사), 업무지원직(완화의료)) 및 계약직(…
    지금   한국보훈복지의료공단 대전보훈병원 물리치료사 **정규직** 채용공고
```

★ **고용형태 칸은 비어 있는데 제목에 「정규직」이 붙었습니다.** `고용형태보임행()` 이
빈 칸일 때 원문에서 글자를 줍는 꼴입니다 — 그 공고의 우리 직군 자리가 정규직인지는
공고문을 봐야 합니다. **제목이 비어 있지 않은 값을 지어 붙이는 자리**라 DB 자리입니다.
세중님 캡처의 「체험형 인턴」 노란 딱지는 **그 딱지를 고용형태 값으로 옮기는** 일이고,
값이 「체험형 인턴」·「채용형 인턴」·「인턴」이면 **정규직으로 안 적습니다.**

## C. 한자·특수문자

```
기관명에 한자 2 · 제목에 한자 2 · 기관명에 ★※【】 0 · 제목에 0 · 기관명에 (주)·㈜ 꼴 5
  WNK130052610210031  삼성(杉晟)센텀정형외과의원
  WNK150112609110004  계양효(孝)요양원
     → 지금 제목: 「계양효(孝)요양원 **계양효요양원** 작업치료사·물리치료사 정규직 채용공고」
       (기관 이름과 산하 이름이 같은 말인데 한자 때문에 두 번 적힙니다)
```

고칠 것 — 괄호 속 한자(`(杉晟)`·`(孝)`) 떼기 · `㈜` 를 법인 표기 목록에 넣기 ·
`★※[]【】` 떼기 · 공백 정리 · **떼서 두 글자 이하면 원문 유지**.
→ 「삼성센텀정형외과의원」 · 「계양효요양원」 (그러면 C 가 D·A 의 겹침도 함께 풉니다)

## D. 제목에 지역 금지

위 A-2 표의 **지역 갈래 8건**이 대상입니다. 기관 이름의 일부인 지역
(「대구광역시 중구 치매안심센터」)은 **그대로 둡니다** — `제목기관()` 이 내는 값이라
`제목산하()` 와 자리가 다릅니다.

## E. 「지원하러 가기」 차례 — ① 채용 게시판 → ② 기관 홈페이지 → ③ 원문

```
회원 화면 289건 — 채용게시판 칸 **0건** · 기관홈 칸 **있음(detail.기관홈)** ·
                 원문 주소 **289건** · 접수방법에 「자사채용사이트」 말 **0건**
기관 표에 홈페이지가 있는 공고 — **세어 보니 0건** (기관 표의 홈페이지 칸이 비어 있습니다)
```

★ **지금은 ①도 ②도 담긴 데가 없습니다.** 「채용 게시판」은 `tools/긁기/채용게시판찾기.mjs`
가 찾아 둔 것이 **181곳**이지만 그 주소가 **공고의 `detail` 에는 안 들어 있습니다**
(사이트표에만 있습니다). 그래서 차례를 바꾸려면 **먼저 그 주소를 공고 쪽에 이어야**
합니다 — 그건 창구·수집기 자리입니다.

→ 지금 할 수 있는 것 — 차례를 **코드로 먼저 세우고**(①②가 비면 ③으로), 「원문 보기」
작은 줄을 **항상** 그립니다. 그러면 주소가 이어지는 대로 ①②가 자동으로 앞섭니다.
