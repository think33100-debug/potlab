## A. 기관 이름 = **근무처 이름** (법인 이름 아님)

### A-1 워크넷 상세에 근무처·사업장명 칸이 **없습니다**

`detail` 에 담긴 **열쇠 열여덜 개를 전부** 세어 봤습니다 (워크넷 출처 공고) —

```
연봉 799 · 경력 482 · 근거 482 · 급여 482 · 기관종별근거 482 · 모바일 482 ·
사업자번호 482 · 시설구분 482 · 업종 482 · 직종이름 482 · 직종코드 482 ·
출처 482 · 휴일 482 · 접수방법 461 · 지원자격 451 · 기관홈 336 ·
마감메모 251 · 기관홈페이지 68
```

「근무·사업장·사업체·지점·점·기관·회사·업체·부서·장소」로 훑으면 걸리는 것은
**`기관종별근거`·`기관홈`·`기관홈페이지`** 셋뿐이고, **근무처 이름 칸은 없습니다.**
(우리가 상세에서 담는 칸이 이것들입니다. 워크넷 상세 응답 자체의 59개 항목 가운데
사업장 이름은 `company`·`busino` 꼴로 오지만 **지금 담고 있지 않습니다** — 담는 쪽을
고치는 것은 **수집기**라 동결 자리입니다.)

→ **A-2 길로 갑니다** — 원문 제목에서 근무처 이름을 꺼내고, 법인명과 **다를 때만** 씁니다.

## B. 인턴 ≠ 정규직

```
지금 회원 화면 고용형태 — 정규직 184 · 계약직 98 · (빈칸) 7
원문에 인턴이 있는데 고용형태가 인턴이 아닌 줄 — **1건**
  306248 [AL2] 고용형태 (빈칸)
    원문   [대전보훈병원] 정규직(약무직(약사), 업무지원직(완화의료)) 및 계약직(…
    지금   한국보훈복지의료공단 대전보훈병원 물리치료사 **정규직** 채용공고
```

★ **고용형태 칸은 비어 있는데 제목에 「정규직」이 붙었습니다.** `고용형태보임행()` 이
빈 칸일 때 원문에서 글자를 줍는 꼴입니다 — 그 공고의 우리 직군 자리가 정규직인지는
공고문을 봐야 합니다. **제목이 비어 있지 않은 값을 지어 붙이는 자리**라 DB 자리입니다.
세중님 캡처의 「체험형 인턴」 노란 딱지는 **그 딱지를 고용형태 값으로 옮기는** 일이고,
값이 「체험형 인턴」·「채용형 인턴」·「인턴」이면 **정규직으로 안 적습니다.**

```

  WNK130052610210031  삼성(杉晟)센텀정형외과의원
  WNK150112609110004  계양효(孝)요양원

       (기관 이름과 산하 이름이 같은 말인데 한자 때문에 두 번 적힙니다)
```

고칠 것 — 괄호 속 한자(`(杉晟)`·`(孝)`) 떼기 · `㈜` 를 법인 표기 목록에 넣기 ·
`★※[]【】` 떼기 · 공백 정리 · **떼서 두 글자 이하면 원문 유지**.
→ 「삼성센텀정형외과의원」 · 「계양효요양원」 (그러면 C 가 D·A 의 겹침도 함께 풉니다)
