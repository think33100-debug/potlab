## 2. ★ **아직 아무도 한 바퀴를 안 돌았습니다**

```

```

29곳 다 **마지막확인**(기계가 두드려 본 날)만 있고 **사람이본날**이 비어 있습니다.
오픈까지 한 번은 돌아야 합니다 — 특히 상급종합 둘(강북삼성·울산대)은 아침 메일에

관리자 화면에 「사람이 봤다」를 적는 자리는 **있습니다** —
`web/app/admin/hand/page.tsx` 가 `admin_hand_check_seen` 창구를 부릅니다.

## 3. ★★ **「관리자 손 등록」 흐름은 아직 없습니다**

`docs/손확인_기관.md` 9줄에 이렇게 적혀 있습니다 —

> 공고가 있으면 **관리자 화면에서 손 등록** 합니다 (source 는 손등록)

**그 자리가 없습니다.** 저장소를 전수로 찾았습니다 —

```
「손등록」이 나오는 곳      docs/손확인_기관.md 그 한 줄뿐
collect_source 의 출처     AL·AL2·AL2C·ALIVE·CE·CE2·EDU·GJ·GJ2·HS·HS2·HS3
                           ·JF·ND·ND2·PUSH·RIVAL·VMS·WN·WN2  — **손등록 없음**
관리자 화면 web/app/admin/jobs   admin_decide · 보류함마감정리 뿐 (공고를 **만드는** 창구 없음)
```

즉 **29곳에서 공고를 찾아도 회원 화면에 올릴 길이 없습니다.** 세중님께 묻습니다 —

```
ⓐ 오픈 전에 만듭니다        관리자 화면 + 출처 「손등록」 줄 + 공고 만드는 창구
                            → DB·창구는 10/31 동결 전, 화면은 11/1~11/6 토막
ⓑ 오픈 뒤로 미룹니다        29곳 공고는 오픈 때도 회원 화면에 없습니다 (지금도 없습니다)
ⓒ **담당자 자리를 그대로 씁니다**  이미 있고 **오늘 끝까지 시험했습니다** (아래 4절)
                            관리자가 그 기관 담당자 자격을 자기에게 주고 공고를 올립니다
```

제 생각은 **ⓒ** 입니다 — 새로 만들 것이 없고, 공고에 「담당자가 올림」 꼬리표가
남아 회원에게도 솔직합니다. 다만 공고 수가 적으면(29곳 가운데 몇 곳) 손이 많이 갑니다.
