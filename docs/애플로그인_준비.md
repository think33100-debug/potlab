# Apple 로그인 — 세중님이 누르실 것

기준 시각 **2026-10-11 17:30 (한국시간)**

> **열쇠 값은 이 글에도, 대화에도 붙이지 마십시오.** 아래 ④ 에서 받는
> `.p8` 파일과 값 넷은 **세중님이 Supabase 대시보드에 바로 넣으시면 됩니다.**
> 제가 볼 일이 없습니다.

왜 하나 — 애플 심사 **4.8** 입니다. 카카오·네이버 같은 다른 로그인이 있으면
**Apple 로그인도 있어야** 심사를 지납니다.

**코드 쪽은 다 돼 있습니다** (2026-10-11). `/login` 의 Apple 단추가 이어져
있고, 가입 막는 훅도 Apple 을 안 막습니다. 아래 ①~⑤ 를 마치면 **배포 없이
바로** 됩니다.

---

## 먼저 — 애플 개발자 계정

- https://developer.apple.com → 가입 (**연 99 달러**)
- 승인에 하루~이틀 걸립니다. **이것부터** 하십시오

---

## ① App ID 만들고 「Sign in with Apple」 켜기

```
developer.apple.com → 오른쪽 위 Account → 왼쪽 Certificates, IDs & Profiles
→ 왼쪽 Identifiers → 파란 + 단추
→ App IDs 고르고 Continue → App 고르고 Continue
   Description   POTJOB
   Bundle ID     Explicit · kr.co.potjob  (아무거나 좋지만 뒤에서 또 씁니다)
→ 아래 목록에서 **Sign in with Apple** 에 체크
→ Continue → Register
```

## ② Services ID 만들고 **돌아올 주소** 넣기

웹(브라우저)에서 쓰는 것은 App ID 가 아니라 **Services ID** 입니다.

```
같은 Identifiers 화면 → + 단추
→ **Services IDs** 고르고 Continue
   Description   POTJOB 웹
   Identifier    kr.co.potjob.web      ← 이것이 Supabase 의 **Client ID** 입니다
→ Continue → Register
→ 만든 줄을 다시 눌러 들어가서
   **Sign in with Apple** 에 체크 → 옆의 **Configure** 단추
   Primary App ID     ① 에서 만든 kr.co.potjob
   Domains and Subdomains   potjob-web.vercel.app
   Return URLs              아래 주소를 **그대로** 붙여넣기
```

```
https://qbnxycavokzcdonlfdat.supabase.co/auth/v1/callback
```

> 이 주소는 Supabase 대시보드 **Authentication → Providers → Apple** 을 열면
> 「Callback URL (for OAuth)」 로 적혀 있습니다. **거기서 복사해 붙이는 것이
> 가장 안전합니다** — 제가 적은 것과 다르면 **화면에 적힌 쪽**이 맞습니다.

```
→ Next → Done → Continue → Save
```

## ③ Team ID 확인

```
developer.apple.com → Account → 오른쪽 위 Membership details
→ **Team ID** (열 글자쯤 되는 영문·숫자)
```

## ④ Key (.p8) 만들기 — **한 번만 받을 수 있습니다**

```
Certificates, IDs & Profiles → 왼쪽 **Keys** → + 단추
   Key Name   POTJOB Sign in with Apple
   **Sign in with Apple** 에 체크 → 옆 Configure
      Primary App ID  kr.co.potjob
      → Save
→ Continue → Register
→ **Download** 를 누르면 `AuthKey_XXXXXXXXXX.p8` 파일이 내려옵니다
```

> **이 파일은 다시 못 받습니다.** 안전한 곳에 두십시오.
> 파일 이름의 `XXXXXXXXXX` 열 글자가 **Key ID** 입니다.

## ⑤ Supabase 에 넣기

```
supabase.com/dashboard → 우리 프로젝트
→ 왼쪽 Authentication → Providers → 목록에서 **Apple**
→ 맨 위 Enable Sign in with Apple 켜기
```

칸이 넷입니다. **값은 세중님이 바로 넣으십시오.**

| 칸 | 무엇을 넣나 |
|---|---|
| **Client IDs** | ② 의 Services ID — `kr.co.potjob.web` |
| **Secret Key (for OAuth)** | ④ 의 `.p8` **파일을 메모장으로 열어** 안의 글 전체 (`-----BEGIN PRIVATE KEY-----` 부터 끝까지) |
| **Team ID** | ③ 에서 본 값 |
| **Key ID** | ④ 파일 이름의 열 글자 |

> Supabase 가 **「client secret」 을 대신 만들어 줍니다.** `.p8` 을 넣으면
> 됩니다 — 따로 도구를 돌려 JWT 를 만드실 필요가 **없습니다.**
> (예전 안내 중에는 직접 만들라는 것이 있는데, 지금 대시보드는 넷만 받습니다.
> 칸이 넷이 아니라 **Secret Key 한 칸**만 보이면 그때 알려 주십시오 —
> 그때는 세중님 PC 에서 돌릴 명령을 적어 드리겠습니다)

```
→ 맨 아래 **Save**
```

## ⑥ 다 되면 — 한 바퀴 시험 (제가 아니라 세중님 계정으로)

웹에서 합니다. 앱은 아직 없습니다.

```
1. https://potjob-web.vercel.app/login 에서 **Apple로 시작하기**
2. 애플 화면에서 **「내 이메일 가리기」(Hide My Email)** 를 골라 보십시오
   → 가입이 끝까지 가야 합니다. 가려진 주소(@privaterelay.appleid.com)여도
     우리는 이메일로 아무것도 안 보냅니다
3. 닉네임·직군을 넣고 가입을 마칩니다
4. 로그아웃 → 다시 Apple 로 로그인 → 같은 계정으로 들어와야 합니다
5. /me → **회원 탈퇴** → 끝까지
6. 다시 Apple 로 로그인 → **새 가입**으로 시작되어야 합니다
```

**막히면 화면에 뜨는 글을 그대로** 알려 주십시오. `/login` 은 실패 까닭을
감추지 않고 그대로 보여 줍니다.

---

## 아직 안 한 것 — **탈퇴할 때 애플 연결 끊기**

애플은 **5.1.1(v)** 에서 「탈퇴하면 애플 쪽 연결도 끊으라」고 합니다
(`POST https://appleid.apple.com/auth/revoke`). 이건 `.p8` 로 만든
client secret 이 **서버에** 있어야 할 수 있습니다.

지금은 안 돼 있습니다. **⑤ 가 끝난 뒤**에 붙이겠습니다 — 승인대기 ⑲.
웹만 쓰는 동안에는 심사 대상이 아니고, **앱을 올리기 전에는 꼭 필요합니다.**
