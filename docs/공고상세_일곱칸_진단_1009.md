# 공고 상세 일곱 칸 — 진단 (2026-10-09)

세중님이 짚어 주신 두 공고로 **지금 무엇이 그려지고 무엇이 비는지** 봤습니다.
짐작하지 않고 `detail` **원문과 항목 이름**을 찍었습니다 (작업지침 2절).

## 1. 강릉의료원 작업치료사 — 같은 자리가 **세 벌**입니다

출처가 셋이라 같은 채용이 세 줄로 들어와 있습니다.

일곱 칸에서 결격사유를 빼기로 한 결정이 이 줄에서는 **도움이 됩니다.**

### 뺀 칸 (전에는 그렸습니다)

전형방법 · 우대사항 · 결격사유 · 문의처 · 제출서류 · **학력**.
강릉 CE 줄에는 **여섯 중 다섯이 들어 있어서** 상세가 길었습니다.
이제 그 내용은 **원문 보기**와 **첨부 공고문**으로 갑니다.

## 4. 전체 숫자 (`node tools/공고칸채우기.mjs --dry`)

```
본 공고        377건 (감춤·보류·관리자잠금 뺀 것)
빈칸 있는 공고 374건
  지원자격 365 · 모집인원 363 · 예상연봉 120 · 근무지 45 · 접수마감 41
첨부가 있는 공고 0건 · 그림 첨부 0장
Haiku 부를 횟수 0번 · 어림 비용 약 $0.00
```

**Haiku 비용이 0 인 까닭** — `job_attachments` 가 **0줄**입니다.
수집기가 첨부 주소를 한 건도 안 담아 두었습니다.
그래서 「첨부 공고문에서 읽기」는 **지금 재료가 없습니다.**
수집기가 첨부를 담게 하는 것이 앞 순서입니다.

## 5. 채우는 규칙 (세중님 확정)

```
순서     ① 제목  ② 상세 API 가 준 detail  ③ 첨부 공고문
         ③ 은 PDF·HWP 는 kordoc, **그림은 Haiku**

· 「공고에 없음」을 쓰지 않습니다. 못 찾으면 **칸을 안 그립니다**
· 모집인원은 **우리 직군 인원만**. 통합 공고의 전체 인원 금지
· 「내규에 따름」·「협의」는 공고 말 그대로. 숫자를 만들지 않습니다
· 근무지는 공고문 우선, 없으면 기관표 주소
· 끝내 못 찾은 칸 → /admin/blanks 「빈칸 공고」. 채우면 edited_fields 로 잠김
· 뽑은 값은 job_posts.뽑은값 에 따로 담고 원문 detail 은 그대로 둡니다
· admin_locked · edited_fields 는 안 건드리고 updated_at 도 안 바꿉니다
```
