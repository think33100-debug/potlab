### 확정한 길

```

               CLI 도움말에 적혀 있었습니다: 「PNG/JPG/WebP → Markdown · 이미지는 OCR 자동 적용」
               막고 있던 것은 optional 의존 **sharp 가 안 깔린 것** 하나였습니다
               → tesseract·클라우드 OCR 비교가 **필요 없어졌습니다. 비용 0.**
ZIP            안을 풀어 파일마다 읽습니다 (붙박이 zlib · 바깥 꾸러미 없음)
DOCX           kordoc parseDocx. 막던 것은 묶음 안 이름의 **역사선**이었습니다
```

### 뿌리 — 왜 0% 였나

```
①  「ZIP 이면 .hwpx」 로 넘기고 있었습니다. 가리는 분기가 있었지만
    `await import('kordoc')` 가 **언제나 실패**했습니다 — kordoc 은
    `tools/kordoc/node_modules` 안에만 있고 `tools/`·`potlab/` 에는 없습니다.
    **`catch {}` 가 그 실패를 삼켜서 한 번도 안 돌았습니다.**
    (돌려 봤더니 `detectZipFormat` 도 세 파일 모두 `unknown` 을 냈습니다)
②  DOCX 묶음 안 이름이 `word\document.xml`(역사선)이었습니다 — 한컴·옛 워드가
    그렇게 적고 kordoc 은 `word/document.xml` 을 찾아 「유효하지 않은 DOCX」로 돌려보냅니다
③  그림은 `첨부읽기()` 의 문턱에서 바로 돌려보냈습니다 + sharp 가 없었습니다
④  묶음 속 이름이 **CP949** 인데 UTF-8 로 읽어 깨졌습니다 —
    「NCS 직무기술서(물리치료사).hwp」가 「NCS ���…」 가 되면 **공고문을 못 고릅니다**
```
