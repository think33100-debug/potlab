### 확정한 길

```

               CLI 도움말에 적혀 있었습니다: 「PNG/JPG/WebP → Markdown · 이미지는 OCR 자동 적용」

## 10. 일곱 칸 **전후** (시험 2회, 2026-10-21) — 그리고 0 이 나온 까닭

### ① 회원이 보는 값 (본표) — 안 움직였습니다

```

○ 틀림·헛채움이 늘어난 칸 **0** (되돌릴 거리 없음)
```

**까닭 — 시험이 고친 자리를 안 지납니다.** 일곱 칸은 `표본.json` 의 **지금값
= DB 에 든 값(회원이 보는 값)** 으로 채점합니다 (`시험.mjs:183`). 우리가 고친 것은
**첨부를 읽는 쪽**이고, 그 50건은 고친 뒤에 **다시 수집되지 않았습니다** —
DB 값이 그대로이니 숫자가 움직일 자리가 없었습니다. 「고쳤는데 안 늘었다」가
아니라 **아직 안 재어진 것**입니다.

### ② 다시뽑음 — 그래서 넣은 자리

시험 머리말에 「다시뽑음 = 같은 원문에 **뽑기 규칙만** 다시 걸어 본 값」이
적혀 있었는데 **약속만 있고 구현이 없었습니다.** 넣었습니다:

```
node tools/능력시험/시험.mjs --다시뽑음           첨부 글 *.txt      (= 고치기 전)
node tools/능력시험/시험.mjs --다시뽑음 --새글     첨부 글 *.새.txt   (= 고친 뒤)
node tools/능력시험/형식다시읽기.mjs --글적기      읽은 글을 *.새.txt 로 (옛 글을 안 덮습니다)
```

받아 둔 표본 첨부 **61건을 고친 읽기로 다시 읽어** (HWP 20·PDF 19·ZIP 5·그림 3·
HWPX 2·DOCX 1 = **51건 전부 읽힘**, 못 읽은 것은 HTML 이 온 10건과 꾸밈 그림 1건)
글 50개를 남기고, 같은 뽑기 규칙으로 전후를 쟀습니다.

```
다시뽑음   전 42/163 (25.8%)  →  후 42/163 (25.8%)
```

**글은 진짜로 늘었습니다** — 정답지 공고 가운데 **9건**의 첨부 글이 달라졌습니다
(0자 → 4,043자 · 15,522자 → 28,510자 등). 그런데 **일곱 칸은 안 늘었습니다.**
공고 9건을 칸마다 들여다보니 **바뀐 칸이 하나**뿐이었습니다:

```
305876  지원자격  「❍ 물리치료사 면허증 소지자 ※ 신경계 물리치료 자격증 소지자 우대할 수 있음」
                → 「물리치료사 면허증 소지자」      (점수는 전후 같음 — 둘 다 같은 판정)
```

### ③ 그래서 읽은 결론 — 다음 지렛대는 **읽기가 아니라 뽑기**입니다

```
· 세 꼴을 읽게 만든 것은 **읽기 단계**를 0% → 96~100% 로 올렸습니다 (9절)
· 그 글이 **칸으로는 아직 안 번역됩니다** — 답이 이미 쪽 본문에서 오고 있었고,
  새로 읽히게 된 첨부(ZIP·DOCX·그림)의 답은 **표 안·OCR 글**에 있어

```

### ④ 다시뽑음 숫자를 읽을 때 주의

다시뽑음(25.8%)은 지금값(41.4%)보다 **낮습니다.** 뽑기 규칙만 홀로 돌린 값이라

## ★ 정답지를 고친 횟수 — 누적 (2026-10-22 세중님 3번)

**왜 세나** — 점수가 나쁘게 나오면 **코드보다 정답지를 먼저 의심해야** 합니다
(지침 10-2a). 그런데 「이번에도 정답지였다」가 몇 번째인지 세지 않으면, 제가 매번
처음 있는 일처럼 적게 됩니다. 그래서 **누적으로 적습니다.** 이 칸이 늘어나는 것은
제 정답지가 믿을 만하지 않다는 뜻이고, 그만큼 **첫 점수를 조심해서** 읽어야 합니다.

```

```

## 새 40건의 **첫 점수** (표본5 · 2026-10-22 저녁 · 세중님 5번)

오늘 낸 「100%」는 **같은 40건으로 고치고 다시 잰 값**이라 과적합입니다. 그래서
**오늘 한 번도 안 본 회원 화면 공고 40건**(표본 1·2·3·4 의 136건을 뺐습니다)으로

```

   그 4건에서 채운 칸 13개 가운데 **틀림 1개**가 나왔습니다 (안동병원 HS370080078
   지원자격에 목록 표가 통째로 들어옴 → 같은 날 `쓸만한자격글()` 에 울타리)
③ 고용형태는 **글자 찾기로 채점할 수 없습니다** — 「공무직근로자」→무기계약직,
   「임시직」→계약직처럼 판단입니다. 네 건은 원문 줄을 사람이 보고 맞음으로 셌습니다

**판단표에 쓸 한 줄** — 워크넷(회원 화면의 90%)은 **채우기·맞히기 둘 다 끝났습니다.**
