## 아직 안 한 것 — 표본 보건소 10곳 홈페이지

세중님이 지시한 「표본 보건소 10곳(지역 고르게) 홈페이지를 열어 채용 공고가
어디 올라오는지」는 **아직 안 했습니다.** 블록을 따로 받아야 할 품입니다.

**다만 ②를 보고 나니 물어볼 것이 바뀌었습니다.** 「어디에 올리나」보다
**「보건소가 우리 직군을 뽑기는 하나」**가 먼저입니다. 나라일터 2,049건에
보건소 치료사 공고가 0건이라면 두 가지 중 하나입니다 —

```
㉮ 보건소가 물리치료사·작업치료사를 거의 안 뽑는다
   (지역사회중심재활사업이 줄었다면 그럴 수 있습니다)
㉯ 뽑는데 시군구청 홈페이지 고시공고에만 올리고 나라일터에 안 올린다
```

㉮ 라면 475곳 수집기는 **품만 드는 일**입니다. ㉯ 라면 만들어야 합니다.
가리는 길은 둘입니다 —

```
① 심평원 자료로 **보건소에 우리 직군이 몇 명 있나** 셉니다
   (hira_org 에 보건기관 종별이 있고, 인원 자료도 받아 둔 것이 있습니다)
   사람이 0명에 가까우면 ㉮ 입니다
② 표본 보건소 10곳 고시공고 게시판을 열어 최근 1년 치를 봅니다
```

**①이 훨씬 값쌉니다** — 이미 받아 둔 자료이고 웹을 안 긁습니다.
세중님 확인을 받고 ①부터 하겠습니다.
