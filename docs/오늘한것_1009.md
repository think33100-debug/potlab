## ③ 막혀서 넘어간 것

- **`before-user-created` 훅** — 세중님이 대시보드에서 켜셔야 합니다. 권한은 확인했습니다
  (`supabase_auth_admin` 에 execute 있음 · anon·authenticated 없음 · PUBLIC 없음). **켜도 됩니다.**
  켜신 뒤 ③ 이메일 가입 403 · ④ 기존 회원 로그인 정상을 제가 확인합니다.
  카카오·네이버 신규 가입은 **진짜 계정이 있어야** 해서 못 했습니다 — 24시간 Auth 로그를 함께 보겠습니다.
- **국세청 사업자 진위확인** — `NTS_BIZ_KEY` 가 아직 없습니다. 없으면 「수동 확인」으로 돕니다.
  열쇠가 생기면 `node tools/사업자진위확인.mjs <번호> --원문` 으로 **응답 원문부터** 찍고 맞춥니다.
- **채용담당자 공고 등록·수정** — 일부러 안 만들었습니다. 수집한 값과 담당자가 고친 값이
  어긋났을 때 **어느 쪽이 맞는지 정하는 규칙**이 먼저입니다.
- **이메일 알림** — 보내는 곳(도메인·발신 주소)이 정해지면 같은 알림함을 보고 보냅니다.
