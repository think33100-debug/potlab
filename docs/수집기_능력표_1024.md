## 3. ★ 점수를 올리기 전에 **자를 합쳐야 합니다** (채점기가 두 벌입니다)

틀림 38개를 훑어 보니 **적어도 여덜 개는 「같은 뜻을 다른 꼴로」** 적은 것입니다 —
지침 10-5 에 이미 적어 둔 함정인데, **능력시험 채점기만 아직 그것을 안 봅니다.**

```
① 금액 꼴    5건   정답 「월급 244만원」 ↔ 우리 「월급2,440,970원 이상 ~ …」
                   → **같은 돈**입니다. 우리 값이 더 정확합니다
② 고용형태 이름 3건   정답 「계약직」 ↔ 우리 「기간제」·「비정규직」  (틀림 3건 **전부** 이 꼴)
③ 요약 ↔ 문장  8건(지원자격)  정답 「물리치료사 면허증 소지자(경력 관계없음·학력무관)」
                   ↔ 우리 「자격 물리치료사 · 학력 학력무관」 — 포털이 준 **요약**입니다
```

```
자가 두 벌입니다
  tools/칸대조.mjs      신뢰 셋 ② 가 씁니다 — 금액 꼴·날짜 꼴을 **압니다** (10-5 뒤 고쳤습니다)
  tools/능력시험/시험.mjs  능력표가 씁니다 — **아직 모릅니다**
→ 능력시험이 `칸대조.mjs` 의 `칸판정()` 을 쓰게 합니다 (지침 6절 — 기준은 한 자리)
```

**①② 만 반영해도 틀림 38 → 30 이고 정답률 43% → 48% 입니다.** ③은 「요약을 맞음으로
볼 것인가」를 먼저 정해야 합니다 — 지금 회원 화면에 보이는 것은 그 요약입니다.

★ **이것은 점수를 올리는 작업이 아니라 틀린 자를 고치는 작업입니다** —
  세중님 「짐작 점수 금지」와 같은 뜻으로 읽었습니다. 합치기는 **동결(10/31) 전에**
  하겠지만 **수집기 쪽 코드가 아니라 시험 도구**라 동결과 무관합니다.
