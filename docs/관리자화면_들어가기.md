# 관리자 화면에 들어가는 길 (2026-10-23 · 코드와 DB 에서 확인한 것만)

★ **지금 못 들어가는 까닭을 찾았습니다** — 계정이 **페르소나(작업치료사) 상태**라
  `is_admin()` 이 거짓입니다. 아래 ②-3 에 되돌리는 길이 있습니다. **한 번 누르면 됩니다.**

---

## ① 주소 — 운영 도메인 기준

```
관리자 홈        https://potjob-web.vercel.app/admin
공고 (보류함)     https://potjob-web.vercel.app/admin/jobs
GJ306151 바로     https://potjob-web.vercel.app/admin/jobs?state=live&q=GJ306151
```

`/admin/jobs` 는 **주소 칸을 읽습니다** — `state`(상태 칸) · `q`(찾기) · `tab` · `page`
(`web/app/admin/jobs/page.tsx:36-39`). 그래서 위 세 번째 주소를 그대로 열면
**그 공고 한 건만** 나옵니다.

```
어디서 왔나   tools/hold-digest.mjs:690 — 아침 메일 맨 끝에 적히는 그 주소입니다
             `cfg.ADMIN_URL || 'https://potjob-web.vercel.app/admin/jobs'`
             서버 .env 에 ADMIN_URL 이 **없습니다** → 기본값을 씁니다
```

★ **[확인 필요] 다른 도메인(potjob.co.kr 등)은 제가 못 봅니다.** 코드에는
  `NEXT_PUBLIC_SITE_URL` 로 갈아끼울 자리만 있고(`web/lib/site-url.ts:7,14`), 그 값은
  **Vercel 쪽 설정**이라 제가 읽을 수 없습니다. 지금 아는 운영 주소는 위 하나입니다.

## ② 로그인 계정과 `is_admin()` 판정

### ②-1 판정 기준 — DB 에서 찍은 본문 그대로

```sql
CREATE OR REPLACE FUNCTION public.is_admin() RETURNS boolean
 LANGUAGE sql STABLE SECURITY DEFINER SET search_path TO 'public'
AS $function$
  select exists (select 1 from admins where profile_id = auth.uid() and 끈때 is null)
     and not exists (select 1 from 마스터페르소나
                      where auth_id = auth.uid() and 지금역할 <> '관리자')
$function$
```

**조건이 둘입니다 — 둘 다 맞아야 참입니다.**

```
㉠ admins 에 내 줄이 있고 「끈때」가 비어 있다
㉡ 마스터페르소나의 「지금역할」이 **관리자**다 (페르소나 중이면 **거짓**)
```

화면 쪽은 `useAuth()` 가 `rpc('is_admin')` 을 불러 단추를 보일지 정하고
(`web/app/auth.tsx:114`), `/admin/layout.tsx` 가 아니면 「관리자만 볼 수 있어요」를
냅니다(99~102줄). **막는 진짜 자리는 DB 입니다** — 브라우저에서 `isAdmin` 을 참으로
바꿔도 창구가 안 해 줍니다(layout.tsx 10~15줄 주석).

### ②-2 계정 — `admins` 에 **두 줄**이 있고 살아 있는 것은 하나입니다

| 메일 | 갈래 | 넣은 때 | 끈때 | auth.users 에 |
|---|---|---|---|---|
| `mast***` | 직원 | 2026-10-09 | (살아있음) | **있습니다** ← 이 계정으로 들어가십니다 |
| (못 찾음) | **대표** | 2026-09-19 | (살아있음) | **없습니다** ← 고아 줄 (아래 ②-4) |

```
thin***(세중님이 쓰시던 메일)   auth.users 에 **없습니다** · admins 에도 **없습니다**
                       → 그 메일로는 로그인 자체가 안 됩니다
```

★ 메일 전체는 적지 않습니다 — `admins` 에 살아 있는 줄은 **`mast…` 로 시작하는
  계정 하나**입니다(갈래=직원 · 2026-10-09 에 넣은 것).

### ②-3 ★ 지금 막혀 있는 까닭과 **되돌리는 길**

```
마스터페르소나.지금역할 = **작업치료사**   →  is_admin() = **false**
```

`web/components/persona-bar.tsx` 주석이 그 일을 이렇게 적어 뒀습니다 —
「페르소나 중에는 관리자 힘이 꺼집니다. DB 의 `is_admin()` 이
「마스터페르소나.지금역할 <> 관리자」면 false 를 냅니다. **그래서 90군데가
한꺼번에 막힙니다.**」

**누르는 길 — 세 걸음**

```
1. https://potjob-web.vercel.app 아무 쪽이나 로그인한 채로 엽니다
   (관리자 화면이 아니어도 됩니다 — 회원 화면이면 됩니다)
2. **화면 맨 아래 빨간 띠**에서 「운영진 · 작업치료사」 단추를 누릅니다 → 펴집니다
3. 역할 단추 가운데 **「관리자」** 를 누릅니다 → 쪽이 저절로 새로 열립니다
```

그 띠는 **모든 쪽 아래에 그려집니다**(`web/app/layout.tsx:119` 의 `<PersonaBar />`).
띠가 사는 조건은 `마스터인가()` 하나라서 — DB 본문이
`select exists (select 1 from 마스터페르소나 where auth_id = auth.uid())` —
**페르소나 중에도, 「비회원 보기」 중에도 띠는 보입니다.** 돌아올 길이 막히지 않습니다.

```
누르면 무엇이 바뀌나   페르소나바꾸기(p_역할) 가 profiles.role·job_group·survey_at 을
                      **진짜로** 바꿉니다 (화면만 흉내 내지 않습니다). 「관리자」로
                      돌리면 마스터페르소나.보관 에 넣어 뒀던 원래 값으로 되돌립니다
```

### ②-4 ★ 작은 것 — `admins` 의 **갈래=대표 줄이 고아**입니다

```
profile_id 가 auth.users 에도 **없고** profiles 에도 **없습니다**
넣은 때 2026-09-19 · 끈때 비어 있음 (살아 있는 줄로 셉니다)
```

**지금은 해가 없습니다** — `is_admin()` 은 `auth.uid()` 와 맞는 줄만 보니, 가리키는
계정이 없으면 아무에게도 권한을 주지 않습니다. 다만 「대표가 등록돼 있다」로 보여
**다음에 권한을 셀 때 헷갈립니다**. 지우는 것은 `delete` 라 승인 자리입니다
(`docs/승인대기_1023.md` 에 올려 뒀습니다).

## ③ GJ306151 찾기 + 「보류함으로」 단추

### ③-1 찾기 — 두 길

```
ⓐ 주소로 바로   /admin/jobs?state=live&q=GJ306151
ⓑ 손으로        /admin/jobs → 상태 칸에서 **「올라간 것」** → 찾기 칸에
               「GJ306151」 을 넣고 **찾기**
```

**상태 칸의 기본값은 「보류함」입니다**(`page.tsx:36` — `|| 'hold'`). 이 공고는
지금 **회원 화면에 올라가 있으니**(hold=false · hidden=false) 보류함 칸에는
**없습니다.** 「올라간 것」으로 옮기거나 ⓐ 주소를 쓰십시오.

찾기 칸이 받는 것 — 「기관명 · 공고명 · 공고ID」(`page.tsx` 의 placeholder).

```
찾을 공고   GJ306151
기관        보건복지부 국립재활원
제목        국립재활원 한시임기제 공무원(**보건의료정보관리사**) 경력경쟁채용시험 재공고
주소        https://www.gojobs.go.kr/apmView.do?empmnsn=306151
붙은 직군    작업치료사  ← 기관 원문 어디에도 우리 직군 말이 없습니다
```

### ③-2 「보류함으로」 단추 — 그 공고 칸 **안쪽 아래 줄**

공고 한 줄마다 단추가 한 줄로 있습니다(`page.tsx:301~325`). 왼쪽부터 —

```
[회원 화면에 올리기]   ← hold 나 hidden 일 때만 보입니다 (지금은 **안 보입니다**)
[숨기기]              ← hidden 이 아닐 때
[보류함으로]           ← **hold 가 아닐 때** · 지금 보입니다 ★ 이것을 누르십니다
[잠금 풀기]            ← admin_locked 일 때만
[수정]  [회원 화면]                        … 오른쪽 끝에 [삭제] (빨강)
```

★ **[삭제]를 누르지 마십시오** — 오른쪽 끝에 떨어져 있고 「되돌릴 수 없어요.
  보류함으로 보내는 쪽이 안전해요」라고 묻습니다(`page.tsx:168`).

```
누르면 무엇이 도나   rpc('admin_decide', { p_id, p_what: '보류함으로' })
                   admin_decide(p_id text, p_what text, p_job_group text, p_note text)
                   ACL — authenticated 에게 EXECUTE 가 있고 본문이 is_admin() 을 봅니다
됨/안 됨 알림        「보류함으로 보냈어요」 라고 뜹니다 (page.tsx:144)
```

★ **제 도구로는 못 누릅니다** — 도구는 `service_role` 로 도는데 `admin_decide` 는
  `is_admin()`(= `auth.uid()`)을 봅니다. `service_role` 에는 `auth.uid()` 가 없어
  판정이 거짓입니다. 그래서 세중님 손이 필요합니다.
