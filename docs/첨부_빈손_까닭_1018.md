## 3. 404 5건 — 공고가 내려간 것인가

`www.kch.or.kr` 2 · `www.kwmc.or.kr` 2 · `www.newyjh.com` 1 = **5건**.

**아직 확인 안 했습니다.** 재는 법 — 그 공고의 `url`(상세 쪽)이 지금도 열리는지
보면 갈립니다.

```
상세 쪽도 404/없어짐  → 공고가 내려간 것. 정찰이 gone 으로 잡아야 할 자리
상세 쪽은 열림        → **첨부 주소만 틀린 것.** 수집기 link 규칙을 봐야 합니다
```

`읽기탈` 에 까닭이 남아 있으니 다음 바퀴에 바로 집을 수 있습니다.
