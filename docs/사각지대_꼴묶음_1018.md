## 3. 막힌 것 — 왜 막혔나

### ㉠ 못 받음 9곳 — 서버에서 안 열립니다

```
울산대학교병원 · 동국대 분당한방 · 대전대 대전한방 · 동국대 경주병원 ·
건양대 부여병원 · 서광병원 · 세종여주병원 · 정읍한국병원 · 화성유일병원
```

★ **`세종여주병원.com` 은 한글 도메인**입니다 — `https://세종여주병원.com`.
`fetch` 가 퓨니코드로 바꿔 주는지 확인해야 합니다(지침 6-2b 와 같은 결).

고신대·계양구보건소와 같은 꼴일 수 있습니다 — **서버에서는 안 열리고 컴퓨터에서는
열리는** 것. 가리려면 이 컴퓨터에서 같은 주소를 받아 봐야 합니다. **아직 안 했습니다.**

### ㉡ JS 껍데기 12곳 (옮겨 가는 8 + 만드는 4)

```
강북삼성병원(218바이트) · 원광대 한방(496) · 조선대 치과(103) · 구병원(443) ·
신가병원(507) · 하남성심(614) · 세명대 충주한방(447) · 명지병원(1,693) ·
박애병원(1,544) · 씨엠병원(1,647) · 원광대 광주한방(2,189) · 상주성모(3,011)
```

**playwright 로 열어야** 진짜 게시판 주소가 보입니다. 서버에 **안 깔려 있습니다**
(깔면 크로미움 수백 MB — 승인받을 일입니다). 그중 **명지병원·박애병원·상주성모는
robots 전면 금지**라 열어도 긁으면 안 됩니다 → **실제 대상은 9곳**입니다.

### ㉢ 링크 못 찾음 15곳

쪽은 열리는데(5KB~223KB) 첫 화면에 채용 링크가 없습니다. 메뉴가 JS 로 만들어지거나
채용이 **다른 하위 도메인**에 있을 수 있습니다. 쪽마다 봐야 합니다.
