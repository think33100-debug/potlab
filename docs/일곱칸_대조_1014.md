# 일곱 칸 대조표 — 네숫자()가 세는 칸 ↔ 화면이 그리는 칸 (2026-10-14)

세중님 지시 — 「일곱 칸 전부 「네숫자()가 세는 칸 = 화면이 그리는 칸」인지
칸마다 대조표. 다른 것은 **화면 쪽에 맞추기**.」

화면은 `web/app/jobs/[id]/page.tsx` 한 곳입니다 (공고 상세).

## 고친 셋

**지원자격** — 가장 큽니다. `edu` 는 화면이 **한 번도 안 보는 칸**입니다.
회원이 보는 것은 `뽑은값.지원자격 ?? detail.지원자격` 입니다. 88.7 → **77.9**.

**근무지** — 화면은 `지역보임`(우리가 정리한 지역)을 먼저 봅니다. `work_place`
가 비어도 `지역보임` 이 있으면 칸이 그려집니다. 90.9 → **96.7**.

**모집인원** — 화면은 알리오 통합 공고의 `직군인원`(「물리치료사 3명 ·
작업치료사 1명」)과 `뽑은값.모집인원` 도 봅니다. 77.6 → **78.2**.

## 나눈 하나

**바쁜정도**와 **병원뜯어보기**는 같은 자료(`org_hospital_stat`)를 쓰지만
**조건이 다릅니다** — 병원뜯어보기는 줄만 있으면 그리고, 바쁜정도는 `band`
까지 있어야 그립니다. 지금은 두 숫자가 53.0 으로 같지만(줄이 있으면 band 도
다 있습니다) 언제든 갈릴 수 있으니 따로 셉니다.

## 1층만 따로

1층과 2층의 사정이 아주 다릅니다. 네숫자() 가 함께 돌려줍니다.

```
병원뜯어보기    53.0     100.0
```
