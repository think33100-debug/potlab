2. 위쪽 함수 고르는 칸에서 **`testOcr`** 을 고르고 **▷ 실행**
3. **「권한 검토」** → 계정 고르기 → **「고급」** → **「potjob OCR(으)로 이동(안전하지 않음)」** → **「허용」**

## 이 프로젝트에 대해

- **수집기(`gas/wage.js`)와 다른 프로젝트**입니다. 수집기는 동결이고 이건 OCR 만 합니다
- **열쇠가 한 줄도 없습니다.** 그래서 이 폴더는 저장소에 올라갑니다
  (비밀값은 스크립트 속성에만 있습니다)
- 코드를 고치면 `.\push.ps1 -deploy` 로 올리고 배포합니다
- 나중에 구글 Vision 같은 것으로 바꾸려면 **`tools/ocr/` 아래 파일 하나만**
  같은 모양으로 만들면 됩니다. 수집기는 안 고칩니다

## 왜 이 길로 왔나

node 에서 드라이브를 직접 쓰려고 두 가지를 해 봤고 둘 다 막혔습니다.

| 길 | 어떻게 됐나 |
|---|---|
| 서비스 계정 | **제 드라이브 용량이 0.** 폴더를 공유받아도 올린 파일 주인이 서비스 계정이라 `403 storageQuotaExceeded`. 공유 드라이브가 있으면 풀리는데 개인 gmail 에는 없습니다 |
| OAuth (개인 계정) | 됩니다. 다만 열쇠 셋을 관리해야 하고, 동의 화면이 「테스트」면 **7일마다 죽습니다** |
| **Apps Script** | 세중님 계정으로 그냥 돕니다. **열쇠 관리가 없습니다** |
