## ② 공용 채용사이트 — 세중님이 짚으신 셋

### 한림대 4곳 · `recruit.hallym.or.kr` — **가장 잘 됩니다**

JS 가 아니고 **목록이 HTML 에 그대로** 있습니다. 4곳이 같은 34,185바이트 쪽입니다.

그리고 **병원을 가르는 값이 주소에 있습니다** —

```
hrt_p20_detail.jsp?locate=7&adoptcnt=218&inggbn=ing&adoptyy=2026
                   ^^^^^^^^   병원 번호
목록에서 본 locate — 1 · 2 · 3 · 5 · 7 · 9 …
```

공고 제목에도 병원 이름이 들어 있습니다 (`한림대학교성심병원 가정간호사 공개채용 공고 · 마감일 2026.10.31`).
**한 번 긁고 `locate` 와 제목으로 나눠 붙이면 됩니다.**
`locate` 번호 ↔ 병원 대응은 아직 안 확인했습니다 — 규칙을 만들 때 한 번 훑겠습니다.

### 순천향 3곳 (+중앙의료원·부천) · `jobapplication.schmc.ac.kr` — **자료 주소가 있습니다**

세 주소(`?departmentidx=190002/190004/190005`)가 **똑같은 111,647바이트**를 줍니다 —
`departmentidx` 는 화면 안에서만 쓰는 값입니다.

화면 안에 병원 거르개가 있고(`전체 · 중앙의료원 · 서울병원 · 부천병원 · 천안병원 · 구미병원`),
목록을 부르는 자리를 찾았습니다.

```
/recruit/biz/job/recruiteList     ← 공고 목록
/recruit/biz/job/recruitemain
```

**아직 두드려 보지는 않았습니다.** 규칙을 만들 때 응답 원문부터 찍겠습니다.
여기도 **한 번 긁고 병원별로 나눠 붙이는** 꼴입니다.

### 세종충남대 · 빛고을전남대 (+중앙대광명·한양대구리) · `*.recruiter.co.kr` — **브라우저가 있어야 합니다**

미다스 채용 시스템입니다. 넷 다 같은 모양입니다.

```
Next.js App Router · 스크립트 31개 · 본문은 20자 남짓
HTML 안의 자료(__next_f)에는 **제목과 설명뿐**이고 공고 목록이 없습니다
번들 6개를 읽어봤지만 자료 주소가 안 나왔습니다 (난독화)
```

두 번 두드려 못 찾아 **멈췄습니다** (CLAUDE.md 3번 — 짐작으로 주소를 만들지 않습니다).
이 넷은 **브라우저로 열어야** 목록이 보입니다.

> 세종충남대는 본원(충남대병원)과 공용, 빛고을전남대는 본원(전남대병원)과 공용이라고
> 하셨습니다. 맞습니다 — `cnuhinsa` 쪽 제목이 「충남대학교병원 채용」 이고
> 「본분원」 이라는 말이 들어 있습니다. 한 번 긁어 나누는 꼴은 같은데,
> **긁는 방법이 다릅니다.**
