# 드라이브 OCR 열쇠 받기 (세중님이 하실 일)

알리오 공고문은 거의 전부 **스캔 그림**이라 글자를 뽑으려면 OCR 이 있어야 합니다.
구글 드라이브의 「문서로 변환」 이 OCR 을 해 줍니다.

**서비스 계정은 안 됩니다.** 제 드라이브 용량이 0 이라, 폴더를 공유받아도
올린 파일의 주인이 서비스 계정이어서 `403 storageQuotaExceeded` 가 납니다.
공유 드라이브가 있으면 풀리는데 개인 gmail 에는 공유 드라이브가 없습니다.
그래서 **세중님 계정으로** 올립니다.

권한은 **`drive.file` 하나만** 씁니다 — 이 앱이 만든 파일만 보고 지웁니다.
세중님 드라이브의 다른 파일은 **못 읽습니다.**

---

## 1단계 — OAuth 클라이언트 만들기

이미 쓰고 계신 구글 클라우드 프로젝트(서비스 계정 만드신 그곳)에서 합니다.

1. <https://console.cloud.google.com/apis/credentials> 를 엽니다
2. 왼쪽 위에서 **그 프로젝트가 골라져 있는지** 확인합니다
3. 위쪽 **「+ 사용자 인증 정보 만들기」** → **「OAuth 클라이언트 ID」**
4. 「애플리케이션 유형」 에서 **「데스크톱 앱」** 을 고릅니다
   - 웹 애플리케이션이 아닙니다. 데스크톱 앱이라야 `localhost` 로 돌아옵니다
5. 이름은 아무거나 (예: `potjob OCR`) → **「만들기」**
6. 뜨는 창의 **클라이언트 ID** 와 **클라이언트 보안 비밀번호** 를 복사해 둡니다
   (나중에 다시 볼 수 있습니다)

## 2단계 — Drive API 켜기 (이미 켜 두셨으면 넘어가세요)

1. <https://console.cloud.google.com/apis/library/drive.googleapis.com>
2. **「사용」** 을 누릅니다 (이미 켜져 있으면 「관리」 라고 보입니다)

## 3단계 — 동의 화면을 「프로덕션」 으로 ⚠ **이게 제일 중요합니다**

**안 하시면 열쇠가 7일 뒤에 죽습니다.** 구글 문서에 그대로 적혀 있습니다 —

> a publishing status of "Testing" is issued a refresh token expiring in 7 days

1. <https://console.cloud.google.com/apis/credentials/consent>
2. 「게시 상태」 가 **「테스트」** 면 → **「앱 게시」** 를 누릅니다
3. 「프로덕션으로 푸시하시겠습니까?」 → **「확인」**

**심사는 안 받아도 됩니다.** `drive.file` 은 구글이 「민감하지 않은 범위」로
분류한 것이라, 보안 심사 없이 게시됩니다
(구글 문서: non-sensitive scopes *"only require basic OAuth App Verification"*).

「게시됨 · 확인 필요 없음」 이 아니라 「확인 진행 중」 같은 말이 뜨면,
**범위에 `drive.file` 말고 다른 것이 들어 있는지** 봐 주세요.
`drive` (전체 드라이브)가 들어 있으면 심사 대상이 됩니다.

## 4단계 — 열쇠 받기 (컴퓨터에서 한 번)

```
cd "C:\Users\think\OneDrive\바탕 화면\potjob\potlab"
node tools/drive-auth.mjs <클라이언트 ID> <클라이언트 보안 비밀번호>
```

- 브라우저가 열립니다. **세중님 계정**으로 로그인하고 **「허용」**
- **「이 앱은 Google에서 확인하지 않았습니다」** 가 뜨면
  → **「고급」** → **「…(으)로 이동(안전하지 않음)」**
  (세중님이 직접 만든 앱이라 그렇습니다)
- 터미널에 값 세 개가 찍힙니다

## 5단계 — GitHub Secrets 에 넣기

<https://github.com/think33100-debug/potlab/settings/secrets/actions>

| 이름 | 값 |
|---|---|
| `GDRIVE_CLIENT_ID` | 1단계에서 받은 클라이언트 ID |
| `GDRIVE_CLIENT_SECRET` | 1단계에서 받은 보안 비밀번호 |
| `GDRIVE_REFRESH_TOKEN` | 4단계에서 찍힌 값 |

`GDRIVE_OCR_FOLDER` 는 **있어도 되고 없어도 됩니다.**
있으면 그 폴더에 올렸다 지우고, 없으면 드라이브 맨 위에 올렸다 지웁니다.
어느 쪽이든 **OCR 이 끝나면 바로 지웁니다** — 쌓이지 않습니다.

**`GDRIVE_SA_JSON` 은 이제 안 씁니다.** 지우셔도 됩니다
(코드는 OAuth 가 있으면 그쪽을 먼저 씁니다).

## 6단계 — 되는지 보기

**Actions → 「알리오 수집 (AL2 · 새 수집기)」 → Run workflow →
「담지 말고 옛것과 대조만」 체크 → 실행**

로그에서 이 두 줄을 봐 주세요.

```
규칙 구운 날 … · OCR 세중님 계정 (OAuth · drive.file)     ← 열쇠를 찾았다는 뜻
OCR        N건                                        ← N 이 0 보다 커야 합니다
```

---

## 열쇠가 죽으면

로그에 이렇게 뜹니다. 그리고 **workflow 가 빨간 줄로 실패**합니다 —
조용히 넘어가지 않습니다.

```
★ OCR 열쇠 확인 — 연속 5번 실패해서 멈췄습니다.
  마지막 까닭: ★ 드라이브 열쇠가 죽었습니다 (invalid_grant) — …
```

그러면 **3단계(프로덕션 게시)를 확인**하고 **4단계를 다시** 돌리시면 됩니다.

연속 5번 실패하면 더 안 두드립니다. 열쇠가 죽었는데 500건을 다 두드리면
로그가 90줄씩 쌓이고 무엇이 문제인지 안 보이기 때문입니다.
